# 知识

存放已经整理、抽象并适合长期复用的技术知识与领域知识。

## 目录

- [技术](./技术/)：知识工程、RAG、评测、Agent、Harness、Ontology、MCP、部署和企业流程
- [领域](./领域/)：半导体、制造业等业务领域知识

## 边界

- 外部产品、公司和案例事实放在 [研究](../研究/)。
- 个人判断、战略方向和职业路线放在 [洞察](../洞察/)。
- 有独立实现、测试、部署和验证节奏的内容放在 [项目](../项目/)。
- 个人经历、简历和面试表达放在 [个人](../个人/)。

知识正文必须经过整理和验证，保留来源、适用范围、更新时间和成熟度；未验证的想法不直接进入本目录。
