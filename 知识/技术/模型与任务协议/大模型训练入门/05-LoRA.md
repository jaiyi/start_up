# 05 · LoRA：用少量可训练矩阵适配大模型

> 一句话：Low-Rank Adaptation 冻结大部分基座权重，在选定线性层增加低秩增量 `ΔW = BA`，只训练小矩阵 A、B；它是参数高效微调方法，不是数据集或对齐目标。

## 类比与公式

假设原矩阵 W 有 1000×1000 个参数；若选择秩 r=8，则 A、B 的增量约为 8×1000 + 1000×8 个可训练参数（仅示意，不含其他模块或优化器状态）。前向计算可写为 `y = Wx + BAx`。实际节省取决于注入哪些层、是否训练 embedding/head、精度和实现。

```text
基座模型（冻结） + 任务 adapter（LoRA 权重） → 任务适配后的行为
```

训练示范学习可以采用 SFT 目标，偏好训练也可能用 LoRA；不要说“先 SFT 再 LoRA”是普遍必须顺序。

## 取舍

- 优点：可训练参数和相应优化器状态较少，便于保存多个适配器。
- 限制：加载基座模型仍有显存需求；秩、目标层和数据质量决定效果。未经合并的适配器在某些部署方式下会增加推理开销，**LoRA 不等于模型量化或无条件加速推理**。
- 若要同时降低基座权重显存占用，可研究 QLoRA：它把量化基座权重与 LoRA 训练结合，但有量化精度和实现前提。

## 自测

LoRA 让新知识实时可检索了吗？**没有**，它修改权重/增量；可追溯的新知识仍更适合在授权 RAG 中维护。
