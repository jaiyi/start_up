# 大模型训练入门：从数据到会使用工具的模型

> 面向初学者的概念地图；不是从零复现大模型的工程手册。本文举例均为合成例子，不要求下载模型或使用真实业务数据。与 [大模型技术体系总览](../大模型：理解DeepSeek、Qwen、GLM等底层模型能力.md)配合阅读。

## 一张地图

```text
原始材料 → 合规筛选/数据清洗 → token 化 → 预训练（预测下一个 token）
                                              ↓
                                      基座模型 / 可选 MoE 架构
                                              ↓
             SFT（演示任务）/ 可选 LoRA 参数高效训练
                                              ↓
       偏好或可验证结果优化：DPO、PPO、GRPO、CISPO 等路线
                                              ↓
       Tool Use / Agentic RL / 自适应思考（能力与训练策略）
                                              ↓
       蒸馏得到更小的学生模型；离线评测 + 安全与治理贯穿全链
```

这不是唯一顺序：MoE 是**架构**，LoRA 是**训练参数策略**，RLAIF 描述**反馈来源**，PPO/GRPO/CISPO 是**优化方法**，Tool Use 是**行为能力**；不能把它们一概叫“训练阶段”。DPO 可直接用偏好对优化，不必一定先训练奖励模型或运行在线 RL。训练数据和评价数据要隔离，结果必须通过独立任务、成本与安全测试核对。

## 推荐顺序

1. [数据清洗](02-数据清洗.md) → [预训练](03-预训练Pretrain.md)：先理解样本、token、损失与数据泄漏。
2. [SFT](04-监督微调SFT.md) → [LoRA](05-LoRA.md)：理解示范学习及“更新哪些参数”。
3. [RLHF 与 DPO](06-RLHF与DPO.md) → [RLAIF 与 PPO/GRPO/CISPO](07-RLAIF与PPO-GRPO-CISPO.md)：分清反馈来源、偏好目标和参数优化器。
4. [Tool Use](08-Tool-Use.md) → [Agentic RL](09-Agentic-RL.md) → [自适应思考](10-自适应思考.md)：理解从离线示范到多步交互的成本和风险。

## 学完能回答什么？

- 数据清洗和数据审核有什么区别？去重为何可能同时降低污染和误删稀有知识？
- Pretrain 的“学语言分布”和 SFT 的“学按指令回答”分别优化什么？
- LoRA 省了哪些可训练参数，为什么不意味着推理一定更快？
- 人类偏好（RLHF）与 AI 反馈（RLAIF）是什么关系？DPO 和 PPO/GRPO/CISPO 为什么不能简单互换？
- 给模型一个工具 schema 与让工具执行具有业务权限有何不同？模型训练的成功为何不等于 Agent 运行时安全？
- 蒸馏、量化、RAG 和微调各自改变模型或系统的哪一部分？

**落地纪律**：普通团队应先用 Prompt、RAG、工具契约和评测解问题；只有积累稳定、授权且可复现的训练/评测数据、发现通用模型持续失败，才评估微调或更昂贵的 RL。下列论文展示具体方法，不保证在任意模型、业务或硬件上复现作者成绩。
