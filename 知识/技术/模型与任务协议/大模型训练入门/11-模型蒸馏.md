# 11 · 模型蒸馏：让学生模仿老师的行为

> 一句话：知识蒸馏用教师模型产生的概率分布、回答或轨迹训练较小的学生模型，以求在选定任务上以更低资源复制部分能力；它**不是**把教师完整知识原样压缩，也不是 RAG 的知识索引。

## 两种直观做法

1. 软标签蒸馏：老师给每个候选 token 的概率，学生学习接近其分布；不仅看“正确 token”，还看替代选项的相对权重。
2. 回答/轨迹蒸馏：老师对合成且经审查的问题生成答案、推理示例或工具调用示范，学生用这些样本做 SFT 等训练；低质量老师答案可能一并学进去。

```text
合法且经筛选的输入 → 教师输出/分布 → 过滤与质量核对 → 学生训练 → 独立评测
```

通常要看学生是否在**目标任务**保持质量、显存/延迟是否真正下降、幻觉与安全边界是否退化。学生可能在训练分布内模仿得很好，但换任务后明显失效。某些教师 API 或模型授权禁止用其输出训练竞争模型，应先核对服务条款、数据使用许可和隐私政策；蒸馏不会消除版权/个人信息风险。

## 不要混淆

| 方法 | 改变什么 | 典型结果 |
|---|---|---|
| 蒸馏 | 训练一个学生的权重 | 较小模型学到选定行为 |
| 量化 | 用更低精度表示原模型的权重/激活 | 相同架构的内存/速度取舍 |
| LoRA | 给模型加可训练的低秩参数 | 任务适配器 |
| RAG | 推理时检索外部知识 | 可按权更新和引用的上下文 |

## 自测

蒸馏后的学生能否自动知道企业今天新发布的制度？**不能**，除非经授权更新外部知识检索或重新训练。

## 一手资料

- [Hinton 等：Distilling the Knowledge in a Neural Network](https://arxiv.org/abs/1503.02531)——软目标与温度的经典说明。
- [Sanh 等：DistilBERT](https://arxiv.org/abs/1910.01108)——在特定模型和评测下的压缩示例，不能泛化其性能数字。
- [DeepSeek-AI：DeepSeek-R1](https://arxiv.org/abs/2501.12948)——推理模型产生训练样本用于较小模型的研究案例，按论文设定理解。
