# 07｜模型与数据资产保护

> 观察日期：2026-10-28。范围：企业自行训练、托管或调用模型时的权重、适配器、训练数据、评测集、系统提示、检索索引和 API 输出；读者：模型平台、数据治理、研发、安全和采购。本文为防御性教育材料，不提供抽取步骤；不同模型与提供商条款须另行核实。

## 模型不是唯一资产

**模型抽取**指通过获准或越权的查询/文件访问，获得模型行为的可替代近似或机密参数；**蒸馏**可用于正当模型压缩，也可能在违反授权条件下复制能力；**记忆与泄露**指敏感训练数据、上下文、日志或检索片段经输出泄出，不能把每次敏感输出都归因于“训练记忆”。**评测集泄露**可能导致虚高成绩和错误上线决策，即使没有用户数据泄漏；模型文件/LoRA 适配器、Tokenizer、服务端提示与缓存也各有独立权限与许可证。

```text
授权数据 → 清洗/去重/分类 → 训练/微调 → 模型注册表 → 部署 API → 答案/日志
       ↘ 评测集隔离 ───────→ 评测服务 ──→ 准入结论
边界：训练数据与评测集分权；模型文件与推理接口分权；API 可调用 ≠ 可导出权重。
判定：谁调用？哪种用途/速率？哪版模型？输出可包含哪类内容？是否需阻断/复核？
```

首先分开威胁前提和可证明的后果：

| 路径 | 所需访问及可能后果 | 防御性验证重点 |
|---|---|---|
| 制品直接窃取 | 获得注册表、存储、备份或部署节点的读取能力，可复制权重/适配器；不需要先查询 API | 用虚构制品测试导出权限、访问审计与备份隔离 |
| 行为模仿/蒸馏 | 仅有 API 调用权也可能用输出训练替代模型；所得通常是特定任务上的行为近似，不能由此推断已恢复原始参数 | 用合成查询检查用途/配额、异常收集与调用授权；不测试第三方未授权模型 |
| 训练样本重现 | 模型在特定条件下输出与某训练样本高度一致的内容；是否源自训练，需排除检索、上下文、缓存和日志来源 | 以自造带出处的样本隔离输入链，按版本比较输出与训练清单 |
| 从输出推断训练信息 | 有输出访问能力的观察者可能试图推断某类信息是否参与训练，推断强度取决于模型、辅助知识和实验条件；不能把猜测当成员身份的证明 | 在合成数据和明确威胁模型下做隐私评估，记录误报、基线和不确定性 |

训练数据重现依赖数据重复程度和生成条件，不应把所有模型当作会逐字吐出任意语料。威胁主体既可能是越权外部调用者，也可能是有 API 权限但超出合同用途的合作方、内部维护者或被盗服务账号。传统 IAM、备份和供应链安全与模型专有的输出隐私评测需要一起做。

## 两种安全示意失效

1. **受限评测资产混入服务链**：团队把自造“未来题库”放进与训练样本相同的对象存储路径；训练作业递归摄取后离线分数升高。失败发生在资产标签和流水线输入边界，未必有外部入侵，却使验收结论失真；后续公开模型对题库样本的近似回答也无法证明“完全背诵”，需要比对版本和数据流。
2. **API 与模型制品权限混淆**：合作团队仅被批准在测试环境调用内部分类模型，平台却给同一服务账号注册表下载权限；自动化打包时把虚构示例模型适配器附带交付。此处无需进行接口抽取，已经发生文件级资产外流；若只有推理权限，则仍需评估异常调用量和模仿风险，不可混为一谈。

## 分层控制与局限

- **预防｜数据与训练**：来源、许可、敏感级别和允许用途进入不可随手覆盖的训练清单；预处理执行去重、脱敏及秘密扫描；为评测集单独存储、独立权限、记录污染检查和定期更换。去重/脱敏不能保证去除所有隐含个人或商业信息；差分隐私等技术需定义威胁模型、预算及效用权衡，不能只声称“已采用”便认为不会泄漏。
- **预防｜制品与 API**：模型注册表按租户和环境分离读取/导出/部署权限，制品加密和密钥分权，流水线使用短期凭据；上线出口按调用者、用途、地域与配额控制，同时对输出敏感片段作服务器侧策略判定。速率限制能提高某些批量收集成本，不证明阻止所有蒸馏；水印/指纹可辅助追踪但不能确保唯一归属或防逆向。
- **检测｜行为与证据**：记录制品哈希、训练清单与评测集版本、异常导出、查询量/模式、跨租户输出风险及策略决定；按敏感度留存最小化样本，分离审计读权限。单凭高调用量不等于恶意，低速滥用可能绕过；自动相似度告警必须人工复核。
- **响应｜收敛传播**：冻结可疑模型制品/接口，撤销凭据和分享链接，定位模型与数据版本、备份及下游接收方；依事件流程确定重新训练、删除派生物、通知与恢复。撤销访问不能召回已导出的权重或已复制的输出。

## 非生产验证与误区

在隔离环境使用自造“仅训练”“仅评测”“禁止输出”标记样本：验证训练任务只能读取清单列出的对象；评测集被误加入训练时流水线失败；API 用户无法导出模型制品；低额度的合成查询超预算后被限流且留下审计事件；模拟权限撤销后既有会话不能继续导出。不要用真实秘密、真实凭据或第三方未授权模型做抽取试验。误区：“API 不给权重就没有知识产权风险”“匿名化数据一定不会被重现”“得分高证明没有数据污染”“输出过滤足以弥补未授权训练”。残余风险：多来源训练血缘不全、输出与训练样本的关系难证、供应商内部访问难直接观察；采购要索取可核验证据而非仅接收承诺。
