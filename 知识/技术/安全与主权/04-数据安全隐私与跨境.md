# 04 数据安全、隐私与跨境

> 编写日期：2026-10-28；适用：企业 Agent 的训练/微调、推理、检索、Embedding、日志、评测、缓存、备份及供应商链路。读者：数据所有者、架构、隐私/法务、采购和安全。仅提供处理路径和核验问题，不对任何特定地域、行业或合同提供法律结论；官方网页已有入口及部分正文抽样核对；具体法条的当前版本与适用性未核实。

## 一条提示词会留下不止一个副本

**个人数据**的法律口径依司法辖区而异；工程上先识别可直接或间接关联个人的数据，不把“没有姓名”当已匿名。**数据控制/处理责任**的称谓和义务要依适用法律和合同核对，不能仅凭平台“不会训练”推断不留存、不用于滥用监测或不流向分包商。**跨境**既可能是推理请求到异地服务，也可能是远程运维访问日志、向境外观测/评测平台同步数据或备份复制；地域和法律判断应由目标部署和合同证据决定，而非宣传中的区域名。**Embedding** 是衍生表示，不默认匿名或无敏感性；原始片段、向量、元数据、查询及近邻结果仍要分类治理。

```text
员工/客户资料（目的、分类、合法处理依据待确认）
  ├→ 原件库 → 分块/Embedding → 向量索引 → 召回 → 推理提供商 → 回答/工具参数
  ├→ 微调/评测集 → 模型或测试服务（单独审批与版本）
  └→ 宿主日志/缓存/观测 → 分包服务/备份/灾备 → 删除/归档
各边记录：数据种类、接收者与子处理者、存储/访问地点、加密密钥持有者、
处理目的、授权依据、传输与留存时限、删改请求处理、下游转移及证据。
```

数据清单至少区分输入（用户问题、附件、隐含标识符）、中间产物（OCR、分块、嵌入、召回候选、推理上下文、工具参数）、输出（回答、引用、写入记录）及旁路（错误堆栈、模型调用追踪、评测截屏、运维访问、备份）。将**谁能访问**与**数据在哪里处理**分开；即使在本地推理，也可能有第三方遥测、插件转发或跨地域灾备。对每个阶段明确处理目的、最小化字段、保留期和删除能力，并检查索引更新/缓存过期与原件删除是否一致。真正的可删除性需要实测原件、派生索引、备份和外部提供商处理流程，不能只凭管理界面的“删除”按钮。

## 两个不同的合成失效场景

1. **日志扩散**：员工请内部助手把虚构客户投诉摘要成工单；宿主在错误追踪中默认记录完整提示词和附件片段，第三方观测服务拥有较长保留期且可供多个运维团队读取。模型服务不用于训练，仍不能排除日志侧泄漏、超范围访问或违反预期目的。路径是“输入→日志→第三方/备份”，不是“模型训练”。测试必须用假客户数据；处理生产历史日志须按组织事故流程，不能任意下载样本调查。
2. **区域预期与后台处理不一致**：采购团队选择本地域推理端点，假定所有数据都留在本地；但定期质量评测把脱敏不充分的真实问答样本送到另一区域的人工标注/评测服务。即使 API 推理日志保留期短，评测集的备份和分包访问仍可能形成额外跨境或目的扩张问题。应核实物理/逻辑访问、分包、标注和备份清单，与法务判断适用规则；不能仅凭用户 IP 或数据中心标签作结论。

## 控制矩阵：预防、检测与处置

- **采集与调用前预防**：业务端规定允许的目的和数据类型，默认不提交整份资料；服务端做字段白名单、分类、最小化和必要的脱敏/假名化（保留必要关联映射且限制可访问者），对高敏对象要求独立批准。模型调用网关选择获批提供商和区域，封闭任意外部接入；供应商评估核对数据处理协议、分包商名单、训练使用、留存/删除、事故通知、审计支持、区域及远程访问声明。脱敏可能破坏业务含义，也无法保证组合信息不可再识别。
- **处理中预防**：传输/静态加密、分租户权限与短期凭据、工具端复核接收者和发送目的；对日志只记录必要元数据与经批准的短时故障样本，生产密钥和敏感正文不得作为默认追踪标签。把评测/微调与在线推理视作不同用途，单独审批与保存策略；合同承诺不等于技术隔离，应以配置及实际流量核验。
- **检测与响应**：维护数据流账本/出口资产清单，监控异常调用目的地、批量下载、超期缓存与删除队列失败；抽查不同租户索引隔离及供应商回执。发生疑似事件时先停用异常出口/权限、保全最小必要证据、清点复制链和收件方，再由隐私/法务确认通知或补救义务。撤权或删索引不能追回已由人或下游系统复制的内容；监控也不一定覆盖供应商内部处理。

## 非生产负例和验收材料

用带虚构身份标记的合成数据走完整流程：①生成带附件的模拟工单，让应用出错，检查追踪、异常堆栈与评测样本不含不必要的原文；②删除原件后分别查询索引、缓存、测试备份恢复的可见性和删除排程，核对供应商删除回执能证实的范围；③在网关中模拟未获批区域/端点和外部评测服务，预期拒绝并记录决策；④以无权测试账户访问观测日志与向量查询，预期无数据可读。输出可审查的字段表、处理者/地区/保留期矩阵、政策版本、测试证据及仍未知的供应商内部路径，禁止把含敏感原文的失败请求截图传播。

**误区与残余风险**：“不用于训练”不等于不保存；“私有化”不等于没有外部支持访问；加密不代替授权与用途限制；Embedding 不是自动安全的不可逆匿名化；删除在线库不等于删除备份。跨境、个人信息、匿名化和保存时限属于时间及地域敏感判断，应由法务按现行法规、监管解释、合同与实际流向核对。供应商声明与系统遥测不一致时，把未证实的部分列为风险，不能作合规保证。
