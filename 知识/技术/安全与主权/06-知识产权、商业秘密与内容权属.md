# 06｜知识产权、商业秘密与内容权属

> 观察日期：2026-10-28。范围：企业 Agent 的输入、训练/微调、RAG、模型、输出、Skill 与代码的权利和保密边界；读者：数据治理、产品、研发、安全、采购与法务。本章是防御性工程分析，不是任何司法辖区的法律意见；以下“应”主要表示设计建议，不是法律条款。具体权属、例外、赔偿和跨境义务须按地区、合同版本及事实由法务核对。

## 对象与判定路径

**著作权/版权**关注作品及许可使用；**商业秘密**通常涉及不为一般人知悉、具有商业价值且采取合理保密措施的信息（具体要件因法域而异）；**合同保密义务**不等于法定商业秘密；**数据使用许可**、模型使用条款与产出物权属是不同问题。能读到材料不代表获准将其用于训练、对外发布或嵌入长期记忆。模型权重、提示模板、Skill 实现、生成代码和检索索引也可能受不同主体的许可/合同限制，不能统一写成“AI 生成所以企业拥有”。

```text
权利人/数据源 → 获取合同及使用目的 → 入库与分类 → 训练/检索/推理 → 输出与发布
    │              │                 │              │            │
    └来源凭据       └许可/保密范围     └租户/ACL       └片段出处    └人工复核与分发权
决策：来源可证明？本目的获许可？含秘密？接收方可见？超限则隔离/拒绝/转法务。
```

按对象、用途和法域分别提问，不能以一项“企业拥有”结论覆盖整条链。下表是工程核对清单，不代表统一适用的法律测试：

| 对象 | 需确认的不同问题 | 待留证据与决策点 |
|---|---|---|
| 输入、检索原件与片段 | 来源方是否有权授权？查看、索引、训练、微调和引用各是否获准？是否受保密/目的限制？ | 来源与许可版本、合同用途、接收方范围；超范围先隔离 |
| 模型权重、适配器、数据集、Skill/代码 | 制品本身与依赖各由谁提供？使用、修改、再分发及附带通知各受何种许可约束？ | 权利链、第三方组件清单、许可证与版本、发布审批 |
| 生成文字、图像或代码 | 在适用法域及具体创作事实下能否获得保护、由谁主张？供应商合同对输出有哪些约定？是否复现第三方受保护内容或秘密？ | 生成与人工编辑过程、输入来源、相似性复核、合同条款；不能由合同自动消除第三方权利 |
| 对外分发的最终成果 | 即便内部可用，是否另有发布、商用、转载或开源权限？是否违反客户/合作方保密承诺？ | 目标渠道与受众、第三方许可履行、法务/业务放行记录 |

建立**资产台账**：来源 URL 或合同编号、权利主体、获取时间、许可版本、允许的动作（查看、索引、训练、微调、内部引用、商用发布）、地域/期限、删除义务及审批人。第三方开源代码的许可证义务与客户秘密信息的限制应分别记录；SPDX 可规范标识许可证，但标识不证明材料本身取得合法。供应商声称“不用于训练”也不能替代对日志、人工审核、缓存、留存和分包商的数据处理约定。对生成物应记录输入来源和版本、引用、人工编辑与发布审批，而非宣称有了引用就一定满足授权。

## 两种安全示意失效

1. **越目的的内外混用**：有权阅读某合作方未公开方案的员工把它放入通用问答材料库，随后 Agent 给另一团队摘要，团队又复制到公开宣传页。失败链不是模型“记忆”单点问题，而是入库时未记录保密目的、索引未绑定接收人权限、发布出口未复核；即使摘要未逐字照搬，保密义务仍可能相关。示例仅用虚构合作方/文档。
2. **许可链断裂的代码输出**：内部开发助手把某第三方代码片段作为检索示例，生成的代码/说明进入对外产品；台账缺少源文件许可证版本，审查只查到输出文件自身标注“公司所有”。这里存在许可条件、代码实质相似性和合同承诺需要进一步核查，不能靠“模型改写过”推断已无义务。

## 分层控制与边界

- **预防｜入口与用途**：采购、业务和法务确认材料来源及适用许可；按敏感级别分隔训练语料、可检索库与公开语料；未明确许可的材料隔离待核，禁止默认用于微调或外发。Secret/合同材料只在授权项目空间按最小必要摄取；保留许可原文与版本，而非只存一个 `licensed=true`。
- **预防｜运行时与出口**：服务端按发起人、租户、对象 ACL、目的和接收方重新鉴权；检索结果限制引用长度与可见范围，发布/下载由独立出口策略判断；涉密/高相似内容进入人工审批。仅靠提示词“不要泄密”、输出关键词拦截或相似度阈值均可能遗漏改写、表格及语义信息；人工审查也非合法性保证。
- **检测｜证据**：监测跨空间召回、异常批量引用、许可过期材料被复用；记录来源 ID/版本、策略决定、发布审批及接收范围，日志脱敏并限制保留，避免审计本身再造秘密副本。抽样比对输出与授权素材，不以零字面重合证明合规。
- **响应｜隔离与追溯**：暂停相关素材的检索/训练更新/发布，保全必要版本及决策记录，确认衍生物和接收方；按合同和当地法律与法务商定通知、下架、更正或重新授权。删除索引不能保证已生成内容、备份及第三方副本同步消失。

## 非生产负例与误区

在隔离测试租户放入**自造的**“仅甲组内部可见”“限检索不训练”“可公开引用”三种文本，检验乙组检索与导出被拒、训练清单不含限用途样本、许可到期后新任务不可使用、发布时显示来源/许可证缺失并拦截；验证审批通过后仍限制目标接收方。禁止测试真实客户资料或未经授权的第三方全文。误区包括“可在网上读到即可训练”“生成即自动归我”“给出引用便可任意转载”“本地部署便不会泄密”。残余风险是许可随版本变化、生成物来源难以完全归因、语义泄密难被机械检测；出现争议须保留证据而非凭阈值下法律结论。
