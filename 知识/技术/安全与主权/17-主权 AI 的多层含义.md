# 17 “主权 AI”的多层含义

> 范围与时点：2026-10-28 的企业 AI/Agent 教育性分析。各地政策、合同和司法权力随时间与场景变化；“主权 AI”无统一的全球工程验收定义。本章**自拟的控制权矩阵**仅帮助识别实际依赖，不是 NIST 或欧盟法规对“主权”的定义，也不证明任何部署已经合规。

**主权能力**在此指：关键 AI 资产与运行环节上，组织能在约定目的内作出决定、实施限制、获得可核查证据、在依赖失效时继续关键业务并有条件退出。它不是“服务器归我”或“模型由本地厂商提供”的单一属性。还需区分**权属**（资产或合同归谁）、**操作控制**（谁可关停/读取/迁移）、**管辖与披露可能性**（谁可能依何法律程序要求访问），三者不能互推。

## 从端到端数据流逐项问“谁能决定”

```text
员工/客户输入 → 身份/密钥 → Agent 编排 → 模型推理 → 工具调用 → 企业系统
       │                          ↑             │              │
       └→ 日志/遥测/备份      模型与依赖更新      └→ 第三方服务  └→ 审计/恢复
             └──────── 导出格式、密钥撤回、迁移与退出 ────────┘
```

| 维度 | 应追问的控制权与可核查证据 | “本地部署”仍可能遗漏 |
|---|---|---|
| 数据与隐私 | 输入、训练、检索索引、推理缓存、日志、备份分别存在哪里，谁能删？以路径清单、删除回执、抽样和合同核对 | 备份异地、远程支持访问、客户端遥测 |
| 模型与知识资产 | 权重、许可、微调产物、升级与回退谁决定？看许可证、版本签名、替代模型实测 | 权重受限制许可、依赖在线许可校验、知识库无法导出 |
| 算力及基础设施 | 谁采购调度加速器、控制虚拟化/固件、保障电力网络与容量？看运维权和故障演练 | 硬件与驱动供应仍跨境，单地域故障不可恢复 |
| 身份/密钥和运维 | 谁创建最高权限、托管密钥、审批厂商维修？看管理员日志、HSM/密钥策略与断连测试 | 提供商保有恢复通道，特权账号可绕过审批 |
| 审计、法律管辖与生态 | 谁保存证据、响应法律请求、控制标准/接口与导出格式？看协议、分包清单、接口文档 | 审计平台依赖外部服务；本地物理位置不排除其他法域义务 |
| 退出与持续性 | 解约后能否迁移数据、配置、索引和关键流程？看格式、期限、成本和演练结果 | 自建专有 API、工具绑死、删除证明难以获得 |

表中每行还应登记四个问题：**谁拥有决策权、谁有技术执行权、谁可独立验证、依赖失效时多久能恢复？**“企业控制”可能是受合同、代码和外部审计共同约束的控制，并非一定要求自有硬件；反之完全自建也可能在维护链条上缺乏独立性。个人信息、商业秘密和涉监管行业信息的处理要求，必须按具体司法辖区、数据类型、主体角色及当前生效法律另行核对。

## 两种误判及其失败链

1. **本地算力误当全链主权**：推理和向量库存于企业机房，但服务启动会调用远端许可接口，故障日志默认向第三方传送请求片段；外网中断时许可证过期，关键应用停止。物理位置可控却未覆盖许可、遥测和离线连续性；还可能产生隐私与商业秘密风险，需先核真实发送内容而不推断已泄露。
2. **数据留区误当企业自主**：租用单一区域云，合同承诺数据驻留；模型、身份网关及向量数据库都用专有接口，供应商涨价或停供时索引不能直接迁移，重建知识库耗时。数据驻留这个维度可能成立，但替换成本和停止服务时长暴露退出控制不足；不由此推断跨境违法。

## 控制、观察、止损

**预防**：建立含遥测与备份的全链清单，分层标注“自控/合同承诺/仅宣称/未知”；为关键环节设置可替代接口、导出格式与最低离线时间；对远程运维、密钥恢复和子处理者配置审批。**检测**：对照实际 DNS/网络出口、供应商账单及遥测配置核查承诺；记录模型和依赖版本、导出试验成功率、断网时可用时长，关注未经批准的区域与管理员变更。**响应**：暂停未经批准的外发，保全审计证据，切换预演过的替代服务，撤回密钥与令牌，按合同请求导出与删除证明，组织业务核实恢复结果。残余限制包括不可见的底层硬件链、供应商审计不充分、导出后语义差异和法律程序的不可预测性；“零外部依赖”通常不是现实验收条件。

## 非生产验证与负例

- 用合成输入标记请求与遥测，枚举模型调用、嵌入、插件、监控、远程支持及备份出口；对未知域名和内容采取阻断后复核，不发送生产秘密。
- 在隔离环境暂停外网和许可服务，记录 Agent 的读/写分别如何降级、误操作是否被阻断、恢复需要哪些权限。
- 让替代模型在固定虚构工单集上运行，比较引用、工具参数和业务回执；不要把“接口兼容”当作行为等效。
- 导出知识库及权限元数据至另一实现，再删除测试租户、索引、缓存与备份副本；若无法取得可审计删除证据，明确标为未验证。

## 一手资料与边界

- [NIST AI RMF](https://www.nist.gov/itl/ai-risk-management-framework)：风险治理参考，而非主权指标标准。
- [欧盟委员会 Data Act 政策说明](https://digital-strategy.ec.europa.eu/en/policies/data-act)：了解数据使用与服务切换议题；是否适用于具体云/AI 服务及何种义务须以届时法条和合同核实，不能把该页面当“所有模型均可自由迁移”的保证。
- [欧盟委员会数据保护法律框架入口](https://commission.europa.eu/law/law-topic/data-protection/legal-framework-eu-data-protection_en)：有关个人信息适用条件和跨境处理的查询起点，非本章的法律结论。
