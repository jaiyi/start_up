# 领域知识

本目录沉淀已经抽象、相对稳定、可跨项目复用的业务领域知识。

## 与其他目录的边界

- `研究/`：外部公司、产品、行业周期、案例和其他时效性事实。
- `洞察/`：基于研究和经验形成的个人判断、方向和取舍。
- `项目/`：特定项目的设计、实现、测试、部署和运行证据。
- `个人/`：个人经历、简历、面试回答和职业材料。

领域知识正文不应混入特定公司的最新财务、招聘推测或个人面试话术。涉及公司和行业时效信息，应链接到研究目录中的 canonical source，并标明观察日期和证据等级。

## 当前入口

- [半导体领域基础](./半导体/半导体领域基础.md)：产业链、测试、良率、SPC、供应链和数据对象等稳定知识。

## 写作要求

每篇领域知识至少说明：

- 适用范围和读者；
- 核心对象、指标、流程和术语；
- 与已有技术方法的对应关系；
- 来源、更新时间和证据等级；
- 哪些内容仍属于待核实假设；
- 关联研究、项目和个人材料入口。
