# 半导体领域基础

> 适用范围：半导体产业链、测试、良率、供应链和数据应用的通用知识。
> 内容状态：领域知识基础稿；公司实时事实和个人面试表达分别维护在研究、个人目录。

## 1. 产业链和 fabless 边界

```text
设计（Design） → 制造/晶圆代工（Foundry） → 封装测试（Package & Test） → 销售
```

Fabless 公司主要负责芯片架构、设计、验证、产品定义、客户导入和供应链协同；晶圆制造和封装测试通常由外部伙伴完成。因此其数据范围不只包括设计数据，还包括委外制造/测试数据、质量数据、产能数据、库存数据和销售数据。

兆易创新的公司事实、产品组合、长鑫关系和最新经营数据不在本文复制，以 [`研究/公司/11-gigadevice.md`](../../../研究/公司/11-gigadevice.md) 为准。

## 2. 良率 Yield

良率通常表示合格品数与投入总数的比值，是制造成本、质量和产能利用的重要指标。

| 术语 | 含义 |
|---|---|
| Wafer Yield | 一片晶圆上可切出的合格芯片比例 |
| Die | 从晶圆上切下的单颗芯片 |
| CP Yield | 晶圆测试阶段良率 |
| FT Yield | 封装后成品测试阶段良率 |
| Yield Ramp | 新产品量产初期良率逐步提升 |
| FA | Failure Analysis，失效分析和根因定位 |

良率分析通常需要联合批次、机台、测试程序、产品版本、工艺条件和时间窗口，识别不良的聚集、漂移和异常来源。

## 3. 芯片测试数据

芯片流片或封装后会经过多轮测试，每轮测试都产生结构化记录。

| 术语 | 全称/含义 | 数据意义 |
|---|---|---|
| CP | Chip Probing，晶圆测试 | 晶圆切割前的 Die 级测试 |
| FT | Final Test，成品测试 | 封装后的最终测试 |
| WAT/WLT | Wafer Acceptance Test | 晶圆验收和工艺参数测试 |
| ATE | Automated Test Equipment | 自动测试设备，数据产生源头 |
| Bin | 测试后按结果分类的分箱 | 重要的失效和质量分析维度 |
| Bin Map / Wafer Map | 芯片在晶圆空间位置上的分布 | 用于识别边缘、中心和局部聚集 |
| Test Program | 测试程序 | 定义测试项、限制和判定规则 |
| STDF | Standard Test Data Format | 常见的测试数据交换格式 |

Bin 分析可以统计各类结果占比，查看空间聚集，并跟踪不同批次、设备和时间段的漂移。它与通用异常检测中的分桶、趋势和多维归因有相似结构，但具体判定规则仍需由半导体领域专家确认。

## 4. SPC 在半导体场景

半导体质量监控常使用控制图、控制限、过程能力指数和统计判异规则。

| 通用方法 | 半导体场景 |
|---|---|
| Nelson/WECO 判异规则 | 测试参数或工艺参数异常检测 |
| Cp/Cpk/Pp/Ppk | 参数过程能力和稳定性评价 |
| UCL/LCL | 控制图上下控制限 |
| 趋势和漂移检测 | 参数随批次、时间或设备变化 |
| 波形/曲线异常检测 | 测试曲线、信号和过程轨迹分析 |
| PAT | Part Average Testing，识别偏离群体的潜在异常 |
| SBL/DBL | Statistical/Dynamic Bin Limit，针对分箱分布的统计限 |

Cpk 的目标值、抽样方式、分组粒度、控制限更新策略和异常处置需要结合产品、客户和质量规范确认，不能只套用单一行业阈值。

## 5. 供应链和销售数据

存储类半导体具有较强周期性，数据应用通常要同时处理需求、产能、库存、交期、价格和客户导入。

```text
需求变化 → 订单/渠道信号 → 产能与投片计划 → 在制品/裸片/成品库存 → 交付与销售
```

| 术语 | 含义 |
|---|---|
| Sell-in / Sell-through | 卖给渠道 / 渠道卖给终端 |
| Wafer Start | 开始投片 |
| WIP | 在制品 |
| Die Bank | 已测试但未封装的裸片库存 |
| Lead Time | 从下单到交付的周期 |
| Safety Stock | 安全库存 |
| Book-to-Bill | 订单额与出货额的比值 |
| DOI/DIO | 库存覆盖或周转天数 |
| NCNR | 不可取消、不可退的订单 |
| ASP | 平均售价 |
| Design-in / Design-win | 设计导入/客户采用并进入量产 |
| Backlog | 已下单但尚未交付的订单 |
| Product Mix | 产品组合 |

S&OP（Sales and Operations Planning）用于定期对齐销售预测、供应能力、库存和交付计划。数据团队的价值不只是做报表，还要解释预测误差、识别渠道噪声、支撑产能分配和风险决策。

## 6. 数据对象和平台

典型数据对象包括：

- 产品、芯片型号、版本和客户；
- 晶圆、Die、批次、Lot、封装和测试程序；
- 机台、测试站点、供应商和封测厂；
- 测试参数、Bin、Wafer Map、失效记录和 FA 结论；
- 订单、预测、库存、交期、价格和 Design-win；
- 质量事件、纠正措施、复测结果和客户反馈。

典型平台能力包括：

- STDF 等测试数据接入和解析；
- ODS/DWD/DWS 等数据分层；
- Yield Management System；
- Python、SQL、JMP、Spotfire 或 BI 分析；
- 控制图、良率看板、批次追踪和根因分析；
- 数据质量、血缘、版本、权限和审计。

## 7. 与通用工业数据方法的关系

半导体数据分析可以复用许多工业数据方法：

- 用控制图和能力指数识别过程稳定性；
- 用分桶、聚类和趋势发现异常聚集；
- 用批次、机台、产品和测试程序做多维归因；
- 用供应链预警、需求预测和库存模型支撑 S&OP；
- 用数据血缘、版本和权限保证分析可追溯。

但方法可迁移不等于业务结论可直接迁移。测试规范、产品等级、客户质量协议、工艺窗口和失效机理必须由领域证据和专家确认。
