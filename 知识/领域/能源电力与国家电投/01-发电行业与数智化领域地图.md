# 01｜发电行业与数智化领域地图

> 适用范围：发电集团的业务、数字化场景及与工业 AI 的连接。内容状态：领域知识整理，不代表国家电投的某个项目已经取得效果。更新：2026-10-19。

## 1. 发电集团在哪一段

```text
能源开发/燃料 → 发电与储能 → 输配电和系统调度 → 售电与工商业/居民用电
                       ↘  电力交易、辅助服务、需求响应、综合能源服务  ↗
```

发电集团经营电源和能源项目，关注开发、投资、建设、运营、安全和售电收益；电网企业承担输配电、系统运行与供电服务等职责。发电集团可以开展功率预测、交易辅助、场站监测、储能聚合等数智化工作，但**自有平台不等于拥有电网调度权**。一个“智慧场站”可能是设备监控、远程集控、预测、巡检或检修闭环的不同组合，面试时需要问具体系统和权限。

上游与横向参与方包括风机/逆变器/火电设备厂商、信息通信和云厂商、工业软件商、电力交易机构、地方能源企业。集团数科公司一般站在“跨场站数据、集团共性平台、系统交付与安全”层，能否对外销售产品，需按具体主体和合同核实。

## 2. 为什么新能源让数字化变成经营问题

风光出力受气象和时间影响，储能与可调节负荷带来更多运行与交易选择。数字能力因此由“采集、展示”扩展为“预测—计划—执行—结算—复盘”。但要区分**模型指标**、**业务指标**和**安全指标**：预测误差降低，不必然转化为电量收益；工单减少，也不必然代表设备可靠性提高。

| 业务场景 | 常见核心对象和数据 | 可供讨论的效果指标（具体口径待项目核实） |
|---|---|---|
| 新能源开发/工程 | 风光资源、土地与位置、设计、项目进度、投资 | 项目周期、可发电量、投资偏差、度电成本 |
| 功率预测与场站运营 | 气象、风机/逆变器、功率、限电、故障与工况 | 预测误差、设备可利用率、弃电、实际收益 |
| 设备运维 | 测点、告警、检修工单、故障、备件 | 非计划停机、误报与漏报、故障提前量、维修成本 |
| 火电及灵活性改造 | 燃料、机组工况、排放、启停、调峰任务 | 煤耗、调节性能、排放与安全指标 |
| 储能/用户侧综合能源 | 电池状态、荷电状态、负荷、电价、用能设备 | 系统效率、寿命损耗、调节收益、用能成本 |
| 集团经营与采购 | 主数据、项目、资产、财务、供应商、交易合同 | 资金占用、采购效率、结算偏差、审计可追溯性 |

这些是**分析用候选指标**，不是某家公司已公布的收益或性能。核电和工业控制场景还需要更严格的安全授权，不能把面向知识工作的生成式 AI 直接等同于可自主控制机组的系统。

## 3. 通用数据链条及名词

```text
资产与设备台账 → 现场传感器 / SCADA / DCS / 天气与交易数据
              → 数据采集、时钟对齐、质量校验、资产编码映射
              → 分析与预测 / 业务知识库 / 智能体
              → 告警、工单、计划、人工复核及业务结算
              → 实际效果评估、持续优化与跨场站推广
```

- **SCADA**：监控与数据采集，常见于远程监控。**DCS**：分散控制系统，多见于连续过程/电厂控制；两者场景和控制权限不同。
- **场站/机组/设备/测点**：发电侧数据的主要层级。测点规模大不等于可用数据多，必须检查采样频率、缺测、单位、资产映射、检修停机与工况区分。
- **功率预测/负荷预测**：发电和消费端的不同预测任务。模型误差与商业收益之间通常还要经过计划、交易规则、调度和结算。
- **集控/少人值守**：将不同场站监控和部分作业集中化；不是“无人值守”的同义词，现场安全作业与责任边界不可省略。
- **虚拟电厂/综合智慧能源**：聚合分布式电源、储能和可调负荷以提供运行优化或市场服务，具体能做什么受区域规则、接入标准与合同约束。

## 4. 工业 AI 能迁移什么，不能迁移什么

可迁移的方法：异常检测、时序建模、图像识别、检修知识检索、语义建模、数据治理、业务价值量化与多站点产品化。典型落地顺序是**定义现场痛点 → 获取合规数据 → 建立标注及评测 → 与现有规程对照 → 专家复核 → 接入工单/经营流程 → 验证增量收益**。

不能直接迁移的结论：煤电/风光/储能/核电设备机理、当地电力市场规则、保护和控制权限、安全分级、现场作业规范。避免将“演示了 AI 助手”表述成“已替代调度员或现场专家”。
