## 证据规则

- **E1：官方直接资料**：集团/公司官网、监管机构正式文件、采购公告原文。官网报道支持“其公开宣称/报道了某事”，不自动证明财务回报或行业领先。
- **E2：权威二手资料**：可核对的行业报告、媒体报道；应与官方资料交叉验证。
- **E3：弱证据**：第三方招标转载、招聘平台、行业讨论等，只作为线索，不作为公告原文。
- **E4：研究判断**：基于公开材料的推论和候选问题，均明确标注“分析”或“待核实”。

文中**发布日期**是原页面标注的日期，**观察日期**是复核网页的日期；官网无发布日期时直接标明“未标注”。含项目的表格只写查到公告原文且能辨识项目主体的条目，不能用“找不到”推论“没有项目”。

## 边界与历史资料

- 本专题按读者的面试目标集中放在 `知识/领域/`；其中 `02`—`04` 是**带时间戳的研究快照**，并非不变的领域知识。不要将其复写成无日期的“公司事实”。
- 仓库已有[2026 年 9 月电投数科本部岗位匹配分析](../../../研究/公司/16-spic-digital.md)，其中招聘 Excel 的原件未在当前环境找到，薪资/职级/工作强度等推断**不作为本专题已核实结论**；实际岗位须以新的 JD 或 HR 信息确认为准。
- 招采追踪的观察窗口是一年，并非集团及全部二级单位的全部项目；官方采购平台公开页为动态加载，本专题如没有逐条原始公告，将明确留空，而不把转载当原文。
