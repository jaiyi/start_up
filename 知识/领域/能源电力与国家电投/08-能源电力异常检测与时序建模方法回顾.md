# 能源电力场景的异常检测与时序建模：方法、用法与避坑

> **定位**：复习手册，而不是模型排行榜。先明确业务动作、预测时点与可用数据，再选最简单可用的基线；复杂模型只有在按时间回测、按场站/工况验证后确实增益时才升级。下文侧重发电、设备运维和负荷侧；相关业务场景先看[01 发电行业与数智化领域地图](./01-发电行业与数智化领域地图.md)。电网保护与调度必须遵循相应安全规程，模型告警不能直接替代保护定值或人工决策。

## 1. 先分清任务，再谈模型

| 问题 | 输出 | 电力场景举例 | 常见混淆 |
| --- | --- | --- | --- |
| 异常检测 | 某时刻/时间窗的异常分数或告警 | 逆变器效率骤降、风机轴承温升异常、计量突变 | 异常不等于故障；限电、检修、启停也可能“异常” |
| 变化点检测 | 系统分布或水平从何时开始改变 | 换热效率逐步下降、传感器校准后漂移 | 与单点尖峰不同，需判断变化是否持续 |
| 时序预测 | 未来一段时间的点值/区间/分位数 | 次日每 15 分钟负荷、风光出力、设备温度 | 预测残差也能用于异常检测，但预测本身不是故障诊断 |
| 故障诊断/定位 | 故障类型、部件及证据 | 风机齿轮箱异常 vs 传感器故障 | 仅凭异常分数通常不能确定原因 |
| 剩余寿命/RUL | 距离失效或维修窗口的时间分布 | 轴承退化、储能电池健康度 | 缺少失效样本时不能把趋势外推称为可靠的 RUL |

**先写清一个任务契约**：监控对象（机组、逆变器、变压器、馈线、计量点）→ 采样间隔和预测时点 → 提前量/预测跨度 → 允许使用的数据 → 输出粒度 → 谁收到告警/如何处置 → 漏报与误报代价。例如“每天 08:00，使用截至 08:00 的实测负荷和当时已发布的天气预报，预测未来 24 小时逐 15 分钟负荷”，比“做负荷预测”更可实现、可验收；若目标是**次日自然日**，则是另一个预测区间（见 4.1），不能混用评估口径。

### 数据与业务约束

- **来源与频率**：SCADA/EMS/DCS 采样与汇总、PMU 同步相量、智能电表/AMI、振动波形、检修工单、气象实测与数值天气预报（NWP）、电价/调度指令。不同来源的时间戳、延迟和缺测机制不一样；不要在未对齐时直接拼接。
- **工况和物理边界**：风速—风机功率曲线、辐照—光伏出力、环境温度—负荷、机组启停/爬坡、限电、容量变化、设备更换都会改变“正常”的定义。应按设备交流侧/并网点容量及计量口径设出力边界（不能把组件直流装机容量当交流出力上限），光伏夜间零出力并不是模型发现的异常。
- **层级与空间关系**：测点→设备→场站→区域，馈线/母线/变电站有拓扑关系；总量通常应与下级可用计量口径一致，考虑网损、自用电和计量延迟，不能硬性假设完全相等。
- **事件标签并不天然可靠**：告警码可能是结果不是原因；工单的创建时间不等于故障起点，维修完成后设备与传感器的基线也可能改变。

## 2. 异常检测：由简到繁

设观测值为 \(x_t\)，可用的上下文为 \(c_t\)（工况、时刻、天气等），模型输出异常分数 \(s_t\)。部署时还需要告警阈值、连续触发时间、去重及处理流程；**分数高 ≠ 必然发生故障**。

| 方法 | 核心原理与简化用法 | 更适合的场景 | 主要避坑 |
| --- | --- | --- | --- |
| 业务/物理规则 | 对上下限、变化率、跨测点一致性设规则；按工况设阈值并加滞回、持续时间 | 电压/温度越界、功率不可能值、计量守恒 | 固定阈值跨季节/负载误报；规则不能代替传感器质量核验 |
| 稳健统计与滑动窗口 | \(m=\operatorname{median}(x)\)，\(\sigma_\mathrm{robust}\approx1.4826\operatorname{MAD}(x)\)（近似正态且 MAD 为未缩放的中位绝对偏差时），\(s_t=\lvert x_t-m\rvert/(\sigma_\mathrm{robust}+\epsilon)\)；按同一工况/时段建正常基线 | 单测点尖峰、离群值、水平偏移 | 当前点混进基线或异常污染滑窗会掩盖问题；MAD≈0 时需业务兜底 |
| 季节分解 + 残差 | STL 等将时序拆成趋势、季节项和残差，对残差做稳健阈值或变化检测 | 有稳定日/周季节性的负荷、能耗 | 节假日、天气突变、启停/限电不在普通季节项中；分解窗口不能使用未来观测去模拟实时效果 |
| 过程控制/变化检测 | EWMA 平滑微小变化；对已做工况校正的残差做单侧上升 CUSUM：\(g_t=\max(0,g_{t-1}+r_t-k)\)，\(g_t>h\) 报警；下降变化另建一侧；Page–Hinkley 等检测均值改变 | 效率缓慢下降、长期传感器漂移 | 自相关、工况切换会破坏独立同分布假设；\(k,h\) 需用历史回放标定；离线变点定位不等于在线告警 |
| 多变量统计：PCA | 从正常数据学相关结构，监测主成分空间 \(T^2\) 和重建残差 SPE/Q | 多传感器间关联变化（温度、压力、流量） | 模式不同、非线性强时全局 PCA 易误报；只用训练集估计均值/方差，主成分贡献不等于因果解释 |
| Isolation Forest | 随机切分特征空间，容易被较短路径隔离的点分数更高 | 已有窗口统计/上下文特征、异常标签很少 | 时间顺序不是树自动理解的；必须显式构造滞后/工况特征，阈值不要照搬默认值 |
| LOF / One-Class SVM | LOF 比较邻域密度；One-Class SVM 学正常区域边界 | 中小样本、正常数据边界较清晰 | LOF 新数据推断与训练内评分的使用方式不同；距离方法怕量纲、高维和工况混杂；核方法大规模代价高 |
| 时频特征 + 基线 | 从高频振动/电流波形提取 RMS、峰度、FFT/包络谱的特征频带或小波能量，再按转速/负载分层设阈值或接分类器 | 旋转机械轴承、齿轮箱、电机电流异常 | 采样频率与测点安装影响可见频段；变转速导致谱线移动，混叠和有限窗长产生的频谱泄漏会造假峰，不能把低频 SCADA 当高频振动信号 |
| Matrix Profile | 为各固定长度子序列寻找最近的非重叠相似片段；距离大的“discord”提示形状异常 | 振动/曲线波形、重复工作周期中的新形态 | 窗长决定能看到的事件；按同工况比较，避免把季节转换或大量重复故障当正常 |
| 预测残差 | 先预测 \(\hat x_t\) 或条件分位数，再监测 \(r_t=x_t-\hat x_t\) 是否超出按工况校准的区间 | 同样数值在不同天气/负载下含义不同；风光和设备温度 | 预测失败、输入天气预报误差也会触发；要区分设备异常与上游预测误差 |
| 自编码器 / LSTM-AE / VAE | 学正常窗口压缩与重建；重建误差大的窗口告警 | 高维非线性、多测点序列、足够长的正常历史 | 模型可能同样重建异常；窗口重叠、训练污染、工况偏移、解释困难；VAE 概率分数也需校准 |
| 有标签分类：逻辑回归/随机森林/GBDT | 把经确认的故障与正常时段做监督学习，输出故障概率和分类 | 有较可靠工单标签，需定位已知故障 | 类别极不均衡、维修后样本泄漏、标签延迟；分类器对未见过的新型故障没有保障 |
| 物理残差 / 状态估计 | 用功率平衡、性能曲线、状态估计或机理模型给定合理区间；观测与期望不符则告警；电网状态估计中的加权最小二乘残差可辅助坏数据识别 | 光伏组串对标、热力系统、网络量测一致性 | 模型参数会随老化与工况变化；需核实可观测性与量测误差，异常残差不能直接区分设备故障与传感器故障，协调一致的坏数据也可能逃过简单残差检验 |
| 图/时空模型 | 将设备连接、空间邻近和时间动态建模，找局部与关联异常 | 明确拓扑的馈线、站内设备群；多场站共性模式 | 拓扑变化、缺测和训练成本较高；先验证简洁的邻站/同类设备对标是否已足够 |

**如何选**：先做数据质量标记和物理规则，再加按工况分组的稳健基线；具有强季节性时用“预测 + 残差”；多传感器耦合时再比较 PCA、树模型和时序网络；有高质量故障标签时用分类器辅助诊断，同时保留未知异常通道。对于风光场站，可把“气象/限电已解释的低出力”和“无法解释的低出力”分开，不要把调度动作送成设备故障告警。

**阈值不是模型附属品**：用时间上靠后的、未参与拟合的验证集调阈值；评估每日/每台设备误报量、事件级召回、提前量和平均处理时长。采用连续 \(n\) 点触发、恢复滞回、冷却期和告警合并，往往比把 AUC 提高一点更有现场价值。

**把残差法走一遍**：假设用正常工况数据拟合变压器温度的条件预测模型 \(\hat x_t=f(\text{负载、环境温度、运行模式})\)。在线取 \(r_t=x_t-\hat x_t\)，用独立验证期的同工况残差确定上侧阈值 \(u\)；连续 3 个采样点满足 \(r_t>u\) 才报警，低于恢复阈值后解除。若想抓缓慢升温，可改用上表的 CUSUM 累积 \(r_t\)；负向异常需另设下侧判据。回放时检查每台设备每月告警数、故障前首次触发时间，并用气温/负载突变案例检验误报；阈值切勿拿测试集反复调到“好看”。

## 3. 时序建模：从预测基线到复杂模型

在时点 \(t\)，用截至此时真正可用的历史 \(x_{\leq t}\)、未来已知信息 \(z_{t+1:t+H}\) 和静态信息（场站、容量）预测 \(x_{t+1:t+H}\)。**未来天气只能用当时发布的预报版本，不能用后来才知道的天气实况**。

| 模型/方法 | 核心原理 | 典型用法 | 局限与避坑 |
| --- | --- | --- | --- |
| 持续值/季节性朴素法 | 未来等于发布时点的最近已知值，或目标时点上一周/昨日同刻的**已知**值 | 所有项目先做基线；检验复杂模型是否真有增益 | 长提前量下“昨日同刻”可能还没发生，须检查目标对应历史值在发布时点是否可用；突变、节假日、天气变化时欠拟合 |
| 移动平均、指数平滑 ETS/Holt-Winters | 更新水平、趋势、季节状态，对近期观测赋更大权重 | 稳定日/周周期的负荷、消耗量 | 天气驱动和限电等外因难靠单变量自适应；趋势不宜长期无限外推 |
| STL + 回归/预测 | 先分离季节和趋势，再建模残差或解释变量；多重季节性可比较 Fourier 日历特征 + 回归、MSTL/TBATS | 多重周期负荷、观察长期变化 | 分解/平滑边界和回测时点必须对齐；不要全量分解后再回测 |
| ARIMA/SARIMA/SARIMAX | 用差分处理非平稳，再以自回归和移动平均描述相关性；X 表示外生变量 | 数据量不大、周期稳定、需要可解释统计基线 | \((p,d,q)(P,D,Q)_s\) 随周期扩张后计算繁重；天气等未来外生量必须可预测，差分也不能解决工况突变 |
| 状态空间/卡尔曼滤波 | 隐状态随时间转移，观测有噪声；逐步更新水平、趋势或设备状态 | 缺测/噪声下平滑、在线状态估计和预测 | 经典线性高斯版只是起点；错误的噪声假设或参数使区间过窄，平滑器用到未来数据不可冒充在线滤波器 |
| 回归 / GAM / GBDT（XGBoost、LightGBM 等） | 用滞后、滚动统计、日历、天气、价格/生产计划等特征预测目标；GAM 可表达平滑非线性 | 负荷、风光功率、设备健康指标的常用强基线 | 滚动统计需先按发布时点截断，目标时点滞后特征也要检查可用性；未来特征要可用，树模型通常不擅长超出训练范围的趋势外推 |
| LSTM/GRU、TCN | 循环门控或因果扩张卷积捕捉序列依赖；可多步直接预测 | 大规模多变量/多设备联合建模、复杂时滞 | 数据需求、调参和部署成本高；递归式多步预测会累积误差，直接多输出也可能随跨度增大退化；不能因“深度”自动胜过 GBDT |
| Transformer 系列（如 TFT、PatchTST） | 注意力建模跨时间/变量依赖；具体架构区分未来已知协变量、静态特征或序列分块 | 多场站多变量、较长上下文/多步预测，有充分历史与算力 | 不同模型对未来协变量支持不同；注意力权重不是因果解释；小数据易过拟合，需同口径比较简单基线 |
| N-BEATS / N-HiTS 等 | 以神经网络块分解并多步输出趋势/季节等信息 | 多序列、直接多步预测 | 需要针对数据尺度、序列数量和预测跨度实验；不自动理解物理边界 |
| 概率/分位数预测 | 预测 \(q_{0.1},q_{0.5},q_{0.9}\) 或分布；用 pinball loss/概率评分优化 | 风光不确定性、备用容量、风险控制 | 分位数覆盖率要在风速区间、季节、启停工况分别核验；分位数交叉须修正，多时段联合风险还需检验时序相关性 |
| 层级/空间预测 | 同时预测设备、场站、区域，再做层级协调；或利用邻站/拓扑信息 | 场站集群功率、负荷层级汇总 | 对齐容量、计量口径和拓扑变更；一致性约束不代表各层级都更准 |

**多步策略**：递归法用上一步预测当下一步输入，简单但误差可能累积；直接法为每个跨度单独建模，成本更高；多输出法一次预测整段。按实际需求比较 \(H\) 个时点的逐步误差，而不是只看平均。对于风光，通常需要结合 NWP 的发布时间、预报提前量和设备可用容量，评估“真实可发功率”与“实际受限出力”两个目标是否需分开。

**把预测法走一遍**：以前一日 08:00 发布次日逐 15 分钟负荷为例，训练样本的一行对应一个“发布时点 × 预测目标时点”，标签为该目标时点实测负荷。特征只能来自发布时点前已入库的负荷、日历，以及当时可取得的目标时点天气预报；用发布时点最近值/目标时点上周同刻的朴素法作基线，再训练按预测跨度建模的 GBDT 或多输出模型。依月滚动回测后计算各跨度 MAE，另查日峰值误差；若需要上下风险边界，用分位数模型并检查留出期覆盖率。训练时基于历史标签构造的“目标时点昨日同刻负荷”只有在该时点早于发布时点时才可用，长提前量不能照搬短提前量的特征。


**模型不是必须从零训练**：样本稀少时可对比成熟时序预训练模型/迁移学习，但发布时点约束、缺测、单位口径、概率校准仍需本地回测；不能因为模型泛化宣传就略去业务基线。

## 4. 四个完整场景，串起“模型—动作”

### 4.1 次日负荷预测（计划与调度辅助）

1. 每天 08:00 发起预测，目标是**次日 00:00—24:00** 的 96 个 15 分钟负荷值；明确节假日、需求响应、大用户生产计划是否在前一日 08:00 已知，并在回测时保持相同提前量。
2. 建立上周同刻值（若在发布时点前可用）、ETS/SARIMAX 基线；再试 GBDT：截至发布时点的滞后与滚动负荷、时段/星期、当时版本的未来逐时气温预报；长历史多序列可试全局深度模型。注意“次日某时刻的昨日同刻负荷”可能落在当天 08:00 之后，此时尚未观测到，不能直接使用。
3. 滚动回测按月份/季节/气温段以及峰值时段比较 MAE、峰值误差和分位数覆盖率；异常节假日单独看，避免总体均值掩盖关键错误。
4. 预测值进入计划参考而非自动控制；天气预报失效时降级到历史同类日/保守区间，并标注数据来源和置信度。

### 4.2 风电/光伏低出力异常（状态监测）

1. 同一时段汇总 NWP/实测风速、辐照、温度、可用容量、限电指令、启停状态及相邻同类型设备；标注夜间、低风速和停机，避免低出力误报。
2. 用功率曲线或 GBDT/分位数模型估计**当前工况下**应有出力；低于下分位的残差经持续时间和邻机对标后告警。
3. 先排除天气预报偏差、积灰/遮挡、逆变器限额、叶片结冰、检修和调度限电，再进入故障排查；单靠出力偏低无法定位根因。
4. 验证时把不同季节与风速/辐照区间分开，关注每百台设备每天的误报和真实损失电量；若模型用同时刻**实测**气象，只能作事后/当前诊断，不能宣称具备同等效果的提前预测。

### 4.3 风机轴承/变压器温度缓变（预测性维护）

1. 先核验测点跳变、采样缺口、传感器更换；按负载、电流、环境温度和运行模式建立正常温度或振动特征基线。
2. 用预测残差 + EWMA/CUSUM 提取持续漂移，必要时加入振动频域特征、PCA 或自编码器；以工单与实际维修时间窗口核对，不要直接拿告警码当故障标签。
3. 告警先给出相关测点、残差趋势和运行工况，转运维复核；RUL 需有足够失效与删失样本，否则只报告“异常趋势/优先检修级别”。
4. 用事件级命中率、首次提前量和误报/设备月评价，拆分训练/测试要按时间且检查设备/场站外推能力。

### 4.4 计量异常与电量平衡（数据治理/排查）

1. 明确发电量、上网量、厂用电、储能充放电、计量损耗的口径与时区；先做增量/累计表码辨识、复位/回卷检测和延迟对齐。
2. 物理平衡规则查不可能值；同类计量点比较、稳健统计和变化点检测查长期漂移；逐项追溯倍率、CT/PT 变更及工单。
3. 计量不平衡提示复核，不等于认定窃电或设备问题；以核查结论补标，误差容忍区间按计量精度和实际网损设置。

## 5. 可复用的实施与评估清单

### 5.1 数据切分和防泄漏（优先级最高）

- **时间切分**：训练 → 验证/阈值校准 → 最终测试，严格按时间先后；滚动起点回测（rolling-origin）模拟每次真实发布时间。大量重叠窗口会让随机划分泄漏近乎相同的样本。
- **按“当时已知”重放**：天气预报按发布版本、调度/检修计划按生效与获知时间、设备元数据按当时配置建特征；对批处理延迟留出可用性间隔。滚动统计只计算发布时点前的数据；预测目标或故障标签的未来片段不能进入插值或归一化。
- **新设备/新场站泛化**：时间外测试之外，必要时另做设备/场站留出；同一机组前后样本不是跨机组验证。容量升级、设备替换、传感器更换应记录为工况切换。
- **缺失和异常分开**：缺测、通信中断、异常平线、坏点、真实零值分别标记。长时缺失不应插值成“正常”，否则模型会学到伪模式。

### 5.2 指标选到业务层

| 任务 | 推荐看什么 | 容易误读的指标 |
| --- | --- | --- |
| 点预测 | MAE/RMSE、逐预测跨度误差；必要时按额定容量归一化 nMAE | MAPE 在光伏夜间/零负荷附近会发散；WAPE 在测试集总量小或跨集合比较时也不稳 |
| 概率预测 | 各分位数 pinball loss、区间覆盖率与宽度、按工况的校准情况 | 只看覆盖率会鼓励过宽区间；总体覆盖良好仍可能漏掉极端天气 |
| 有标签异常检测 | PR-AUC、指定告警预算下 precision/recall；**按故障事件合并**后的召回与首次告警提前量 | 类别极不均衡时 ROC-AUC 可能看起来很高但告警不可用；逐点 F1 对长事件偏置；PR-AUC 也随正例比例变化 |
| 弱标签/无标签异常检测 | 回放典型案例、人工抽检、误报/设备月、告警处理耗时、损失电量/故障损失 | 无可靠真值时不能声称“准确率 99%”；异常分数不是故障概率 |

### 5.3 上线与退化管理

1. 先做数据质量/物理规则兜底；记录模型版本、特征快照、气象预报版本、阈值、告警解释及处置结果。
2. 离线回测 → 影子运行（不触发业务动作）→ 人工复核小范围试点 → 分层告警；安全联锁、保护动作保持独立。
3. 监控输入分布、误报量、分组误差、预测区间覆盖与报警耗时；定期重新标注工单，但**不要未经复核将所有近期数据自动当作“正常”重训**。
4. 准备降级：天气/遥测缺失、拓扑变化、容量更新或模型服务失败时切换明确的业务规则与朴素基线，保留人工处理入口。

## 6. 快速选型和口头复习

- **有明确物理约束** → 先规则/平衡/状态估计；**周期稳定的单变量** → 季节性朴素、ETS/SARIMA；**外生变量强** → GAM/GBDT + 可用的天气/工况；**多测点耦合且标签少** → PCA/Isolation Forest/预测残差；**复杂形态或跨设备海量历史** → 对比 TCN/LSTM/Transformer/图模型。
- **急性尖峰** → 稳健阈值；**慢性漂移** → EWMA/CUSUM/变化点；**形状异常** → Matrix Profile/序列编码器；**已知故障类型** → 有标签分类；**需提前预警** → 预测/健康指标，但区分提前预警与事后解释。储能还应区分 SOC（荷电状态）、SOH（健康状态）与 RUL（剩余寿命）：SOC 估计常用库仑计量配合等效电路/滤波校正，SOH/RUL 要面对充放电制度、温度和容量衰减的变化，不宜只把静置电压异常当寿命结论。
- 回答“为什么这么选”：先给出预测/检测时点和允许特征，再给业务基线、时间回测、误报预算、工况分层和处置闭环；不要先说网络层数。
- 回答“模型预测准但告警差”：看阈值与持续时间、事件级评估、故障前兆的提前量、限电/检修过滤、传感器质量与标注延迟；预测 MAE 低不保证异常可分。
- 回答“最危险的坑”：**用未来天气实况/全量平滑/随机窗口切分造成泄漏**；把停机限电当故障；把所有告警当真值；只在总体指标上比较而不看场站、季节、极端工况和告警量。
