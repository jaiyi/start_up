# 08｜企业身份与委托授权

> 观察日期：2026-10-28。范围：企业内用户借助 Agent、后台服务、插件和 Runner 访问租户、空间及对象；读者：IAM、平台、安全、后端和产品。内容为工程学习，不是 OAuth 配置模板或合规认证；真实实现须验证身份提供者、业务权限源与令牌生命周期。

## 把“谁在行动”分成三层

**主体**：人、Agent 工作负载、服务账号或第三方工具；**发起者/代理者**：用户提出目标，Agent/服务实际调用 API，二者不能用同一个名字取代；**授权**：主体、租户、资源对象、动作、目的、时间、环境及批准记录的交集。身份认证证明“可能是谁”，不是资源授权。**委托**是在既有权限内为受限任务授予执行权，不应靠复制用户长期令牌实现；**服务账号**适合机器身份，却不自动继承用户的对象权限。OAuth 令牌的 scope 是一维限制，不代替原件 ACL、组织职能分离及实时状态检查。

```text
用户会话 → 任务授权（目的/时限/范围） → Agent/Runner 的工作负载身份
                     │                         │
                     └────委托链/批准 ID ───────┤
                                                ↓
工具网关：验证签发者/受众/到期/撤权 → 取用户与租户上下文 → 服务端资源 ACL
                                                ↓
                                  仅允许该动作 → 数据源/业务 API → 回执
```

典型判定：用户是否仍有权访问对象？工作负载是否允许该工具？scope 和受众是否覆盖此资源？目标属于哪个租户/空间？本次目的与批准是否有效？若任何一项未知，高风险动作拒绝并要求重新授权。RFC 8693 定义可用于委托/模拟场景的令牌交换协议，但不是要求所有 Agent 使用此协议；是否换取新令牌以及委托链怎样编码取决于系统设计。若 MCP 服务经 OAuth 受保护，需按协议版本核对授权服务器元数据、资源受众及服务端校验；不能把工具描述或模型话语当授权票据。

## 两种安全示意失效

1. **共用服务账号遮蔽个人权限**：甲组员工只能看自造的甲组周报，却让 Agent 借全局读取服务账号检索到乙组周报；回答只展示摘要，审计只见服务账号。故障在资源 API 没校验终端用户和对象 ACL；是否逐字输出与越权是否成立不是同一个问题。
2. **离岗后长任务续跑**：已批准的自造报表导出任务进入队列，用户在执行前被移出项目，但 Runner 保留先前长期令牌继续处理。队列提交时曾合法，不代表执行时仍合法；Token 未过期也不代表用户权限未撤销。涉及重试及长任务时应与第 10 章联动。

## 分层控制、检测与响应

- **预防｜签发与任务**：企业 IdP 为人和工作负载分别建身份；短时、受众绑定且最小 scope 的凭据，密钥不进入 Prompt、日志或工具描述；委托凭证绑定发起者、代理者、任务、租户、动作和期限。高风险操作批准记录应可撤销、不得复用为更广泛权限；令牌交换不自动保证接收系统按目的执行。
- **预防｜服务端执行**：网关验证凭据有效性和工具准入，资源 API 再校验当前用户/对象 ACL、租户和动作；子代理取权限**交集**而非继承超级账号。对第三方接口做受众隔离，不把内部令牌直接传给不受信任服务；UI 隐藏按钮不是访问控制，Agent 自称获准也无效。缓存授权结果需设短生命周期并处理撤权事件。
- **检测｜可审计身份链**：记录用户 ID、Agent/Runner ID、租户、任务/批准 ID、令牌标识摘要、资源与动作、授权决定、执行回执（不记录令牌明文）；监测跨租户拒绝、异常代理链及被撤销主体继续调用。审计数据自身严格授权和最小化留存。
- **响应｜立即止损**：禁用会话/工作负载凭据并撤销可撤销令牌，暂停队列及后续重试，回查既成读写的范围、结果和通知义务。RFC 7009 提供令牌撤销协议，但资源端本地校验、缓存及离线令牌可能存在传播延迟；必要时在资源端强制查状态/阻断任务。

## 非生产负例与误区

用合成甲乙租户和假用户：令甲组用户通过 Agent 请求乙组对象，须在资源服务拒绝；移除甲组用户权限后，已排队未执行任务须重新核权失败；把仅供资源 A 的令牌交给模拟资源 B，须拒绝受众不匹配；子代理持合法任务但请求超范围动作须失败；人工撤销后检查运行中任务、缓存和审计记录。测试不使用真实令牌或生产资源。误区：“服务账号有权等于用户有权”“scope=read 足以定义可读对象”“批准一次便可无限重试”“令牌短时即自动解决撤权”。残余风险包括 IdP 同步延迟、第三方接口缺细粒度权限、离线任务已完成的不可逆结果；必须以实际资源端拒绝证据验证。
