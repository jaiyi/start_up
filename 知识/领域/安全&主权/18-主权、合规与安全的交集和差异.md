# 18 主权、合规与安全的交集和差异

> 范围与时点：截至 2026-10-28 的防御性分析，适用于企业模型、RAG、Agent 及工具选型。这里将“主权”操作化为可验证的控制与替代能力；并非一个适用于所有国家的法律定义。涉及个人信息、跨境、行业规则、合同及欧盟 AI 法规的结论，必须以适用司法辖区、角色、用途和生效版本另行核验；本章不是法律意见。

**安全**关注保密性、完整性、可用性及可控可审计的业务后果；**合规**是依据具体法律、合同和内部承诺，证明适用义务被履行；**主权能力**关注谁能决定数据、模型、密钥、运维、审计和退出。三者会相互影响却互不蕴含：满足某条数据驻留要求不证明工具不会越权；安全的密钥管理不自动消除跨境个人信息义务；可替换模型的企业也可能留存超期日志。

## 按用途判断而不是按口号打勾

以下是**本章原创的“三问加证据”判别矩阵**，不是 NIST 或欧盟法规规定的评估标准。对同一具体数据与动作逐格填“是/否/未知”并记录证据，未知不能当符合。

| 方案场景 | 控制/主权问题 | 安全问题 | 合规问题及待查材料 |
|---|---|---|---|
| 单机房私有模型辅助起草（不写业务库） | 模型、日志、备份与离线许可是否自控；能否换模型 | 内部账号能否跨部门读材料；检索结果会否指挥工具 | 原始材料的目的、保留、权属、保密义务由谁核 |
| 单一区域托管模型 + 企业工具网关 | 数据与遥测、密钥、供应商停服时退出路径 | 网关是否逐次校验对象 ACL、拦截伪造工具结果 | 数据类别、实际传输地区、处理者角色和合同义务须逐项查 |
| 多区域混合部署与外部检索 | 模型选择权、索引迁移和分包链 | 外部片段是否被当指令；网络出口有无限权 | 各阶段个人信息、跨境、留存和地域承诺分别审查 |

```text
资料/用户请求（类别、目的、地区） → RAG/Prompt（是否含敏感内容）
      → 模型/外部处理者（位置、留存、管理访问） → Agent 动作（授权和审批）
      → 工具业务回执 → 日志/备份/删除（责任、期限）
       ├─ 安全检验：每个边界是否限权并可检测
       ├─ 合规检验：具体适用义务是否被满足且有证据
       └─ 主权检验：控制权、独立性和退出权是否可实证
```

## 两个彼此独立的失败案例

1. **“私有部署，所以安全合规”**：财务 Agent 在内网以共享管理员身份接查询与付款工具，检索页里出现伪装成指令的审批信息；应用只做自然语言确认，后台没有逐笔审批，最终可能产生错误支付。未出境不能保护动作完整性，也不能替代真实授权；数据保留或个人信息处理是否合法更不能据此下结论。防护应落在交易系统的权限和回执，而不是提示词。
2. **“调用境外供应商，所以一定泄密违法”**：某方案仅把不可识别的合成样本发给外部推理服务，生产敏感数据留在受控系统，网关禁止外发并有审计。跨境调用这一事实并不能单独推断泄密或违法；若后续改用真实用户内容、日志外发或转包，则必须重新开展实际数据流和法律核对。安全证明依赖边界测试，不依赖“外部服务天然安全”的反向断言。

## 可操作的分层控制与局限

**预防**：数据所有者分类和最小化输入，法务/隐私逐用途核适用规则及供应商条款；系统侧用独立身份、对象 ACL、短期令牌、出站白名单、交易确认、密钥隔离和版本化资产清单；对关键模型与数据定义迁移接口。**检测**：关联用户请求、检索源、推理区域、实际网络目的地、权限决策、审批和工具回执；比较合同声称与遥测/配置；监视越权拒绝、异常下载及未经批准的地区/版本变化。**响应**：封停工具和令牌、停止有争议的外发路径、保存最小必要证据、核定真实影响并由法务判断告知与监管要求，修复后做负例回归。数据脱敏可能被重新识别，合同审计不等于底层可见，禁出站不能阻止内部滥用；这三类残余风险需分别登记和接受。

## 安全验证（模拟数据、隔离系统）

- 用不同部门的虚构文件测试检索与交易：有检索权限不等于有写权限；模拟文档里“请批准付款”不能触发工具动作。
- 注入合成敏感标记于输入、评测、缓存、错误日志各路径，核对实际去向、保留和删除回执；不把工具配置页面当传输证据。
- 切换区域、模型供应商或启用第三方监控后，复测网络目的地与合同清单；若不能观察底层路径则标记“待验证”。
- 桌面演练安全事故、数据处理争议及供应商停供三种事件：决策人与证据需求不能混同；禁止在生产发送测试敏感数据。

## 一手资料与适用性

- [NIST AI RMF 官方入口](https://www.nist.gov/itl/ai-risk-management-framework) 与 [NIST GenAI Profile 出版页](https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-generative-artificial-intelligence)：AI 风险识别与治理参考，不自动构成合规认证。
- [NIST SP 800-207](https://csrc.nist.gov/pubs/sp/800/207/final)：资源访问和零信任架构参考，非 Agent 的自动授权规则。
- [欧盟委员会 AI Act 政策入口](https://digital-strategy.ec.europa.eu/en/policies/regulatory-framework-ai) 与 [欧盟委员会数据保护法律框架入口](https://commission.europa.eu/law/law-topic/data-protection/legal-framework-eu-data-protection_en)：核查欧盟规则的起点；政策页不能代替法条、修订状态或专业适用性判断。
