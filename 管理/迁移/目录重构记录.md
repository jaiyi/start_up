# 目录重构记录

本次迁移将仓库从 `docs/` 混合承载模式调整为中文一级目录：`知识/`、`研究/`、`洞察/`、`项目/`、`个人/`、`资料/`、`管理/`。

## 原则

- 使用 `git mv` 保留文件历史。
- 项目级设计、计划、决策和资料跟随项目。
- 原始资料优先跟随主题，只有未归属或公共资料进入 `资料/`。
- 不复制正文，不保留多个 source of truth。
- 第一轮只调整目录边界、导航和内部路径，不大规模重写内容。

## 本轮范围

- 迁移稳定知识、研究、洞察、项目、个人资料和原始资料。
- 补充各一级目录和主要项目 README。
- 修复旧目录路径引用。
- 不提交 Git；由用户在检查 diff 后决定是否提交。
