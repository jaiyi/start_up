# 理想汽车案例横向专题

本目录不是新的案例来源，也不替代各案例正文。它只负责把多个案例中反复出现的业务链路、工具接入模式和经验资产化方法提炼出来，便于比较、验证和迁移判断。

## 阅读顺序

1. [`01-设变三案：从ECR到ECN执行监控.md`](./01-设变三案：从ECR到ECN执行监控.md)：看规则评审、ECR 候选、设变审批和执行断点如何连接。
2. [`02-专业工具接入：从脚本执行到Agent直连.md`](./02-专业工具接入：从脚本执行到Agent直连.md)：看 CATIA、TRACE32、CAE 和研发工具的控制粒度、人工门槛与审计协议。
3. [`03-经验资产化：从经验到Skill、剧本与图谱.md`](./03-经验资产化：从经验到Skill、剧本与图谱.md)：看经验如何经过验证成为可复用资产，以及错误经验如何被阻断。

## 与其他文档的关系

- 案例事实、原始来源和单案例分析：保留在上级目录的具体案例文档。
- 权限、证据、审计、人工责任和禁止迁移项：统一登记在 [`../案例治理矩阵.md`](../案例治理矩阵.md)。
- 稳定的方法论判断：经过多个案例和实际项目验证后，才考虑沉淀到 `洞察/` 或 `知识/`，本目录不直接把推演升级为知识。

## 横向专题的共同边界

```text
来源案例
  → 横向比较
  → 未决问题与验证任务
  → 经过项目验证的判断
  → 再决定是否沉淀为洞察或知识
```

当前三个专题都不是“理想汽车已经统一建设了这些平台”的结论，而是基于已有案例形成的研究假设和比较框架。
