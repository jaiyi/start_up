# 01 · 设变三案：从 ECR 到 ECN 执行监控

> 本文是横向研究专题，不是理想汽车内部系统架构或已完成的平台整合证明。三个案例来自不同材料和团队，以下链路是研究者根据案例描述形成的对照模型，待进一步核验系统是否互通。

## 1. 对照范围

| 案例 | 主要位置 | 核心能力 | 规则形态 | 当前材料显示的出口 |
|---|---|---|---|---|
| [`工艺设计合规性智能评审系统`](../理想汽车-工艺设计合规性智能评审系统.md) | 数模/工艺评审上游 | CATIA 几何检查、MR 标准解析、SE 对象和跨工艺规则 | 五元组、规则库 | 不合格项自动转 ECR 的描述，实际权限待核验 |
| [`设计变更智能评审助手`](../理想汽车-设计变更智能评审助手.md) | 设变申请评审入口 | 跨系统取数、40+ 规则、自然语言规则共创和高危提醒 | Skill + 自然语言规则 | 拦截/放行提醒和干系人触达，是否写回系统待核验 |
| [`工程设变断点端到端监控平台`](../理想汽车-工程设变断点端到端监控平台.md) | 设变批准后的执行侧 | MBOM 差分、到货监测、责任人图谱和断点催办 | 规则引擎、数据差分 | ECN 执行断点、到货和责任状态监控 |

## 2. 研究中的端到端链路

```text
数模 / 工艺要求
  ↓
CATIA 几何与 MR 规则评审
  ↓
不合格项、证据和 ECR 候选
  ↓
人工确认、补充信息和设变评审
  ↓
ECR 审批 / ECN 发布
  ↓
MBOM、到货、库存和产线断点监控
  ↓
责任人处置、执行验证和结果回流
```

这条链路是研究模型，不是已证实的系统调用链。尤其不能从“自动生成 ECR”直接推导出 ECR 已提交、已审批或已成为 ECN。

## 3. 三种规则形态

```text
规则 = 代码 / 差分逻辑
  → 适合稳定、高频、需要强审计的判定

规则 = 结构化约束 / 五元组
  → 适合把标准、对象、阈值和单位形式化

规则 = 自然语言 / Skill
  → 适合快速共创、半结构化判断和探索性提醒
```

更稳健的目标不是三选一，而是：

```text
业务人员自然语言提出规则
  → AI 生成结构化候选
  → 冲突检查、回放测试和影响分析
  → 规则 owner 确认
  → 形式化规则或代码执行
  → 结果、误报和漏报回流
```

自然语言“生效”不能意味着未经审核就改变生产拦截逻辑。

## 4. 责任和权限分层

| 阶段 | AI 可以做 | 不能默认做 | 必须确认的人 |
|---|---|---|---|
| 几何/标准分析 | 识别对象、匹配规则、生成证据 | 把证据不足当作合规 | SE 工程师/规则 owner |
| ECR 准备 | 生成候选、预填字段、关联证据 | 自动发布工程变更 | ECR 创建人和变更 owner |
| ECR/ECN 审批 | 汇总风险、提醒责任人 | 代替审批和签字 | 授权审批人 |
| 执行监控 | 差分、提醒、状态聚合 | 自动关闭未验证断点 | 制造、供应链和责任人 |
| 结果回流 | 收集处置结果和复盘材料 | 把提醒当作已闭环 | 业务 owner |

## 5. 需要重点验证的对象关系

- ECR 候选、ECR、ECN、MBOM 变更和到货断点是否有稳定 ID；
- 三个案例是否接入同一设变系统，还是仅在研究层可串联；
- 工艺评审的规则结果如何进入设变评审，是否保留原始数模和规则版本；
- 自然语言规则是否编译为结构化规则，还是每次由 LLM 现场解释；
- 评审助手的高危提醒是否进入执行监控，是否产生重复通知；
- 设变批准后如何验证设计、物料、库存、供应商和产线实际执行；
- 误拦、漏拦、重复 ECR、断点漏报和权限失败如何补偿；
- 谁拥有跨案例的规则、数据和责任边界。

## 6. 对 SPC/制造项目的迁移判断

可迁移的不是“自动 ECR”这个表面动作，而是对象链和证据链：

```text
规则命中
  → 结构化异常
  → 证据快照
  → 人工确认
  → 候选工单/变更
  → 授权执行
  → 执行验证
  → 结果回流
```

对于 SPC 或质量场景，lot release、PCN、工艺参数变更和供应商整改也应保持“候选生成”和“正式发布”分离。

## 7. 当前结论

1. 三个案例可以形成一个有价值的研究链路，但不能声称已经是统一平台。
2. 稳定红线规则优先形式化，动态规则可以自然语言共创，但必须经过编译、测试和人工发布。
3. 自动发现、自动提醒、自动生成候选和自动批准是四个不同权限级别。
4. 真正需要补的不是更多 Agent，而是 ECR/ECN 的稳定对象、证据、责任和执行回流。
