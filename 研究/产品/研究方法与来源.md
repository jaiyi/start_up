# 产品研究方法与来源

这是跨产品的**比较与证据方法**，不是产品主分类。产品专属的原始来源、图片与附件保留在各自专题；[产品能力分类](./README.md)与[场景交叉导航](./场景索引.md)分别负责正文归属和行业/任务入口。

## 建议沉淀内容

- 产品分析模板，区分对象、版本、交付物、部署方式及验证范围；
- Agent 工作台能力矩阵，比较任务、协作、产物和权限；
- 知识库 / RAG 产品横向对比，记录切片、检索、引用和更新边界；
- 行业 AI 平台落地评价标准，包括环境适配、现场接入、人审与持续运营；
- 人机协作资料库设计原则，区分知识、协作产物与业务权威状态；
- 动态状态、稳定知识、Agent 工具边界的架构模式。

## 证据与比较口径

1. 记录对象、日期、资料链接和适用版本；优先公开一手资料。区分官方声明、可核实的文档/仓库事实与自己的推断，横向比较先对齐部署形态和使用边界。
2. 将“提供接口/示例”与“已集成、已部署、已生产验证”分开；未经复现的性能、成本、准确率或自动化效果只按原资料限定条件转述，不写成实测。
3. 比较时检查权限与许可、来源可追溯性、失败/误报/漏检、升级及迁移成本，注明未知项和待验证假设；不把研究索引当成采购选型或上线验收结论。
4. 原始资料若受访问或使用限制，应先核权、限制传播；不要把未经授权的正文或敏感业务材料复制到跨产品索引。自己的项目实现与结果进入 `项目/`，已验证可复用方法进入 `知识/`，方向判断进入 `洞察/`。
