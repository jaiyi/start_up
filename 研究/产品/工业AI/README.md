# Industrial AI Platforms

本目录用于分析外部工业 AI 平台、行业 Agent 平台、制造质量/工艺/设备等场景产品。

## 当前目录边界

- `lattice/`：外部工业 AI 产品和公开能力研究；
- `lianshan/`：内部连山产品、代码仓和当前产品能力分析；
- AI Native 任务闭环平台的方向判断和设计推演位于 [`../../../洞察/AI原生转型/`](../../../洞察/AI原生转型/)；具体 AI 平台试点位于 [`../../../项目/SPC-DeepSeek-Harness/`](../../../项目/SPC-DeepSeek-Harness/)。

本目录记录外部事实、产品能力和案例证据；自己的架构决策、实现计划和验证结果进入 `项目/`。

## 关注重点

- 私有化部署与企业环境适配；
- 工业数据、业务状态和现场系统接入；
- 行业知识、工艺经验、诊断流程的沉淀；
- HITL、人审、EVI、价值归因与反馈闭环；
- 从 demo 到生产系统的工程化路径；
- 行业 Know-how 与 Agent 工作流的结合方式。
