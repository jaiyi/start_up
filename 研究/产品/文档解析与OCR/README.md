# 文档解析与 OCR 产品研究

本目录关注**有权获取原件后**，将 PDF、扫描件和图片解析为文本、结构、布局与可回溯的来源定位。解析成功不等于完整覆盖原件，更不等于知识已经获批、发布或可授权检索。

## 当前分析对象

| 产品 | 关键能力 | 需要特别核实 |
|---|---|---|
| [SoMark OXR](./somark-oxr.md) | 带版面坐标的文档解析、可插拔版面分析、Markdown / JSON 输出 | 自定义许可证、模型服务资源和坐标/漏读验证 |
| [百度 Unlimited OCR / OCR 2](./baidu-unlimited-ocr.md) | 多页文档解析与长文档推理 | 版本差异、显存/时长/页数边界、页级覆盖及后处理 |

## 横向评估维度

1. **来源与权限**：获取主体、空间、允许的目标、原件版本/hash 与保存期限。
2. **覆盖率**：扫描页、跨页表格、文字/图形/公式、不可读区域、截断与缺页是否显式反馈。
3. **证据锚点**：页码、区域坐标、阅读顺序、Markdown/JSON 与原件能否一一对齐。
4. **工程隔离**：文件大小/类型、PDF 渲染、恶意文件防护、沙箱、超时、并发及资源配额。
5. **运营成本**：模型权重、显存、吞吐、部署维护、商业授权及离线能力。
6. **下游闭环**：解析结果与审核过的 Git 正文、WeKnora 索引与授权检索的版本边界。

团队知识工程项目中，个人 Inbox 链接保存不触发抓取；只有在知识入口明确选用并重新核权、受限获取通过后才进入可选解析路径。这里是外部能力研究，不表示已完成与产品的集成。
