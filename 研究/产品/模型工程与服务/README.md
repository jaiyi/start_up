# 模型工程与服务产品研究

这里按主要交付物收录模型的训练复现、预测/决策能力与模型客户端接入服务。模型工程**不是**通用 Agent 执行控制面；列出训练阶段不代表所有阶段构成唯一必经流水线，也不代表项目可直接用于生产。

| 报告 | 定位 | 阅读重点 |
|---|---|---|
| [MiniMind](./minimind.md) | 小语言模型从零训练的教学与复现项目 | 数据/模型版本、Pretrain/SFT/LoRA、RL 优化、工具示范与蒸馏；准确理解成本声明与应用边界 |
| [Chronos Forecasting](./chronos-forecasting.md) | 时序预测模型家族及服务部署案例 | 预测能力、SageMaker AI Chronos-Bolt 部署与 SPC 判异的边界 |
| [laya / laya server](./laya-typed-decision-engine-and-server.md) | 非自回归 System 1 类型化决策引擎及服务组件 | 高频路由、工具选择和风险分级的模型判定与宿主运行控制分工 |
| [Magpie](./magpie.md) | 本地多协议模型网关与客户端接入管理 | 多模型/账号路由、客户端配置恢复及 Library 资产分发与宿主授权的边界 |

## 评估与相邻类别的边界

- 训练/复现核对数据、模型和代码版本、硬件与成本条件；预测/决策核对目标指标、输入范围、误差和风险兜底；网关核对协议、凭据、路由和变更恢复。报告依据公开资料，**未经本地复现实验不得写成实测**。
- 通用任务循环、工具权限、状态恢复和运行观测见[任务运行与编排](../任务运行与编排/README.md)；训练后任务级 Harness 的持续改进见[Agent 记忆与学习](../Agent记忆与学习/README.md)；工业/制造只是[场景标签](../场景索引.md)，不改变模型的主归属。
- 入门概念与学习顺序另见[大模型训练入门专题](../../../知识/技术/模型与任务协议/大模型训练入门/README.md)。
