# 编程 Agent 产品分析

本目录用于分析编程 Agent、AI IDE、代码协作与软件工程自动化产品。

## 关注重点

- Agent 如何理解代码仓、文档和项目规范；
- 是否支持计划、编辑、测试、提交、代码审查和长任务执行；
- 项目记忆、工程规范、上下文管理和多 Agent 协作；
- 权限、安全边界、外部命令执行和供应链风险控制；
- 从个人开发效率到团队工程流程的产品化路径；
- 设计、可用性和质量门如何约束 AI 生成的界面与代码。

## 当前分析对象

| 产品文档 | 产品 / 能力 | 类型判断 | 核心问题 |
|---|---|---|---|
| `impeccable.md` | Impeccable | 面向 coding Agent 的设计工作流、界面规范和确定性质量门 | 如何通过设计上下文、可复用命令和 detector，减少 AI 生成界面的通用化、失真和质量回退 |

## 边界

本目录关注软件工程任务中的 Agent 使用方式。通用模型调用、工具权限、任务状态和恢复机制见 [`../Agent运行时/`](../Agent运行时/)；团队 Skill、Agent 组织、预算和发布治理见 [`../Agent资产与团队治理/`](../Agent资产与团队治理/)。

## 评估维度

1. 代码库理解、索引和上下文选择；
2. 计划、编辑、测试、运行和提交的闭环程度；
3. 规范、设计系统和项目约束的注入方式；
4. 工具权限、沙箱、命令执行和敏感信息保护；
5. 产物质量、可审查性、可回滚性和团队协作；
6. 记忆、Skill、MCP 和跨项目复用能力。
