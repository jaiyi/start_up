# 浏览器自动化产品分析

本目录用于分析浏览器扩展、Userscript、Bookmarklet、网页自动化和浏览器内 Agent 工具。

## 关注重点

- 如何把网页变成可编程、可复用的工作界面；
- 脚本 / 扩展 / RPA / Agent 的执行边界；
- 网页上下文、扩展权限、跨域访问和敏感数据保护；
- 自动化脚本的安装、分发、更新、版本、回滚和审计；
- 自然语言意图与确定性网页操作之间如何分工；
- 用户个人自动化如何升级为团队可治理的能力资产。

## 当前分析对象

| 产品文档 | 产品 / 能力 | 类型判断 | 核心问题 |
|---|---|---|---|
| [`tampermonkey.md`](./tampermonkey.md) | Tampermonkey | Userscript Manager / 网页层可编程扩展运行时 | 如何通过用户脚本声明网页匹配范围、权限和依赖，把网页改造成可定制的工作界面；第三方脚本供应链与高权限执行如何治理 |

## 边界

本目录关注浏览器中的确定性自动化和网页扩展能力。面向代码仓库的编程 Agent 见 [`../编程Agent/`](../编程Agent/)；通用 Agent 工具调用、执行和恢复见 [`../Agent运行时/`](../Agent运行时/)；企业流程和机器人自动化若涉及具体业务系统，还需结合相应领域目录分析。

## 评估维度

1. 网页上下文注入与脚本执行模型；
2. 匹配规则、权限声明、跨域和资源依赖；
3. 脚本创建、安装、启停、更新、调试和同步闭环；
4. 生态分发、兼容性和维护成本；
5. 数据安全、供应链、隐私和企业治理；
6. 与 RPA、浏览器扩展、MCP 浏览器工具和 Agent Skill 的边界；
7. 可审查性、可回滚性、人工确认和审计能力。
