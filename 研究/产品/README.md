# 产品研究索引

本目录按产品的**主要能力层**分类；单个产品可能跨多个层，但只保留一份主调研文档。研究以公开一手资料为主，区分官方声明、已核实的仓库/文档事实与本地分析推断；未部署或复现的效果指标不得当作实测结论。

## 分类目录

- [AI 原生数据平台](./AI原生数据平台/)：企业数据底座、业务语义/本体与 Agent 数据供给。
- [Agent 运行时](./Agent运行时/)：Harness、任务执行控制面及相邻的工作流编排。
- [文档解析与 OCR](./文档解析与OCR/)：从 PDF/图片到带版面结构的文本或数据；不替代知识审核。
- [知识库](./知识库/)：文档知识、索引、授权检索与引用。
- [Agent 资产与团队治理](./Agent资产与团队治理/)：Skill、发布/分发、组织控制面。
- [Agent 工作台](./Agent工作台/)：人与 Agent 的协作、产物与任务界面。
- [Agent 学习系统](./Agent学习系统/)：轨迹、反馈、评估与经验沉淀。
- [编程 Agent](./编程Agent/)：代码工作、工程任务、编辑与测试。
- [后端基础设施](./后端基础设施/)：应用数据库、认证、存储、Functions 与 BaaS。
- [数据治理平台](./数据治理平台/)：目录、质量、权限、血缘与合规。
- [工业 AI](./工业AI/)：制造场景、工业数据、模型和 Agent 平台。
- [办公 AI](./办公AI/)：文档、表格、会议及办公套件智能能力。
- [浏览器自动化](./浏览器自动化/)：网页任务与浏览器脚本。
- [来源与方法](./来源/)：跨产品评估框架、研究资料组织。

每个分类的 `README.md` 保留该分类的现有索引和评估口径；研究归档不构成产品选型、集成许可或上线验收结论。
