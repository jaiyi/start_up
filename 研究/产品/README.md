# 产品研究索引

本目录按研究对象向使用者交付的**主要能力与责任边界**分类：一个对象选一个主目录，跨层能力通过索引互链，不复制权威正文。行业（工业、办公、航天）、任务（编程、预测）、厂商和“Agent 原生”是[场景交叉索引](./场景索引.md)中的标签，而非另一套产品目录。模型、组件、原型与应用均可研究，但须注明粒度，不能将邻接能力冒称完整平台。

## 如何归类

1. 先问主要交付物是什么：训练/预测/模型接入归[模型工程与服务](./模型工程与服务/README.md)；原件解析归[文档解析与 OCR](./文档解析与OCR/README.md)；已有知识的索引与引用归[知识库与检索](./知识库与检索/README.md)；综合数据与业务语义供给归[数据与语义平台](./数据与语义平台/README.md)；数据控制、语义变更及隐私处理归[数据治理与隐私](./数据治理与隐私/README.md)。
2. 若交付应用后端（数据库、认证、存储、计算），归[后端基础设施](./后端基础设施/README.md)；若负责 Agent 执行、工具、工作流与运行观测，归[任务运行与编排](./任务运行与编排/README.md)；运行后记忆、轨迹评估与经验/Harness 改进归[Agent 记忆与学习](./Agent记忆与学习/README.md)；Skill/Agent 资产分发、组织与预算归[Agent 资产与团队治理](./Agent资产与团队治理/README.md)。
3. 若主要交付协作空间、文档和任务产物，归[人机协作与产物](./人机协作与产物/README.md)；面向代码及工程质量的工具归[软件工程工具](./软件工程工具/README.md)；浏览器脚本和扩展归[浏览器扩展与自动化](./浏览器扩展与自动化/README.md)；交付端到端业务任务成果或跨层产品体系，归[业务应用与解决方案](./业务应用与解决方案/README.md)。
4. 综合对象选其**主要交付物**的一类；行业和任务只加[场景索引](./场景索引.md)链接。研究项目的实现与验证进入 `项目/`，可复用的已验证知识与方向判断按各自规范分别进入 `知识/` 与 `洞察/`。新增二级目录应有独立交付物、与邻类的判断边界及长期横向比较价值，不按单篇文档的细功能或行业增设空类。
