# 近一年央国企智能化改革与电力行业专项政策

> **观察窗口：2025-10-19—2026-10-19；整理日期：2026-10-19。**“近一年”按文件**制发日期**判断；网页发布日期另列。范围为国家层面央企政策/部署及能源电力行业文件，不将地方国企政策自动等同于央企统一要求。本篇是面试研究快照，不代替现行法规、项目实施细则或企业内部制度。
>
> **证据标记：**E1-正式文件＝部门原文及附件；E1-会议报道＝主管部门官网对会议/活动的报道，能证明部署或表态，**不是**公开发布的规范性文件全文；E4＝面向国家电投/电投数科的分析推论。下面凡有文件号、量化目标，均以链接原文为准。

## 一页结论

1. **央企层面：**国务院国资委在2026年2月的中央企业“AI+”专项行动深化部署会上，强调主责主业与高适配、高价值、高可靠场景对接，关键技术、有效算力投资、“算力+电力”、全链条数据治理及开源协同。这是**官方会议报道中的工作部署**，不可伪称“新出台的央企AI管理办法”。[S1]
2. **财务与治理层面：**国资委2026年3月的培训报道提出财务“五大升级方向”、DRP系统和智能化穿透监管；它提到一份指导意见，但本研究没有取得该指导意见的公开全文，**不替其补写文号、发布日期或具体条款**。[S2]
3. **电力行业确有专项文件，而且更具体：**2026年四部门《人工智能与能源双向赋能行动方案》、能源体系“十五五”规划、电力系统“十五五”规划、能源节能降碳行动计划，分别落到算电协同、能源场景与数据/模型、电力全流程智能化，以及碳数据在线监测。前者与后者并不只针对央企；须按各文件适用对象和业务环节判断。[P1–P4]
4. **面试转化（E4）：**对发电集团数科公司，优先讨论场站运维/新能源预测/经营与碳管理的数据闭环、可靠性验证、跨场站复制和算电协同，而不是将“AI+”简化为建设一个大模型。国家文件**不证明**电投数科已拥有某平台、已承担某个项目，或已完成量化目标。

## 2. 央企改革：哪些是明确部署，哪些尚不能当作文件条款

### 2.1 国资委“AI+”专项行动深化部署——会议层面的四条主线

[S1]报道在“会议强调”部分要求中央企业：①强化自主创新，突破关键核心技术，推进大模型成果从样品到产品；②把AI与**主责主业和产业需求**精准对接，尤其重视“高适配、高价值、高可靠”并形成规模化应用；③扩大**有效**算力投资，推进“算力+电力”协同和全链条数据治理；④开源开放协同，参与产业共同体。这些措辞体现央企选择场景、投资和生态的方向，但报道未给出对每家央企的考核口径、投产截止日或预算额度，不能自行推定。[S1]

### 2.2 财务数智化及智能监管——存在转型方向，原指导意见待核

[S2]报道提及《关于推动中央企业加快财务数智化转型升级的指导意见》，概括“财务管理体系化、财务系统集成化、财务信息数字化、财务监督智能化、财务转型一体化”，提出建设全经营领域数字化资源管理平台（DRP系统），并部署智能化穿透式监管。**本篇所核实的是国资委的培训报道，不是该指导意见原件**；尚不能据此断定意见的文号、强制性、实施时限，或电投数科负责DRP建设。[S2]

[S3]分论坛报道中的“未来将组织开展新一轮数智化转型专项行动”属于**后续工作方向**，还不是可以引用具体任务清单的正式行动方案。其智能工厂梯度培育更适于产业类企业情境；映射到发电场站，需要重新界定对象和评价口径，而非直接等同。[S3]

国资委党委2026年4月署名文章还将**智能化、绿色化、融合化**列为传统产业转型方向，提出深化“AI+”行动、避免重复建设和低效投入，并在国企改革中推动组织扁平化、智能化管理与穿透式监管。这是**国资委官网刊载的政策阐述文章，不是新的规范性文件**；可用来理解数智化为何同时服务于产业升级与国资监管。[S4]

## 3. 能源电力专项：政策原文说了什么

### 3.1 四部门《人工智能与能源双向赋能行动方案》：最直接的新增专项

国家发展改革委、国家能源局、工业和信息化部、国家数据局共同印发[P1]，文号**国能发科技〔2026〕34号**，主送有关中央企业。它在2025年能源AI基础文件之上进一步串起两条路径：

- **能源支撑AI：**统筹新能源基地和算力枢纽布局，探索算力设施与配套能源系统协同建设；按接入条件保障电能质量，推进算力设施绿电消费、能效碳效管理，以及算力负荷与电力系统互动。第四部分提出多年期绿电交易、需求响应和辅助服务等**鼓励/支持的机制**，不是要求所有发电企业强制进入全部市场。[P1，第二至四部分]
- **AI赋能能源：**以应用价值、数据基础和规模化潜力筛选场景，开展试点、性能评测与闭环管理；专栏涉及新能源基地调度决策、风光功率预测、风光场站智慧运维、核电运行异常识别等，也列出电网规划及协同调度。第六部分明确高质量数据集建设、分类分级和安全，第七部分推动能源专业模型及智能体等技术。规划中“推动五个以上专业大模型……深度应用”是**行业层面方向**，不是对国家电投或电投数科单独下达五个模型指标。[P1，第五至七部分]
- **安全不是可选项：**场景开放以国家能源安全、网络安全和商业秘密为前提，并提出应用安全责任划分和数据/模型/应用治理。[P1，第五、六、八部分]

### 3.2 两项“十五五”规划：总体方向与电力系统细化

[新型能源体系规划][P2b]专栏“人工智能+”能源提出新能源基地与算力枢纽协同布局、以电强算/以算促电、智慧电厂和电网数智化；正文提出算电协同。它是能源全行业框架，不把所有电网职责转嫁给发电集团。[P2a][P2b]

[新型电力系统规划][P3b]的**（三十二）“深化人工智能赋能”**原文要求“加强电力行业数据资源开发利用”，统筹AI赋能新型电力系统建设，推动电力行业全环节、全流程数智化升级，围绕典型场景试点打造可复制、可推广标杆。规划还涉及新能源消纳、智能微电网、虚拟电厂和系统调节等，适合按**发电侧、网络/调度侧、负荷侧**区分业务责任。比如风光场站预测/运维主要关联发电资产；跨省调度、安全稳定控制与电网运行不因为文件提到“AI”就成为电投数科的法定职权。[P3a][P3b]

### 3.3 节能降碳行动计划：国家电投被直接列为主送单位

[P4]通知收件单位逐项列有“国家电投”，因此对该集团的**政策关联比仅有“有关企业”表述更直接**。第六部分（十六）节提出数字化碳管理平台、能耗精准计量/实时采集/智能分析、能耗和碳排放在线监测与核算，并探索AI节能降碳高价值场景。这里的“支持企业建设”“鼓励创新”“探索”应按原文力度解读；文件**没有**指派集团旗下某一家数科公司建设唯一平台。[P4]

## 4. 将政策翻译成岗位问题（E4：分析，不是政策原话）

| 政策信号 | 对发电集团数智岗位可讨论的工作假设 | 面试时要追问的边界/验证指标 |
|---|---|---|
| 主业高价值/高可靠场景；AI能源试点 [S1][P1] | 选少量有稳定数据的场站，比较预测、设备缺陷识别、维修辅助的真实收益 | 基准线是什么？误报漏报、停机时间、人机复核、跨电站迁移如何度量？ |
| 高质量数据集和全链条治理 [S1][P1][P3b] | 贯通设备台账、测点、工单、气象、发电量和告警事件，治理时序质量与权限 | 数据权属、实时性、异常标注、脱敏/分级、模型评测由谁负责？ |
| 算电协同及绿色算力 [S1][P1][P2b] | 将绿电供给、负荷弹性与算力部署关联，评估供电质量、绿电消费与市场收益 | 角色是发电商、用电方还是平台方？涉及电网调度时接口与权限在哪里？ |
| 碳管理与穿透监管 [P4][S2] | 强化计量—核算—审计追溯链条，避免AI生成的数字未经核实就进入报送 | 排放因子版本、核算边界、人工复核和财务/监管系统责任分工是什么？ |

**建议回答框架：**“政策要求的不是单独上模型，而是主业场景的可靠应用 + 可治理的数据 + 可验证收益 + 生产安全边界。我的落地次序会先明确资产和责任主体，再确定基准指标与数据质量、做受控试点，最后评估跨场站复制。”这是基于[P1–P4][S1]的**面试分析**，并非关于电投数科现状的已证实陈述。

- 遇到2027、2030等数字，核实是全国/行业指标、预期性还是约束性，以及是否分解至企业；**不要**从国家规划直接推出电投数科的业绩承诺。
