## 背靠集团：国家电投意味着什么

国家电投是五大发电集团之一，也是清洁能源、新能源、光伏、核电、水电、火电综合布局很重的央企。对电投数科来说，集团背景带来几个特点：

1. **业务场景足够大**：新能源场站、火电、水电、核电、煤电铝、路港、多产业协同、经营管理、供应链、设备运维、安全生产，天然有大量工业AI/数据治理场景。
2. **数据和系统复杂度高**：集团型央企的典型问题是业务条线多、系统多、数据口径不统一、历史包袱重，因此数据中台、数据治理、指标体系、主数据、知识图谱、智能决策都有真实需求。
3. **项目周期偏长**：央企数字化项目通常不是互联网式快速试错，而是规划、立项、试点、验收、推广、审计、合规全流程推进。
4. **稳定性较强**：集团内生需求稳定，抗周期性优于多数民企；但相应地薪酬、晋升、流程、决策速度也更央企化。

对你来说，最关键的是：**电投数科不是一个纯AI研究机构，而是一个要把AI、数据、云、安全、业务系统真正塞进集团产业现场的数字化平台。** 这正好对应你“AI落地方法论 / EVI / 产业AI解决方案”的方向。

## 结论先行

**最值得优先看的不是纯算法/纯云原生/纯ERP岗，而是“产业数智化解决方案 + AI产品/数据治理 + 科研创新管理”三类。**

结合你的画像：

- 佐治亚理工 EE/CS 硕士；
- 6 年工业 AI / 制造业 AI 落地经验；
- 有供应链质量预警、时序/波形异常检测、AI诊断Agent、知识图谱/语义建模、数据闭环经验；
- 更想做 **AI落地方法论、EVI/价值量化、产业AI规划、产品/解决方案/项目牵引**，不想回到纯写代码；
- 偏好稳定央企、北京、家庭友好，但也希望薪资不要大幅低于当前 60-80 万年包；

我会把电投数科本部岗位分成三档：

| 档位 | 岗位 | 推荐动作 |
|------|------|----------|
| **A档：优先投/重点聊** | 高级解决方案经理、高级人工智能产品经理、数据中台产品经理、智慧产业创新项目负责人 | 与你的工业AI落地、数据治理、方法论、跨部门推进最相关 |
| **B档：可备选/看团队再定** | 产品经理、高级数据分析师、高级大模型评测工程师、高级规划咨询顾问、高级AI算法工程师 | 有契合点，但存在业务域偏离、职责偏窄或技术深度错位 |
| **C档：不建议优先** | 云原生/后端/前端/ERP/网络安全/基础设施/客服运营等岗位 | 多数偏底层工程、ERP实施、安全专门线或运维管理，不符合你的主叙事 |

**如果只能选一个主投方向：推荐第一优先级是 `智慧产业事业部 - 高级解决方案经理`。**
原因：它最接近“产业数智化顶层设计 + 智慧场站/智能运维/智能监测 + AI方案落地 + 面向业务高层讲清楚价值”的工作，是你从汽车工业AI迁移到能源产业AI最自然的叙事入口。

这个岗位从标题和岗位职责看，非常适合你：负责人工智能相关产品、行业AI解决方案，从需求调研到上线落地、迭代优化。它需要的是能理解AI技术、业务场景和产品交付的人。

这个岗位适合你在央企里走“数据治理 + AI基础设施产品”的路线。它要求主导集团级数据中台产品规划，建设数据集成、治理、建模、服务、指标体系、数据安全、数据开发平台，并推动各产业业务数据标准化接入。

你的知识图谱、语义建模、供应链质量预警、数据闭环经验，可以很好地迁移到“集团数据标准体系建设”和“AI应用的数据底座”上。

但它不是最直接的“工业AI应用落地”岗，可能更像平台产品经理/数据治理产品负责人。若你想减少编码、转向集团级方法论和平台能力，这是非常合适的备选。

**适合在面试时确认：这个岗位是否服务AI/大模型/智能体场景，还是仅做传统数仓与数据治理。**

## 建议投递组合

### 如果系统每人只能投 1 个岗位

**首选：智慧产业事业部 - 高级解决方案经理**

理由：

1. 最能承接你“工业AI落地 + 方法论 + 业务价值 + 产品/解决方案”的复合优势；
2. 不要求你回到纯开发/纯算法；
3. 能把汽车制造经验迁移到新能源、火电、煤炭、铝业、路港等能源产业数智化；
4. 面试表达空间最大，最容易讲出差异化故事。

### 如果可以同时沟通多个岗位

优先顺序建议：

1. **高级解决方案经理**（主投）
2. **高级人工智能产品经理**（AI产品备选）
3. **数据中台产品经理**（数据治理/平台产品备选）
4. **智慧产业创新项目负责人**（若不强卡职称/科研申报，可冲）
5. **智慧管理事业部产品经理**（管理AI/知识图谱方向备选）

### 如果HR说你“能源行业经验不足”

可以这样转化：

> 我的优势不是某一个能源子行业经验，而是工业AI从场景识别、数据治理、模型/Agent落地到价值评估的全链路方法论。能源行业的智慧场站、智能运维、设备状态识别、生产经营预测，本质上与制造业质量预警、设备异常诊断、供应链风险预测有共通的数据闭环和价值闭环。我可以补能源业务知识，但电投数科更稀缺的可能是能把AI真正落到产业现场、形成可复制解决方案的人。

## 面试重点准备

### 1. 主线故事

建议把个人叙事从“AI算法/模型经验”改成：

> 我擅长把工业场景里的复杂业务问题，转化成可落地、可评估、可复用的AI/数据产品方案。

围绕四类案例讲：

1. **质量预警 / 供应链风险**：如何定义风险指标、数据口径、预警闭环和业务价值；
2. **设备/过程异常检测**：如何从时序/波形/工况数据中建立异常诊断体系；
3. **知识图谱 / 语义建模**：如何沉淀业务知识，让AI系统可解释、可复用；
4. **AI Agent / 决策辅助**：如何把模型能力嵌入业务流程，而不是停留在Demo。

### 2. 对能源行业的迁移表达

把汽车制造经验映射到能源产业：

| 你的经验 | 可迁移到电投数科场景 |
|----------|----------------------|
| 制造质量预警 | 火电/新能源设备异常预警、生产过程质量/安全风险识别 |
| 时序/波形异常检测 | 风机、光伏、火电机组、输变电设备状态监测 |
| 供应链风险预测 | 能源物资、备件、采购、项目交付风险预测 |
| 知识图谱/语义建模 | 设备知识库、故障树、管理决策知识图谱、行业知识库 |
| EVI/价值量化 | AI项目立项、验收、推广、投资回报评估 |
| AI Agent | 智能运维助手、报告生成、故障诊断助手、业务问答助手 |

### 3. 必问问题

面试或HR沟通时建议确认：

1. **具体坐班地点**：北京哪个区？是否固定本部？是否有海淀/昌平/丰台等研发点？
2. **薪资带宽**：本部社招专家/经理岗年包大致范围？是否有绩效、年终、补充公积金/企业年金？
3. **岗位性质**：是产品/解决方案牵引，还是实际要承担大量编码/测试/运维？
4. **团队归属**：是否服务集团AI、大模型、智能体、智慧场站/智能运维项目？
5. **出差频率**：智慧产业事业部是否需要长期去厂站/项目现场？
6. **汇报对象和职级**：是个贡专家、项目负责人，还是带团队岗位？
7. **考核指标**：按项目交付、科研申报、产品上线、收入回款，还是内部管理KPI？
8. **是否强卡能源行业经验/职称/PMP/高级职称**：特别是智慧产业创新项目负责人、高级解决方案经理。

## 风险判断

### 主要优势

1. **央企稳定性强**：国家电投体系数字科技平台，长期确定性优于多数民企；
2. **岗位都在北京**：Excel中电投数科本部岗位地点均为北京；
3. **AI与产业数智化需求明确**：多个岗位直接写人工智能、大模型、智能体、智慧场站、智能运维、知识图谱、数据治理；
4. **你的复合背景有稀缺性**：懂工业AI、懂业务价值、懂数据闭环、能跨团队推进，不是单一算法或单一产品。

### 主要风险

1. **薪资不透明**：央企本部岗位通常“面议”，可能低于你当前60-80万年包；
2. **能源行业经验短板**：高级解决方案经理等岗位明确要求熟悉新能源/火电/煤炭/铝业等业务；
3. **央企流程与材料工作较重**：规划、科研、解决方案岗位可能大量写材料、汇报、申报、验收；
4. **部分JD疑似错贴/混写**：高级AI算法工程师、高级人工智能产品经理、高级软件测试工程师等岗位职责与任职要求存在不一致，需要面试确认真实岗位；
5. **通勤未知**：虽均为北京，但本部具体地址未在Excel中体现；需要确认具体办公地点。

## 最终建议

**推荐投递优先级：A档偏上，值得认真推进。**

在已看过的央企/国企数字化机会中，电投数科本部这批岗位的特点是：

- AI、数据治理、产业数智化岗位密度高；
- 北京本部岗位多；
- 有“智慧产业”这种和工业AI强相关的业务线；
- 但薪资、通勤、能源行业经验门槛、央企材料/流程负担都需要进一步验证。

**最建议的定位不是“AI算法专家”，而是：**

> 工业AI落地与产业数智化解决方案专家 —— 能把能源生产经营场景中的AI机会识别出来，设计数据/模型/Agent/业务闭环方案，并用EVI方法论衡量价值、推动规模化复制。

按这个定位，首选 `高级解决方案经理`，备选 `高级人工智能产品经理` 和 `数据中台产品经理`。如果电投数科能给到合理薪资、坐班地点可接受、岗位不是纯材料/纯交付，这家公司值得进入重点机会池。
