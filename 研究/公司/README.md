## 信息分层

每篇公司研究应区分：

1. **公司事实**：来源、发布日期、观察日期和证据等级明确。
2. **行业判断**：基于多个来源的分析，说明推理链和不确定性。
3. **岗位推测**：没有正式 JD 或一手访谈时，必须标记为推测。
4. **个人求职判断**：进入 `个人/职业/` 或面试材料，不作为公司事实。
5. **招聘批次与薪资**：时效性强，记录来源和复核日期。

## 公司研究最低交付格式

每篇公司研究至少应在文档开头说明调研日期、观察截止日和文档状态，并为高时效或高影响主张建立证据登记。登记项至少包含：

- 内容区段或主张摘要；
- 主张类型：公司事实、行业观察、岗位推测或个人判断；
- 来源、发布日期和观察日期；
- 证据等级：E1（正式披露）、E2（权威公开资料）、E3（招聘/访谈/单一来源）或 E4（个人推断/来源不明）；
- 适用范围、失效条件、下一次复核日期和复核状态。

没有来源的内容必须标记为“待核验”“推测”或“个人判断”，不能因为出现在公司研究文件中就当作已确认事实。财务、股权和供应链关系、产品发布、客户名单、市场份额、招聘、薪资、组织归属与工作文化等内容，在引用前应重新核验。

兆易创新的最新财务、供应链、产品和组织事实优先维护在 [11-gigadevice.md](./11-gigadevice.md)。面试材料只引用其中经过核验的内容，不复制整篇公司研究。

## 更新规则

- 新增公司前先判断是否已有同一实体或招聘批次文档；
- 公司名称不是稳定身份，正文中注明实体、地区、业务范围和观察日期；
- 过期内容不直接覆盖，使用更新时间、复核日期和替代关系说明；
- 不能把招聘平台推测或个人判断写成公司事实。
