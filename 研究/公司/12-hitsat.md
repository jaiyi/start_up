## 🎯 面试准备深度资料

### 一、SATware柔性化卫星平台 — 模块化理念详解

**核心问题**：传统卫星是"手工定制"，每颗都从头设计，周期长（4-6个月）、成本高。星座时代需要批量制造（年产180颗+）。

**SATware的解决方案**：

```
传统模式：每颗卫星 = 独立项目（定制设计→定制制造→独立测试）
SATware：每颗卫星 = 平台(标准) + 载荷(定制)
                     ↓
         平台模块化 → 像乐高一样拼装
         载荷可插拔 → 通信/导航/遥感按需挂载
```

| 特性 | 传统模式 | SATware柔性化 |
|------|----------|--------------|
| 研制周期 | 4-6个月 | **7天**（平台标准化后） |
| 成本 | 每颗独立核算 | 单星成本降低25% |
| 产线 | 定制作坊 | **脉动式柔性产线**（类似汽车流水线） |
| 适配性 | 一型一造 | 一个平台适配通信/导航/遥感多种载荷 |
| 构型 | 传统三维 | **平板式**（堆叠发射，一箭多星） |

**关键技术要素**：
1. **卫星可批产化架构**：平台与载荷解耦，平台标准化、载荷可插拔
2. **脉动式柔性化产线**：借鉴汽车脉动生产线理念，卫星在工位间流动
3. **全流程数字化智造**：5G+数字孪生，从设计到测试全链路数据贯通
4. **平板式卫星构型**：二维平面设计，厚度<5cm，火箭内堆叠发射

**面试话术**：
> "SATware的模块化理念和我在理想汽车做的事本质相同——都是把'定制化'变成'平台化+可配置'。在汽车制造里，我们通过SPC统一监控不同工艺的质量参数，通过本体论统一不同工位的数据语义；在卫星制造里，平台标准化后同样需要一套统一的质量监控和数据管理体系来支撑批量化。"

### 二、"卫星批产质量管控" vs "汽车焊装质量管控" — 类比分析

| 维度 | 汽车焊装（你的经验） | 卫星AIT（工大卫星需求） |
|------|---------------------|----------------------|
| **批量规模** | 日产数百台车/数十万焊点 | 年产180颗卫星/十颗同时总装 |
| **关键工序** | 点焊、涂胶、拧紧 | 总装(Assembly)、集成(Integration)、测试(Test) |
| **质量数据类型** | 焊接电阻曲线、扭矩曲线、胶量 | 热真空数据、振动试验数据、EMC测试、精度测试 |
| **异常检测** | 包络线偏离/FFT/DTW/SPC | 性能参数超限/趋势退化/环境试验异常 |
| **控制限来源** | 历史数据拟合±3σ | 设计规范(Spec) + 历史型号数据 |
| **数据量级** | 秒级采集，日百万条 | 型号周期数据，测试数据量大但频次低 |
| **追溯需求** | VIN→工位→设备→焊点 | 卫星编号→单机→部件→元器件→批次 |
| **反馈闭环** | 推卡→确认/忽略→阈值调优 | 问题归零(航天术语)→技术状态更改→闭环验证 |
| **知识管理** | 故障树/8D报告/OWL本体 | 设计规范/故障模式/FMEA/归零报告 |

**关键共同点（面试必须强调）**：

1. **"从事后检验→事前预防"的转变** — 你做的SPC趋势检测+诊断Agent，正是航天质量管控最急需的能力
2. **"经验驱动→数据驱动"的升级** — 航天30年积累的工程经验大多在专家脑中/纸质文档里，亟需AI化
3. **全生命周期质量追溯** — 汽车的VIN追溯链 ≈ 卫星的产品保证数据包(PPDB)
4. **供应链协同** — 你管理56家供应商 ≈ 工大卫星管理20+家上下游企业

**航天特有概念（面试需了解）**：

| 术语 | 含义 | 对应你的经验 |
|------|------|-------------|
| **AIT** | 总装Assembly + 集成Integration + 测试Test | 相当于汽车的焊装+总装+下线检测 |
| **问题归零** | 航天质量管理最严格的闭环机制：技术归零5条+管理归零5条 | 类似你的诊断Agent完整闭环 |
