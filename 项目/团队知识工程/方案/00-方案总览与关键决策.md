# 方案总览与关键决策

> 本文是方案的唯一决策摘要。它定义产品目标、双资产范围、当前架构和阶段；具体流程、资产、治理、实现与验收见后续文档。

## 1. 产品定义

这是一个面向 40 人业务团队的**知识与 Skill 双资产 AI 工作台**，不是单独的聊天机器人、向量数据库或企业 Agent 平台。

它持续完成两件事：

- 把资料、会议、复盘和业务规则变成有来源、有人负责、可检索、可复核的知识；
- 把高频、低风险、可重复的业务任务变成有契约、可测试、可授权、可发布、可回滚的 Skill。

```text
知识：Agent 应该知道什么
Skill：Agent 应该如何完成一类任务
工作台：让知识和 Skill 被创建、治理、装载、运行和持续改进
```

## 2. 首期要同时证明两条链

选择一个低风险知识域和一个低风险高频任务，服务 5–8 名真实使用者：

```text
知识链：资料 → 候选知识 → 事实/范围确认 → Git/MR → WeKnora → 带来源的检索
Skill 链：任务需求 → Skill 草稿 → 契约/权限/effects → 测试回归 → Git/MR → 非生产 profile 装载

知识版本 + Skill digest + profile
  → DSH Agent 运行
  → 结果/人工纠正/业务结果
  → 知识复核或 Skill 回归任务
```

首期限制的是 Skill 的风险和环境，不是取消 Skill 管理。SkillHub 自动发布不可用时，使用 Git/CI + 管理员发布 + DSH 非生产 profile 完成闭环。

## 3. 核心决策

| 决策 | 当前结论 |
|---|---|
| 产品边界 | 知识资产管理、Skill 资产管理和 Agent 运行反馈 |
| 正式源 | Git + MR/CI + 人工审核 |
| 知识检索 | WeKnora，只接收已批准知识 |
| Skill 注册/分发 | SkillHub（验证后）或管理员流程 |
| Skill 执行 | DSH profile、loader、工具策略和人工确认 |
| 首期控制面 | 模块化单体 + 数据库任务表 + worker |
| 业务体验 | 业务人员提交、确认、审核、查询、反馈；不直接操作 Git |
| 首期 Skill | 一个低风险 Skill，完成创建、契约、测试、审核、非生产装载、运行和反馈 |
| Bot | 可选 Agent 协作层，不是资产治理权威 |
| 高风险动作 | 人工 gate、最小权限、真实状态读回、审计和回滚 |

## 4. 四条不可破坏的原则

1. **双资产、一套治理底座**：知识和 Skill 都有 owner、版本、来源、审核、权限、反馈和回滚，但两者不能混成一种资产。
2. **一类对象一个权威写入面**：Git 保存知识和 Skill 正式源；WeKnora 做知识索引；SkillHub 做 Skill 分发；DSH 做运行。
3. **状态必须有证据**：请求发出、HTTP 200、模型说完成，都不等于业务成功。
4. **自动化降低成本，不替代责任**：模型起草，脚本门禁，人确认事实、范围、风险和发布责任。

## 5. 阶段顺序

| 阶段 | 要证明的结果 | 进入条件 |
|---|---|---|
| P0 | 双资产模型、关系、样本、角色、schema、provider contract 和运行关联清楚 | 开始真实集成前 |
| P1 | 一个知识闭环 + 一个低风险 Skill 闭环可创建、审核、装载和运行 | P0 证据齐全 |
| P2 | 知识和 Skill 的运行反馈、质量报告和复核运营持续运行 | P1 有真实使用 |
| P3 | SkillHub 自动分发、多 profile、beta/stable 和回滚被真实验证 | P1/P2 稳定 |
| P4 | 只有出现规模/复用瓶颈时才演进 Console/Gateway/MCP/多 provider | 触发证据出现 |
| P5 | Bot 协作、Plugin 和高风险生产写入 | 安全、审批和回滚证据齐全 |

阶段由退出证据推进，不按日历自动升级。

## 6. 成功标准

MVP 退出时：

- 非程序员不操作 Git 也能创建知识草稿和 Skill 草稿；
- 正式知识有 owner、来源、适用范围、版本和复核日期；
- Skill 有 owner、输入/输出契约、知识依赖、权限/effects、测试和固定版本；
- 知识检索返回来源和版本，Skill 运行能反查 digest、profile 和 Git commit；
- 反馈能分别进入知识复核或 Skill 回归；
- 发布、装载、运行和回滚均有审计和人工接管路径；
- 至少有一个真实任务减少重复劳动或返工。

北极星指标是：**有引用且由固定 Skill 可靠完成的有效任务次数**。
