# 知识资产与生命周期

> 先定义正式知识，再定义 Skill。运行记忆、反馈和检索索引不是同一种资产。

## 1. 资产分层

| 资产 | 作用 | 首期 |
|---|---|---:|
| 原始证据 | 说明发生了什么 | 必须 |
| 知识卡片 | 沉淀事实、规则、案例、流程和决策 | 必须 |
| 运行记录 | 说明一次任务实际发生了什么 | 最小版 |
| 反馈/复核任务 | 说明哪里需要修订 | 必须 |
| Skill 包 | 固化一类可重复执行任务 | P3 |
| Plugin/MCP | 扩展运行时能力 | P4/P5 |
| Bot Memory | 运行时上下文和协作记忆 | 可选，不是正式知识 |

## 2. 知识卡片

正式条目至少包含：

```yaml
id: knowledge.<domain>.<name>
version: 1.0.0
kind: fact | rule | case | procedure | decision
status: candidate | reviewing | approved | publishing | published | stale | deprecated | rejected
owner: team-owner
steward: user-id
source_refs: []
applies_to: []
not_applies_to: []
last_reviewed_at: timestamp
next_review_at: timestamp
evidence_level: E0 | E1 | E2 | E3
sensitivity: public | internal | confidential | restricted
```

正文固定包含：

1. 一句话结论；
2. 已确认事实；
3. 依据和来源；
4. 适用条件；
5. 不适用范围和例外；
6. 推断或建议（单独标记）；
7. 反例和未知项；
8. 下一次复核条件。

模型可以预填，但贡献者确认事实和来源，steward 确认范围、例外和复核周期。

## 3. 证据等级

- `E0`：个人描述或未核验输入，只能作为候选；
- `E1`：有单一原始来源，并完成基本事实确认；
- `E2`：责任人确认，且有多个支持来源或可复现记录；
- `E3`：在多个相近场景验证，并有明确适用边界。

证据等级不是模型置信度。模型信心不能替代业务确认。

## 4. 知识生命周期

```text
captured
  → candidate
  → reviewing
  → approved
  → publishing
  → published
```

异常和终态：

- `index_failed`：正式源已批准，但新索引失败，旧索引继续服务；
- `index_unknown`：无法确认下游真实状态，必须对账；
- `stale`：到复核时间或出现冲突反馈；
- `deprecated`：不再适用但保留历史和替代关系；
- `rejected`：证据不足或不值得沉淀。

只有有真实索引确认时，才能从 approved/publishing 进入 published。

## 5. 来源、版本和引用

每条知识都要能反查：

```text
知识卡片 → source_refs → Git commit/MR → 审核人/时间
知识卡片 → WeKnora document/version/index_job
运行结果 → knowledge_id/version/source
```

原始敏感资料不应无选择地提交 Git。只保存脱敏正文、引用 ID 或受控附件；密钥、Cookie、个人敏感信息和大规模实时数据不得进入 Git、WeKnora 正文或 trace。

## 6. Skill 生命周期（P3 以后）

```text
scaffolded → proposed → reviewed → beta → stable
                                  ↘ rejected
stable → deprecated / withdrawn → retired
```

Skill 至少需要说明输入/输出 schema、依赖知识域、工具需求、effects、风险等级、兼容 profile、golden cases、回归结果、版本和 digest。Skill 不能自行授权、直接写正式知识或依赖漂移的 `latest`。

## 7. 资产之间的边界

- Skill 引用知识，不复制知识正文；
- WeKnora 是知识检索投影，不是知识审批系统；
- Bot Memory 是运行时上下文，不是正式知识；
- 反馈是候选和任务，不是正文；
- 运行记录是证据，不是组织规则。
