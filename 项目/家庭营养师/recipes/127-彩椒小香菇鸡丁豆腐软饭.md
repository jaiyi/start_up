# 彩椒小香菇鸡丁豆腐软饭

## 一句话定位

彩椒小香菇鸡丁豆腐软饭是 `彩色蔬菜 + 菌菇 + 鸡肉豆腐蛋白的宝宝软饭` 候选菜，适合用于 baby_meal, lunch, dinner 场景，后续可根据宝宝咀嚼和老人控糖反馈调整推荐权重。

## 适合家庭的原因

- 彩椒补充维生素 C 和颜色变化，小香菇增加鲜味，减少对酱油和盐的依赖；
- 鸡肉和豆腐提供动物蛋白 + 植物蛋白组合；
- 可做成宝宝软饭，也可给成人/老人做成少油拌饭或盖饭；
- 适合处理成小丁、软烂形态，便于宝宝练习咀嚼。

## 食材

### 共用食材

- 彩椒（红/黄彩椒优先）
- 小香菇或鹿茸菇
- 鸡胸肉或去皮鸡腿肉
- 豆腐
- 米饭或胚芽米软饭
- 葱姜水或姜片

### 宝宝额外食材

- 少量番茄碎（可选，用于增加汤汁和酸甜味）
- 少量胡萝卜碎（可选）

### 成人/老人共用版额外食材

- 少量生抽
- 少量盐
- 葱花
- 少量植物油
- 黑胡椒或白胡椒（成人可选，宝宝不用）

## 共用备菜

1. 鸡肉去皮、去筋膜，切成宝宝可接受的小丁或剁成粗肉末。
2. 彩椒去籽、去白筋，宝宝份建议去皮或切极小丁。
3. 小香菇或鹿茸菇洗净后切碎；如果用干香菇，泡发后充分清洗并切细。
4. 豆腐切小丁，宝宝份可压碎。
5. 米饭提前煮软，宝宝份可加少量水做成湿润软饭。

## 宝宝版

### 适用年龄和颗粒度

- 当前适配：1 岁 2 个月、8 颗牙；
- 优先形态：软饭、小丁、肉末、碎菇、压碎豆腐；
- 避免彩椒硬皮、大块鸡肉、大块香菇和干硬米饭。

### 做法

1. 锅中加少量水，放入鸡肉小丁和姜片，煮到鸡肉变白熟透后取出姜片。
2. 加入小香菇碎和彩椒小丁，小火煮到彩椒完全变软。
3. 加入豆腐丁和软米饭，继续煮成湿润软饭，不要炒干。
4. 宝宝份不加盐、不加生抽、不加糖；可用番茄碎和香菇自然提味。
5. 出锅前确认鸡肉能轻松压碎，彩椒皮不硬，香菇没有大块。

### 宝宝调味和禁忌

- 不使用添加糖、普通成人调味料、人工添加剂、辣味、油炸做法、腌制品、加工肉和肥肉。
- 花生、坚果、螃蟹、贝壳类默认不推荐。
- 香蕉谨慎 / 避免，芒果默认不主动推荐。
- 彩椒首次吃或不常吃时少量尝试，观察是否胀气或不接受。

## 成人/老人共用版

### 做法

1. 成人/老人份可用少量油先炒香鸡丁和小香菇，再加入彩椒和豆腐。
2. 加入少量水或番茄碎，做成带汤汁的浇头，最后拌入米饭或盖在米饭上。
3. 宝宝份分出后，成人份再用少量生抽或盐调味。
4. 老人份建议少饭、多菜、多鸡肉豆腐，不做油亮重口盖饭。

### 控糖控盐提醒

- 本菜含米饭，姥爷和奶奶份需要控制主食量；
- 彩椒和香菇可以提味，成人份也不需要重盐重酱；
- 如果当天已有土豆、玉米、粉丝、面条或粥，这道软饭的份量要相应减少。

## 好吃的小妙招

- 彩椒先切细再煮软，甜味会出来，不需要加糖。
- 小香菇或鹿茸菇先煮出鲜味，能减少酱油用量。
- 鸡腿肉比鸡胸肉更嫩；如果用鸡胸肉，可用葱姜水抓一下再煮。
- 豆腐后放，轻轻推匀，避免完全碎成渣。
- 宝宝份保持湿润，成人份可以收汁稍浓一点，更像盖饭。

## 阿姨执行提示

- 宝宝份彩椒要切很小并煮软，不能保留硬皮大块；
- 香菇类要切碎，避免宝宝咀嚼困难；
- 鸡肉必须完全熟透，出锅前夹一块确认内部无粉色；
- 做完后反馈：宝宝是否接受彩椒味、是否能咀嚼香菇、老人是否觉得饭量过多。

## 复热与留餐

- 宝宝份建议现做现吃，软饭复热后容易变干；
- 成人/老人份如需留餐，冷藏后当天或次日充分加热；
- 复热时可加少量水恢复湿润，不要再额外加盐。

## 推荐逻辑

- 优先推荐：当需要补充彩椒、菌菇、鸡肉和豆腐，且希望做宝宝软饭时。
- 降低推荐：当当天主食已经偏多、近期香菇/豆腐重复较多、或宝宝对彩椒接受度差时。
