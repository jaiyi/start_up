# 菜谱 Markdown 模板

> 适用于 `recipes/` 目录下的每一道菜谱。  
> 菜谱文件不按宝宝、成人、老人拆目录；所有分类、适用人群和改造方式都写进文件内部，方便 Weknora 检索。

---

## 1. 文件命名

建议格式：

```text
recipes/YYYY-MM-DD-菜名.md
```

如果不是按日期创建，也可以使用：

```text
recipes/菜名.md
```

## 3. 正文结构

每个菜谱默认使用以下结构：

```markdown
# 菜名

## 一句话定位

这道菜适合什么场景、解决什么问题。

## 适合家庭的原因

- 是否高蛋白；
- 是否少油；
- 是否能用常备食材；
- 是否能宝宝和大人共用备菜；
- 是否适合阿姨执行；
- 是否适合复热。

## 食材

### 共用食材

- 食材 A：数量
- 食材 B：数量

### 宝宝额外食材

- 可为空。

### 成人/老人共用版额外食材

- 可为空。

## 共用备菜

- 哪些食材可以统一洗、切、焯、蒸、煮；
- 哪一步之后需要给宝宝单独分出；
- 哪些食材需要切碎、小丁、软烂处理。

## 宝宝版

### 适用年龄和颗粒度

- 当前适配：1 岁 2 个月、8 颗牙；
- 适合形态：软饭、烩饭、面条、肉末、小肉丁、鱼肉块、虾滑、丸子、小块水果、蒸糕、厚蛋烧；
- 避免：大片、硬块、难咀嚼食材。

### 做法

1. 步骤一；
2. 步骤二；
3. 步骤三。

### 宝宝调味和禁忌

- 可少量使用宝宝专用酱油、海苔碎、虾皮、洋葱、番茄、菌菇、南瓜、红枣、黑芝麻等；
- 不使用成人调味料、添加糖、人工添加剂；
- 不使用花生、坚果、螃蟹、贝壳类；
- 默认不推荐香蕉和芒果。

## 成人/老人共用版

成人和老人不拆成两个完整做法，默认共用同一版。  
如有老人慢病、控糖、控盐、复热需要，在本节内部单独提示。

### 做法

1. 步骤一；
2. 步骤二；
3. 步骤三。

### 控糖控盐提醒

- 姥爷：少盐，不加糖或减少糖，注意主食量；
- 奶奶：注意高血糖风险，避免甜口和大量精制主食；
- 全家：少油，不用肥肉，减少浓油赤酱。

## 阿姨执行提示

- 最容易出错的步骤；
- 需要先给宝宝分出的时间点；
- 调味分离方式；
- 做完后需要反馈什么。

## 复热与留餐

- 是否适合姥姥姥爷晚餐复热；
- 如何保存；
- 如何复热；
- 哪些部分不建议复热。

## 采购清单

- 已有食材；
- 需要补买食材。

## 历史反馈

### YYYY-MM-DD

- 宝宝接受度：高 / 中 / 低 / 未吃；
- 成人接受度：高 / 中 / 低 / 未吃；
- 老人接受度：高 / 中 / 低 / 未吃；
- 阿姨执行难度：低 / 中 / 高；
- 问题：
- 下次调整：
- 推荐权重变化：上调 / 不变 / 下调。

## 推荐逻辑

- 什么情况下优先推荐；
- 什么情况下不推荐；
- 与哪些菜搭配更好。
```

## 4. 版本拆分原则

菜谱不拆成宝宝库、成人库、老人库。

每道菜内部只保留两个主要制作版本：

1. `宝宝版`；
2. `成人/老人共用版`。

老人不默认单独成版，只在 `成人/老人共用版` 中写：

- 控糖提醒；
- 控盐提醒；
- 主食量提醒；
- 是否适合复热；
- 是否适合姥姥姥爷晚餐留餐。

这样可以减少维护成本，也更符合家里实际执行方式。
