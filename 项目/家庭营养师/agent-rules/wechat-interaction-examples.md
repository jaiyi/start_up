# 微信交互示例

> 微信是家庭营养师 Agent 的主要低摩擦入口。  
> 目标是让用户用自然语言完成推荐、入库、反馈和菜谱收集。

---

## 1. 推荐早餐

用户：

```text
明天早饭吃什么？要高蛋白，宝宝也能吃。
```

Agent：

```text
明天早餐建议：

1. 宝宝 / 成人老人共用食材：西葫芦胡萝卜鸡肉饼
   - 宝宝版：少量宝宝酱油或不加调味，切小块；
   - 成人/老人共用版：出锅后单独调味，老人份少盐。

2. 鸡蛋：蒸蛋 / 蛋羹
   - 宝宝今天可完成 1 个鸡蛋目标。

3. 主食：玉米 + 面包 / 小馒头

4. 果盘：蓝莓、梨、哈密瓜
   - 宝宝份蓝莓压扁，梨切小块；
   - 不放香蕉和芒果。

5. 成人补充：酸奶碗可加坚果，宝宝份不加坚果。
```

## 2. 推荐宝宝午餐

用户：

```text
今天宝宝午饭吃什么？冰箱有牛肋条、胡萝卜、芹菜、冬瓜。
```

Agent：

```text
推荐：牛肉芹菜胡萝卜烩饭 + 冬瓜汤。

为什么适合：
1. 牛肋条适合午餐，不建议晚上吃；
2. 胡萝卜和芹菜可以切碎，适合宝宝当前颗粒度；
3. 冬瓜汤清淡，适合搭配；
4. 可以和老人午餐共用部分食材。

宝宝版注意：
- 牛肋条炖软后拆碎；
- 不用成人调味料；
- 可少量宝宝酱油；
- 芹菜切碎。

成人/老人共用版注意：
- 牛肉汤少盐；
- 姥爷控制米饭量；
- 汤底不要太咸。
```

## 3. 小红书链接处理

用户：

```text
这个小红书菜谱阿姨能做吗？
```

Agent：

```text
我先按我们家的规则判断：

结论：可改造后尝试。

原菜谱：黑椒鸡腿肉炒口蘑。

适合点：
- 鸡腿肉是常买食材；
- 口蘑全家都吃；
- 高蛋白；
- 阿姨可执行。

需要改造：
- 宝宝版不放黑胡椒和成人调味料；
- 鸡腿去皮，切小丁；
- 成人/老人共用版出锅后单独加黑胡椒；
- 姥爷份少盐，不加糖。

是否适合复热：一般。鸡腿肉可以，口蘑复热可以，但不建议放太久。

建议阿姨执行重点：
1. 鸡腿去皮；
2. 宝宝份先盛出；
3. 成人/老人共用份后调味；
4. 做完反馈宝宝是否接受鸡腿丁颗粒度。
```

## 4. 采购清单入库

用户：

```text
今天买了鸡蛋一盒、番茄 4 个、虾仁一袋、西兰花 2 颗、牛奶 2 瓶。
```

Agent：

```text
我识别到这些库存更新：

- 鸡蛋：1 盒
- 番茄：4 个
- 虾仁：1 袋
- 西兰花：2 颗
- 牛奶：2 瓶

我会把番茄和西兰花标记为优先消耗，虾仁标记为冷冻。
是否确认入库？
```

用户：

```text
确认。
```

Agent：

```text
已更新库存。

这几天可以优先安排：
1. 番茄虾滑口蘑小丸子汤；
2. 西兰花鸡蛋饼；
3. 虾仁豆腐羹。
```

## 5. 饭后反馈

用户：

```text
今天宝宝挺爱吃鸡肉饼，但是姥爷觉得有点干，阿姨说做起来还行。
```

Agent：

```text
已记录反馈：

- 宝宝：接受度高，鸡肉饼可以继续推荐；
- 姥爷：觉得偏干，下次成人/老人共用份增加汤羹搭配；
- 阿姨：执行难度可接受。

下次调整：
1. 鸡肉饼里增加西葫芦或山药提升湿润度；
2. 搭配冬瓜汤或番茄汤；
3. 宝宝份继续切小块。
```

## 6. 应季养生推荐

用户：

```text
这周有什么适合秋天的菜？要宝宝也能改着吃。
```

Agent：

```text
这周可以优先考虑：山药、莲藕、白萝卜、南瓜、梨、菌菇。

推荐 3 个方向：

1. 山药鸡肉丸子汤
   - 宝宝版：鸡肉剁细，山药压泥，丸子做小；
   - 成人/老人共用版：少盐，适合清淡汤羹。

2. 白萝卜牛肉汤
   - 牛肋条适合午餐，不建议宝宝晚上吃；
   - 成人/老人共用版少盐，姥爷注意控制主食。

3. 南瓜三文鱼粥
   - 宝宝晚餐友好；
   - 成人可以作为清淡早餐或晚餐搭配。

说明：这是日常应季饮食建议，不是医疗建议。
```
