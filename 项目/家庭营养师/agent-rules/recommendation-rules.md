# 推荐规则

> 本文件定义家庭营养师 Agent 在微信中推荐早餐、宝宝餐、工作日午餐、老人复热餐、新菜谱时的默认逻辑，并明确推荐必须结合当前库存，周末优先清理上周采购剩余食材。

---

## 1. 推荐输入

每次推荐前，Agent 应尽量读取：

- 家庭成员画像；
- 成员偏好和敏感食物；
- 家庭饮食规则；
- 当前库存；
- 常备食材库；
- 菜谱库；
- 做菜来源库；
- 最近用餐反馈；
- 最近吃过的菜；
- 当前餐次和时间条件。

---

## 2. 推荐评分因子

最小版使用规则评分，不需要复杂模型。

```text
总分 =
家庭目标匹配
+ 安全匹配
+ 库存匹配
+ 时间匹配
+ 成员接受度
+ 宝宝适配
+ 老人适配
+ 阿姨执行可行性
+ 复热友好
+ 来源可信
- 最近重复惩罚
- 改造成本惩罚
```

建议权重：

| 因子 | 权重 |
|---|---:|
| 安全匹配 | 必须通过 |
| 家庭目标匹配 | 0.20 |
| 库存匹配 | 0.20 |
| 成员接受度 | 0.15 |
| 宝宝适配 | 0.15 |
| 老人适配 | 0.10 |
| 时间匹配 | 0.10 |
| 阿姨执行可行性 | 0.05 |
| 复热友好 | 0.03 |
| 来源可信 | 0.02 |

安全匹配包括过敏、宝宝禁忌、老人慢病风险等，不能被其他高分覆盖。

---

## 3. 通用推荐规则

默认优先推荐：

- 高蛋白；
- 少油；
- 不要肥肉；
- 常备食材可做；
- 宝宝可共用部分食材；
- 宝宝版与成人/老人共用版可分开调味；
- 成人/老人共用版可做少盐、少油、控糖提醒；
- 阿姨能执行；
- 可根据反馈迭代。

默认降低推荐：

- 最近 3 天吃过；
- 需要复杂设备；
- 步骤过多；
- 油盐糖过重；
- 依赖肥肉；
- 宝宝无法共用食材；
- 老人不适合；
- 复热后口感差；
- 食材难买。

---

## 4. 库存优先和周末清库存规则

推荐必须优先考虑当前库存，尤其是上周采购后尚未消耗的蔬菜、肉蛋奶、豆制品、菌菇和根茎类。

每次推荐前，Agent 应先判断：

- 哪些食材已经在库存中；
- 哪些食材临近最佳食用期；
- 哪些食材是上周采购但还没用完；
- 哪些食材适合宝宝、成人和老人共用；
- 哪些食材只能进入成人/老人共用版；
- 哪些食材需要尽快消耗，避免浪费。

推荐优先级：

1. **必须先用库存**：能用库存完成的菜，优先于需要大量补买的菜；
2. **周末清库存**：周五晚到周日优先安排清库存菜单，目标是把上周买的菜尽量消耗掉；
3. **先消耗易坏食材**：绿叶菜、菌菇、鲜肉、鱼虾、豆制品优先于耐放根茎和冷冻食材；
4. **组合消耗**：优先推荐能一次消耗多种剩余食材的汤、烩饭、炖菜、蒸丸子、炒杂蔬、早餐盘；
5. **少补买**：周末清库存时，只允许补买关键蛋白、主食或调味必需品；
6. **不为了清库存牺牲安全**：过期、异味、状态不明、宝宝不适合或老人慢病不适合的食材不能强行推荐。

周末清库存输出时，应增加一段：

```text
本次清库存重点：
- 优先消耗：食材 A、食材 B、食材 C
- 暂时不动：耐放食材 D
- 需要补买：只列必要补买项
- 不建议使用：状态不佳或不适合成员的食材
```

如果库存信息缺失，Agent 不应直接假设库存充足，应先问：

```text
家里现在还有哪些菜/肉/蛋/豆制品需要优先消耗？
尤其是上周买了还没吃完的食材。
```

## 5. 早餐推荐规则

早餐面向爸爸妈妈、宝宝和在家老人。

家庭早餐有一个重要固定习惯：**通常要炒两个快手菜**，而不是只吃粥、糊、面包、牛奶或鸡蛋。Agent 推荐早餐时，必须默认按“两个快手菜 + 蛋白质 + 主食/奶/水果”的组合来设计。

两个快手菜的默认要求：

```text
1. 至少 1 个快手菜包含明确蛋白质，例如鸡蛋、虾仁、牛肉、鸡肉、猪肉丝/片/末、豆腐；
2. 至少 1 个快手菜包含青菜、菌菇或根茎类；
3. 尽量 10-15 分钟内可完成；
4. 少油、少盐，不用肥肉；
5. 可以和宝宝共用食材，但宝宝版需要少调味、切碎或做软；
6. 老人共用版需要少盐、软烂、控糖友好；
7. 优先使用库存里需要尽快消耗的蔬菜、鸡蛋、豆制品或肉类。
```

常见早餐快手菜方向：

```text
鸡蛋 + 青菜；
鸡蛋 + 菌菇；
虾仁 + 西兰花 / 口蘑 / 芦笋；
牛肉片 / 牛肉丝 + 青菜 / 菌菇；
猪肉丝 / 猪肉片 + 快熟蔬菜；
豆腐 / 干丝 + 青菜；
胡萝卜 / 土豆 / 山药等根茎类快炒或煎饼。
```

推荐结构：

```text
鸡蛋类
+ 奶 / 酸奶
+ 2 个快手菜
+ 至少 1 个有肉
+ 青菜
+ 根茎类 / 菌菇类
+ 主食
+ 果盘
```

早餐推荐要点：

- 爸爸妈妈是重度脑力工作者，需要足够蛋白质；
- 鸡蛋是高频基础食材；
- 宝宝每天尽量保证 1 个鸡蛋；
- 果盘要避开宝宝香蕉、芒果默认推荐；
- 成人可以吃坚果，宝宝不吃花生和坚果；
- 早餐不能只推荐“牛奶鸡蛋”，要给组合方案。

输出示例结构：

```text
今日早餐组合：
1. 鸡蛋 / 蛋羹；
2. 快手肉菜；
3. 青菜 / 菌菇 / 根茎；
4. 主食；
5. 水果；
6. 宝宝版处理；
7. 成人/老人共用版调整。
```

## 6. 宝宝餐推荐规则

宝宝餐重点：

- 营养均衡；
- 食材多样；
- 高蛋白；
- 当前颗粒度适配；
- 不用成人调味料；
- 和成人餐尽量共用食材；
- 午餐和晚餐分别做。

### 6.1 宝宝早餐

可参考已确认示例：

- 西葫芦胡萝卜鸡肉饼 + 黑芝麻红枣米糊；
- 青菜鳕鱼山药香菇蒸丸子 + 小馒头；
- 番茄虾滑口蘑小丸子汤 + 玉米；
- 蒸鸡蛋 + 南瓜三文鱼菠菜粥。

### 6.2 宝宝午餐

可参考已确认示例：

- 牛肉芹菜胡萝卜烩饭 + 冬瓜汤；
- 豆腐肉沫豆角烩饭 + 白萝卜牛肉汤。

午餐规则：

- 可以安排牛肋条、牛肉、肉类等较扎实蛋白；
- 适合烩饭、汤、丸子、软烂菜；
- 注意少油、无成人调味料。

### 6.3 宝宝晚餐

可参考已确认示例：

- 西红柿鸡蛋小油菜蝴蝶面；
- 黑芝麻山药红枣蒸糕；
- 菠菜胡萝卜厚蛋烧。

晚餐规则：

- 避免牛肋条等不好消化的重肉；
- 优先鸡蛋、鱼、虾滑、豆腐、面、粥、蒸糕、厚蛋烧；
- 口感软、易消化、不过重。

## 7. 工作日午餐推荐规则

工作日午餐由阿姨执行，是家庭饮食系统的核心场景。

推荐目标：

- 宝宝能吃；
- 老人能吃；
- 姥姥姥爷阶段可以留老人晚餐复热；
- 阿姨能按小红书链接和改造说明执行；
- 使用周末采购和常备食材；
- 高蛋白、少油、不要肥肉。

输出给阿姨时包括：

1. 菜名；
2. 原始来源 / 链接；
3. 家庭改造要点；
4. 宝宝版处理；
5. 成人/老人共用版处理；
6. 控糖控盐注意；
7. 是否适合复热；
8. 做完后需要反馈什么。

---

## 8. 老人复热推荐规则

姥姥姥爷阶段，晚餐通常复热中午饭。

适合复热：

- 汤；
- 炖菜；
- 烩菜；
- 烩饭；
- 豆腐类；
- 软烂肉菜；
- 部分根茎类菜。

不优先复热：

- 现炒脆嫩口感的绿叶菜；
- 容易复热变腥的鱼虾；
- 复热后变柴的瘦肉；
- 已经调味很重的菜；
- 宝宝吃剩混入口水的食物。

---

## 9. 新菜谱推荐和收集规则

新菜谱可以来自：

- 小红书；
- B站；
- 微信视频号；
- 老饭骨；
- Amanda；
- 宝宝辅食达人；
- 小思妈妈营养辅食；
- 其他动态搜索结果。

入库前必须判断：

- 是否适合家庭目标；
- 是否能用常备食材做；
- 是否能与宝宝共用食材；
- 是否可以分成宝宝版和成人/老人共用版；
- 成人/老人共用版是否需要控糖控盐提醒；
- 是否适合阿姨执行；
- 是否值得复做。

---

## 10. 应季养生推荐规则

应季养生食谱可以推荐，但要保持克制。

推荐方向：

- 普通应季食材；
- 汤羹；
- 蒸煮；
- 少油；
- 清淡；
- 老人友好；
- 宝宝可改造；
- 高蛋白搭配。

禁止：

- 宣称治疗疾病；
- 替代医生建议；
- 过度药膳化；
- 大量中药材；
- 不适合宝宝和慢病老人的偏方。

---

## 11. 推荐回复格式

微信中推荐时，优先使用简洁格式：

```text
推荐：菜名

为什么适合：
1. 命中哪些家庭目标；
2. 用到哪些现有食材；
3. 适合哪些成员；
4. 宝宝版怎么处理；
5. 成人/老人共用版怎么处理；
6. 控糖控盐和复热注意。

需要补买：
- 食材 A
- 食材 B

注意：
- 关键安全 / 调味 / 颗粒度提醒。
```

如果用户问“为什么”，再展开评分和来源。
