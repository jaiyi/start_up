# 菜谱来源库

> 本文件记录家庭营养师 Agent 可以参考的固定来源与动态搜索策略。  
> 原则：来源提供灵感和技法，进入家庭菜谱库前必须经过家庭规则过滤和改造。

---

## 1. 来源策略

采用：

```text
固定来源池
+ 动态搜索池
```

固定来源池用于长期积累可信菜谱和技法；动态搜索池用于发现小红书、视频号等平台上近期流行、适合家庭的快手菜和应季菜。

---

## 2. 已确认固定来源

### 2.1 老饭骨

定位：

- 学习食材处理技巧；
- 中餐技法；
- 肉类处理；
- 海鲜处理；
- 去腥、焯水、腌制、炖煮、火候、中餐味型。

使用规则：

- 不一定直接照搬整道菜；
- 重点学习食材处理和技法；
- 进入家庭菜谱库时需要少油、少盐、不要肥肉；
- 宝宝版必须单独处理；
- 姥爷 / 奶奶相关菜谱要考虑控糖控盐。

### 2.2 Amanda / 曼食慢语

定位：

- 家庭菜；
- 早餐 / brunch；
- 中西结合；
- 周末改善；
- 有品质感的家庭餐。

使用规则：

- 适合沉淀成家庭改良菜谱；
- 如果使用黄油、奶油、芝士较多，需要根据家庭少油目标改造；
- 宝宝版需要单独判断，成人/老人共用版需要保留控糖控盐提醒。

### 2.3 小高姐

定位：

- 面食；
- 主食；
- 家庭基础技法；
- 馒头、饼、包子、面条；
- 周末备餐。

使用规则：

- 适合作为宝宝主食、成人早餐、周末备餐来源；
- 耗时较长的菜不作为工作日临时推荐。

### 2.4 田螺姑娘

定位：

- 家庭日常餐；
- 一周菜单；
- 采购灵感；
- 城市家庭餐桌组合。

使用规则：

- 适合成人/老人共用版家常菜来源；
- 宝宝版需要改颗粒度和调味。

### 2.5 美食作家王刚

定位：

- 中餐技法；
- 肉菜；
- 火候；
- 调味逻辑。

使用规则：

- 适合作为技法来源；
- 默认需要大幅少油、少辣、少盐改造；
- 不直接推荐给宝宝；
- 不直接用于姥爷控糖控盐餐。

### 2.6 日食记

定位：

- 应季；
- 汤羹；
- 家庭氛围感；
- 周末改善。

使用规则：

- 适合作为应季和家庭改善灵感；
- 需要 Agent 提炼成可执行版本。

### 2.7 詹姆士的厨房

定位：

- 中西融合；
- 家常技巧；
- 调味思路；
- 快手菜；
- 家庭可复制菜。

使用规则：

- 适合成人餐、爸爸周末菜、高蛋白肉菜；
- 宝宝版需要单独处理。

## 3. 宝宝辅食与儿童饮食来源

### 3.1 宝宝辅食达人

定位：

- 宝宝辅食；
- 幼儿餐；
- 蒸糕；
- 饼；
- 丸子；
- 烩饭；
- 汤面；
- 手指食物。

使用规则：

- 优先筛选 12M+、高蛋白、无糖、少盐、软烂小块类型；
- 避免糖、普通调味料、添加剂；
- 排除花生坚果类；
- 避开香蕉、芒果、螃蟹、贝壳类默认推荐。

### 3.2 小思妈妈营养辅食

定位：

- 宝宝餐；
- 营养搭配；
- 辅食结构；
- 宝宝主食；
- 高蛋白组合。

使用规则：

- 适合宝宝每日菜单、食材多样性和颗粒度进阶；
- 进入家庭菜谱库前必须按宝宝当前禁忌和调味规则改造。

### 3.3 年糕妈妈 / 丁香妈妈

定位：

- 宝宝饮食安全；
- 月龄饮食建议；
- 过敏引入；
- 营养原则；
- 喂养误区；
- 儿童健康科普。

使用规则：

- 主要作为宝宝饮食原则来源；
- 不一定作为具体菜谱主来源；
- 适合校验月龄、颗粒度、过敏和安全边界。

### 6.3 动态来源筛选原则

候选菜谱进入家庭菜谱库前，必须判断：

- 是否高蛋白；
- 是否少油；
- 是否避免肥肉；
- 是否能用常备食材或盒马 / 物美买到；
- 是否能和宝宝共用部分食材；
- 宝宝版是否能去掉糖、普通调味料和添加剂；
- 成人/老人共用版是否能少盐、少油、控糖友好；
- 阿姨是否能按链接和改造说明执行；
- 是否适合工作日，还是只适合周末；
- 是否适合姥姥姥爷晚餐复热；
- 是否需要复杂设备或步骤；
- 是否只是摆拍好看但不适合家庭长期做。

## 7. 应季养生食谱来源

可以收集和推荐养生应季食谱。

### 7.1 适合方向

- 应季食材；
- 节气饮食；
- 温和养生；
- 汤羹；
- 润燥；
- 清淡；
- 健脾胃；
- 少油；
- 老人友好；
- 宝宝可改造。

### 7.2 边界

- 不做中医诊断；
- 不宣称治疗疾病；
- 不替代医生建议；
- 避免过度药膳化；
- 不收集需要大量中药材的复杂方；
- 优先普通食材、家庭可买、可执行。
