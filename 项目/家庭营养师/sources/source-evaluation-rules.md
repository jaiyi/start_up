# 菜谱来源与入库评估规则

> 用于判断外部菜谱、博主内容、小红书链接、视频号内容是否适合进入家庭菜谱库。

---

## 1. 入库基本原则

外部菜谱不能直接进入家庭常用菜谱库，必须先经过家庭适配判断。

判断重点：

```text
适不适合这个家庭；
能不能用常备食材做；
宝宝能否共用食材；
宝宝版与成人/老人共用版能否分开调味；
成人/老人共用版是否能满足少油、控糖、控盐等要求；
阿姨是否能执行；
是否值得复做。
```

---

## 2. 必须通过的筛选项

一条菜谱进入候选库前，需要判断：

| 维度 | 问题 |
|---|---|
| 高蛋白 | 是否有明确蛋白质来源 |
| 少油 | 是否可以少油完成 |
| 不要肥肉 | 是否依赖五花肉、肥肉、肥羊等 |
| 食材可得 | 是否能用常备食材、盒马、物美或周末采购解决 |
| 宝宝共用 | 是否能与宝宝共用部分食材 |
| 宝宝改造 | 是否能去掉糖、成人调味料、添加剂 |
| 老人友好 | 是否能少盐、少油、控糖友好 |
| 阿姨执行 | 是否能按链接和改造说明执行 |
| 复热 | 是否适合姥姥姥爷晚餐复热 |
| 时间 | 适合工作日还是周末 |
| 设备 | 是否需要复杂设备 |
| 真实可做 | 是否只是摆拍好看但不适合家庭长期做 |

---

## 3. 降权条件

出现以下情况应降低推荐权重：

- 太油；
- 太辣；
- 肥肉多；
- 糖多；
- 调味料复杂；
- 人工添加剂多；
- 半成品太多；
- 食材难买；
- 步骤太多；
- 宝宝完全无法共享食材；
- 老人不适合；
- 复热后口感明显变差；
- 只适合拍照、不适合长期家庭执行。

---

## 4. 小红书 / B站 / 微信视频号链接处理规则

当用户发来小红书、视频号或其他菜谱链接时，Agent 应输出：

1. 原菜谱一句话总结；
2. 是否适合这个家庭；
3. 宝宝版怎么改；
4. 成人/老人共用版怎么改；
5. 控糖 / 控盐 / 复热注意事项；
6. 阿姨执行注意事项；
7. 需要采购什么；
8. 是否适合姥姥姥爷晚餐复热；
9. 做完后的反馈记录点。

输出应控制在微信一屏到两屏内，优先给可执行信息。

---

## 5. 宝宝版改造规则

外部菜谱若要给宝宝吃，必须检查：

- 是否含糖；
- 是否含普通成人调味料；
- 是否含人工添加剂；
- 是否含花生 / 坚果；
- 是否含螃蟹 / 贝壳类；
- 是否含辣；
- 是否油炸；
- 是否有腌制品、加工肉、肥肉；
- 颗粒度是否适合 1 岁 2 个月、8 颗牙阶段；
- 是否需要切碎、小丁、软烂、丸子、饼、蒸糕等形态改造。

宝宝版可以使用：

- 少量宝宝专用酱油；
- 海苔碎；
- 虾皮；
- 洋葱；
- 番茄；
- 菌菇；
- 南瓜；
- 红枣；
- 黑芝麻。

---

## 6. 成人/老人共用版改造规则

成人和老人不默认拆成两个独立做法，应使用同一个成人/老人共用版；只有在慢病、控糖、控盐、复热上需要额外注意时，在共用版内部写提醒。

改造方向：

- 少盐；
- 少油；
- 不用肥肉；
- 不加糖或大幅减少糖；
- 减少浓油赤酱；
- 姥爷注意控制主食量；
- 奶奶注意高血糖风险；
- 增加蛋白质和蔬菜；
- 避免过咸汤底；
- 避免加工肉和腌制品。

---

## 7. 老饭骨等技法来源处理

老饭骨、王刚等来源可以用于学习：

- 去腥；
- 焯水；
- 腌制；
- 炖煮；
- 火候；
- 肉类处理；
- 海鲜处理；
- 中餐味型。

但进入家庭菜谱库时，必须做家庭化改造：

- 少油；
- 少盐；
- 不要肥肉；
- 宝宝版单独做；
- 成人/老人共用版统一处理，内部注明控盐控糖提醒；
- 不直接照搬重口味调味。

---

## 8. 应季养生食谱评估规则

应季养生食谱可以收集，但必须满足：

- 使用普通食材；
- 家庭可买；
- 做法可执行；
- 不过度药膳化；
- 不宣称治疗疾病；
- 不替代医生建议；
- 能拆成宝宝版和成人/老人共用版，成人/老人共用版内部保留控糖控盐提醒。

优先推荐：

- 山药；
- 南瓜；
- 白萝卜；
- 莲藕；
- 菌菇；
- 梨；
- 冬瓜；
- 番茄；
- 高蛋白汤羹；
- 少油蒸煮菜。

---

## 9. 入库结论格式

每个外部菜谱处理后，输出以下结论之一：

```text
可直接入库；
可改造后入库；
仅作为技法参考；
仅适合成人 / 周末；
暂不适合宝宝；
暂不适合老人；
不建议收录。
```

并说明原因。
