# Skill: meal-recommender

## 1. 目标

为家庭生成下一餐或多餐推荐，兼顾：

```text
库存优先；
早餐两个快手菜；
宝宝适配；
成人健康；
老人控盐控糖和复热；
阿姨可执行；
近期不重复；
周末清库存。
```

## 2. 输入

```text
用户需求：今晚吃什么 / 周末清库存 / 宝宝餐 / 阿姨菜单等；
当前库存：inventory/current-inventory.md；
采购记录：inventory/purchase-log.md；
近期菜单：meals/recent-menu-log.md；
反馈记录：meals/meal-feedback-log.md；
家庭画像：family/*.md；
菜谱库：recipes/*.md；
推荐规则：agent-rules/recommendation-rules.md。
```

## 3. 决策步骤

```text
1. 判断用户要推荐哪一餐、几个人吃、是否有时间限制。
2. 读取当前库存，找出优先消耗食材。
3. 读取近 14 天菜单，排除近期高频菜。
4. 检索适配菜谱。
5. 判断宝宝版和成人/老人版是否可共用。
6. 估算库存消耗和必要补买项。
7. 输出推荐和计划消耗。
8. 等待用户确认执行。
```

## 4. 输出格式

```markdown
## 推荐菜单

- 菜 1
- 菜 2
- 菜 3

## 为什么适合

- 库存：...
- 家庭适配：...
- 近期不重复：...

## 宝宝版处理

...

## 成人/老人版处理

...

## 预计库存消耗

- 食材 A：...
- 食材 B：...

## 需要补买

- 无 / 只需补买 ...

## 复热说明

...

## 菜单记录建议

```text
日期：YYYY-MM-DD
餐次：晚餐
状态：recommended
菜单：...
计划消耗：...
```

## 是否确认执行

如果确认执行，我会把它记录为 planned；饭后无反馈则默认正常并扣减库存。
```

## 5. 边界

```text
不直接扣减库存；
不写入菜谱库；
不忽略宝宝和老人约束；
不为了清库存使用状态不明或不适合的食材。
```
