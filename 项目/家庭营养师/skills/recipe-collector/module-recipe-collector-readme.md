# recipe-collector

> 收集新菜谱、判断家庭适配性、生成标准菜谱 Markdown。

## 职责

```text
把用户提供的新菜谱链接、截图、文案或视频摘要，转成家庭菜谱库可收录的标准菜谱卡。
```

## 触发场景

```text
这个菜谱能收吗？
这个小红书菜谱适合宝宝吗？
帮我整理成菜谱卡。
这个视频里的做法能不能改造？
```

## Web Search 边界

```text
允许：菜谱收集、来源核对、做法补全。
禁止：日常推荐、库存更新、饭后反馈。
```

## 输出

```text
是否建议收录；
家庭适配判断；
宝宝版；
成人/老人共用版；
复热判断；
风险提示；
标准 Markdown；
是否确认入库。
```
