# 家庭常备食材库

> 本文件记录家庭常买、常用、适合进入菜谱推荐的食材。  
> 用途：辅助 Agent 判断菜谱是否适合家庭、是否容易采购、是否能和宝宝餐共用备菜。  
> 注意：本文件不是“当前冰箱库存”，而是家庭常备和可采购食材范围；当前是否有货仍以 `inventory/current-inventory.md` 为准。

---

## 1. 常买蛋白质

### 1.1 蛋奶类

常备：

- 鸡蛋；
- A2 牛奶；
- 无糖酸奶；
- 吾岛无糖酸奶；
- 简爱无糖酸奶。

使用规则：

- 鸡蛋是家庭早餐和宝宝餐基础蛋白质，宝宝每天尽量保证 1 个；
- A2 牛奶是宝宝当前常喝奶；
- 无糖酸奶可作为下午奶替代或早餐搭配；
- 酸奶默认选择无糖、配料表简单的版本；
- 成人酸奶碗可以加坚果，宝宝份不加花生和坚果。

### 1.2 猪肉

常买：

- 梅花肉；
- 里脊；
- 排骨；
- 肉馅；
- 猪肉片；
- 猪肉丝；
- 猪肉末；
- 培根。

使用规则：

- 家庭整体不要肥肉；
- 梅花肉适合宝宝和老人，因为比纯瘦肉更嫩，但要去明显肥油；
- 里脊适合快手菜，但要避免做柴；
- 排骨适合汤和炖煮；
- 肉馅、猪肉末适合丸子、饼、馄饨、烩饭；
- 猪肉片、猪肉丝适合快手炒菜、汤面、早餐肉菜；
- 培根属于加工肉，适合成人早餐或调味少量使用，宝宝默认不推荐，姥爷和奶奶不作为常规推荐。

### 1.3 牛肉

常买：

- 牛肋条；
- 牛排；
- 肥牛；
- 牛腩。

偶尔有：

- 牛腱子。

使用规则：

- 牛肋条适合午餐、炖煮、汤、烩饭；
- 宝宝晚上一般不吃牛肋条，避免不好消化；
- 牛排更偏周末 / 成人改善餐；
- 肥牛适合快手汤、寿喜锅、烩饭或早餐肉菜，但油脂和钠调味容易偏高，宝宝和控糖控盐人群需谨慎；
- 牛腩家里常吃，适合番茄牛腩、萝卜牛腩、土豆牛腩等炖煮菜，需要撇油和控制调味；
- 牛腱子多为过节偶尔获得，适合炖煮、卤后凉拌或切片搭配，但老人控盐需要注意卤味咸度。

### 1.4 羊肉

偶尔有：

- 羊肉；
- 羊蝎子。

使用规则：

- 羊肉、羊蝎子多为过节偶尔获得，不作为日常稳定库存；
- 更适合周末、节日或冬季改善餐；
- 油脂、膻味和调味通常较重，宝宝默认谨慎，姥爷和奶奶需要少盐少油。

### 1.5 鸡肉

常买：

- 鸡胸；
- 鸡腿。

使用规则：

- 鸡胸适合宝宝饼、丸子、肉末、成人高蛋白快手菜；
- 鸡腿肉更嫩，适合宝宝和老人，但要去皮少油。

### 1.6 鱼虾海鲜

常买 / 常用：

- 基围虾；
- 黑虎虾；
- 银鳕鱼；
- 三文鱼；
- 鱼丸。

超市可买候选鱼类：

- 鲈鱼；
- 海鲈鱼；
- 黄花鱼；
- 鲳鱼；
- 多宝鱼；
- 桂鱼 / 鳜鱼；
- 鳕鱼块；
- 龙利鱼；
- 巴沙鱼；
- 带鱼；
- 鲫鱼；
- 青花鱼 / 鲭鱼。

超市可买候选虾贝类：

- 虾仁；
- 大虾；
- 河虾；
- 虾滑；
- 虾皮；
- 扇贝；
- 蛤蜊 / 花蛤；
- 蛏子；
- 青口贝；
- 生蚝；
- 鲍鱼；
- 瑶柱 / 干贝；
- 扇贝丝。

青岛可能带来的海鲜 / 干货：

- 海捕虾；
- 鲅鱼；
- 平鱼；
- 偏口鱼；
- 带鱼；
- 鲍鱼；
- 海参；
- 干贝；
- 海米；
- 其他青岛海鲜或干货。

默认不纳入家庭常用：

- 鱿鱼；
- 墨鱼；
- 八爪鱼等头足类。

使用规则：

- 鱼虾是家庭高蛋白核心食材；
- 宝宝已吃过虾、银鳕鱼、三文鱼；
- 新增鱼类给宝宝前，需要关注刺、汞风险、脂肪含量、产地、是否养殖、是否有可靠供应链；
- 超市活鱼不因为“活”就默认更优，购买时需要关注水质、来源、是否有可靠标签和追溯信息；
- 鱼丸、虾滑等加工食材需要注意配料表，宝宝版默认避免添加剂、糖、成人调味料和过高钠；
- 螃蟹需要避开爸爸和奶奶；
- 贝壳类大人吃，宝宝没吃过，默认不放入宝宝餐；
- 扇贝丝可作为成人/老人共用版提鲜方式，宝宝餐默认不使用，除非明确确认；
- 头足类家里一般不吃，不作为默认推荐来源。

### 1.7 豆制品

常买：

- 豆腐；
- 北豆腐；
- 南豆腐 / 嫩豆腐；
- 内酯豆腐；
- 干丝；
- 毛豆。

使用规则：

- 豆腐适合宝宝、老人和控糖 / 高蛋白搭配；
- 北豆腐适合煎、炖、烧，蛋白质密度较高；
- 南豆腐 / 嫩豆腐适合汤羹、蒸蛋、宝宝软烂菜；
- 内酯豆腐适合羹、蒸、拌，但调味需要清淡；
- 干丝适合成人和老人，宝宝是否吃要看切法和咀嚼情况；
- 毛豆可作为高蛋白配菜，宝宝吃需要去壳、软烂并注意颗粒大小。

### 2.2 根茎 / 瓜茄类

- 土豆；
- 山药；
- 南瓜；
- 红薯；

### 2.3 菌菇类

- 杏鲍菇；

### 2.4 蔬菜共识

- 以上蔬菜全家包括宝宝都吃；

- 成人/老人共用版优先少油少盐；
- 工作日推荐优先使用这些常备蔬菜；
- 绿叶菜更适合现做现吃，不优先作为姥姥姥爷晚餐复热主菜；
- 根茎类、菌菇类、炖煮类更适合复热和留餐。

## 4. 水果

常买 / 可买：

- 蓝莓；
- 黑莓；
- 百香果；
- 应季水果；
- 桃子；
- 葡萄；
- 樱桃；
- 柚子；
- 西瓜；
- 梨；
- 哈密瓜；
- 苹果；
- 橙子；
- 橘子；
- 猕猴桃；
- 草莓；
- 牛油果；
- 火龙果；
- 李子；
- 杏；
- 石榴；
- 枣；
- 无花果；
- 柿子。

宝宝水果规则：

- 香蕉会嘴周红，默认谨慎 / 避免；
- 芒果没吃过，默认不主动推荐；
- 葡萄、樱桃需要去核切小；
- 蓝莓、黑莓根据大小压扁或切开；
- 西瓜、哈密瓜需要切小块并注意不过量；
- 百香果偏酸，宝宝是否适合需要看接受度；
- 猕猴桃、橙子、橘子等酸味水果需要观察口周刺激；
- 石榴不推荐宝宝直接吃籽；
- 枣需要去核，且糖分较高；
- 柿子宝宝和老人都不宜空腹或过量。

## 5. 调味和提鲜

### 5.1 宝宝可用 / 低风险提味

- 洋葱；
- 番茄；
- 菌菇；
- 南瓜；
- 红枣；
- 黑芝麻；
- 海苔碎；
- 虾皮；
- 宝宝专用酱油。

使用规则：

- 虾皮、海苔和宝宝酱油都有钠，只能少量使用；
- 宝宝餐不使用添加糖、普通成人调味料、人工添加剂；
- 宝宝餐不默认使用贝壳类、扇贝丝、干贝、瑶柱。

### 5.2 成人/老人共用版常用

- 生抽；
- 老抽；
- 蚝油；
- 醋；
- 香油；
- 料酒；
- 白胡椒；
- 黑胡椒；
- 花椒；
- 八角；
- 桂皮；
- 香叶；
- 孜然；
- 番茄膏；
- 黄豆酱 / 甜面酱；
- 豆瓣酱。

使用规则：

- 成人/老人共用版可以后调味；
- 姥爷和奶奶需要注意控糖控盐；
- 黄豆酱、甜面酱、豆瓣酱等高钠或含糖调味要谨慎；
- 辣味、重酱、火锅底料、预制酱料包不作为日常推荐。

## 6. 海鲜和提鲜补充规则

- 贝壳类大人都吃；
- 家里喜欢用扇贝丝爆锅提鲜；
- 扇贝丝、干贝、瑶柱可作为成人/老人共用版提鲜方式；
- 宝宝餐默认不使用贝壳类、扇贝丝、干贝、瑶柱，除非明确确认；
- 奶奶、爷爷可能会从青岛带海鲜或食材，需要作为特殊库存录入；
- 头足类家里一般不吃，不作为默认推荐。

---

## 7. 采购渠道和节奏

- 爸爸妈妈周末统一采购；
- 姥姥姥爷阶段主要使用盒马、物美超市能买到的食材；
- 奶奶爷爷阶段可能会从青岛带海鲜或食材；
- 超市能稳定买到的鱼类和海鲜可以进入候选食材清单，用于丰富菜谱和周末采购建议。

Agent 推荐时应优先考虑：

- 周末采购后库存；
- 盒马 / 物美可买到的常见食材；
- 鲜蔬优先消耗；
- 青岛带来的海鲜作为特殊库存，不默认长期稳定供应；
- 候选食材不等于当前库存，推荐前仍需确认是否已购买。
