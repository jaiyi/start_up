# 项目

存放有独立目标、代码、测试、部署或持续迭代节奏的实战项目。

- [家庭营养师](./家庭营养师/)：家庭饮食知识、Agent、MCP 状态服务和部署配置
- [SPC-DeepSeek-Harness](./SPC-DeepSeek-Harness/)：以 SPC 工业质量异常闭环验证 AI 平台能力的具体试点项目
- [个人研究与决策操作系统](./个人研究与决策操作系统/)：外部信号、研究、洞察、项目验证和知识沉淀的自动流转设计

## AI 平台方向的项目边界

`AI Native 任务闭环平台` 目前属于 [`洞察/AI原生转型/`](../洞察/AI原生转型/) 下的方向判断和设计推演，不作为独立实战项目维护。当前真正进入项目层、用于验证 AI 平台能力的是 [`SPC-DeepSeek-Harness/`](./SPC-DeepSeek-Harness/)：它以具体 SPC 场景为边界，记录实现、测试、集成和验证结果。只有经过试点验证的通用能力，才回流为平台判断或 `知识/` 中的可复用方法。

项目内部的设计、计划、决策、专属资料、代码和测试应保持闭环；不要把项目实施文档重新放回全仓库管理目录。
