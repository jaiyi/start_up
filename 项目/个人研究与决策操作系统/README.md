# 个人研究与决策操作系统

这是一个用于让个人知识积累、外部研究、洞察形成、项目设计和实践反馈持续流转的长期项目。

当前问题不是资料不足，而是流程依赖人工记忆和主动提问：外部信息容易遗漏，研究与已有认知之间缺少自动关联，项目完成后的验证结果也没有稳定回流。因此本项目先把这套“研究与决策飞轮”设计成可持续演进的系统，再分阶段实现自动化。

## 目标闭环

```text
外部信号
  ↓
收件箱与候选队列
  ↓
事实研究
  ↓
洞察候选与人工确认
  ↓
项目上下文包与架构设计
  ↓
项目实现、测试和验证
  ↓
知识候选与反馈记录
  ↓
更新研究优先级、个人学习输入和雷达规则
```

系统的目标不是替代个人判断，而是让重要信息不易遗漏，让历史研究能够被重新调用，让每次项目实践都能提高下一轮研究和决策质量。

## 与仓库其他目录的边界

- `资料/` 保存尚未分流的原始材料；
- `研究/` 回答外部对象是什么，保留事实、证据和不确定性；
- `洞察/` 记录经过个人判断的归纳、取舍和方向；
- `项目/` 将判断转化为设计、实现和验证；
- `知识/` 保存经过实践或充分验证后可以跨项目复用的方法；
- `管理/` 保存整个知识库的通用规范，不承载本项目的具体设计和实施计划。

本项目的设计、计划、队列契约和后续实现均放在本目录内，不把项目级文档重新放回 `管理/`。

## 当前阶段

当前只完成设计归档，不实现爬虫、GitHub API、RSS、微信/小红书接入、定时任务或自动 Agent 编排。后续优先从低风险、可人工审核的收件箱和候选队列开始。
