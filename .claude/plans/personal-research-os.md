# 个人研究与决策操作系统项目归档计划

## 目标

在 `项目/` 下建立“个人研究与决策操作系统”项目，先将当前提出的自动流转设计固化为项目级设计文档，不立即实现自动抓取、Agent 编排或外部服务集成。

## 目录

```text
项目/个人研究与决策操作系统/
├── README.md
└── 设计/
    ├── 01-总体架构与目标.md
    ├── 02-信息捕获与外部信号雷达.md
    ├── 03-研究洞察项目知识流转.md
    ├── 04-上下文包与教育反馈.md
    └── 05-MVP实施路线与安全边界.md
```

## 内容范围

1. README：说明项目定位、与 `管理/` 及其他项目的边界、当前阶段和后续演进方式。
2. 总体架构：描述 Signal Radar、Research Pipeline、Insight Engine、Project Copilot、Learning Loop 五个子系统，以及人工确认边界。
3. 信息捕获与雷达：描述微信/小红书/同事分享等人工输入、GitHub/官方发布等主动发现、收件箱和研究队列的状态模型。
4. 研究洞察项目知识流转：明确事实、判断、设计、验证、知识之间的转换契约，避免未经验证的推断自动升级。
5. 上下文包与教育反馈：描述项目上下文包、跨文档关联、Tutor 机制、每周学习输入和反思问题。
6. MVP 实施路线：分阶段定义收件箱、雷达、研究草稿、洞察候选、项目反馈回流的建设顺序，并规定权限、隐私、人工审批和失败记录边界。

## 不在本次范围

- 不实现爬虫、GitHub API、RSS、微信或小红书接入；
- 不创建真实的自动化脚本、定时任务或外部服务凭据；
- 不移动现有研究、洞察、知识和项目文件；
- 不把候选洞察自动写入正式洞察；
- 不提交或推送 Git，除非用户后续明确要求。

## 验证

- 检查新项目目录和文档索引；
- 检查新增 Markdown 相对链接；
- 执行 `git diff --check`；
- 查看工作区状态和变更摘要。
