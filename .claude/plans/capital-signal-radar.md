# 补充资本与生态信号雷达设计计划

## 目标

将硅谷投资机构、融资事件和资本生态判断纳入 `项目/个人研究与决策操作系统/` 的外部信号雷达，作为发现未来方向的重要线索来源，同时明确资本信号不是产品能力或市场成功的直接证据。

## 变更范围

1. 新增 `设计/06-资本与生态信号雷达.md`：
   - 资本信号的定位与证据边界；
   - 资本、产品、采用、生态动量四类信号交叉验证；
   - 投资事件最小数据结构；
   - 与当前 Agent Runtime、Control Plane、Coding Agent、Agent Learning、知识/语义层、工业 AI、SPC 和 AI Native 平台方向的映射；
   - 从融资事件到研究候选、洞察候选、项目实验的流转；
   - 研究优先级和反误判规则。
2. 更新项目 `README.md`：把资本与生态信号雷达加入设计目录和目标闭环说明。
3. 更新 `设计/01-总体架构与目标.md`：将资本信号纳入 Signal Radar 输入，并把 `Capital Signal` 纳入核心对象和成功标准。
4. 更新 `设计/02-信息捕获与外部信号雷达.md`：增加资本信号来源、字段、优先级和四信号交叉验证入口，并链接专门设计文档。
5. 更新 `设计/05-MVP实施路线与安全边界.md`：在公开信号雷达阶段加入融资/投资事件，补充资本信号验证指标和反误判安全边界。

## 明确不做

- 不实时调研或罗列具体融资新闻；
- 不实现融资数据爬虫、Crunchbase/PitchBook 等付费数据接入；
- 不把投资金额、知名投资机构或融资轮次自动转换为产品结论；
- 不改变已有研究、洞察或项目分类；
- 不提交或推送 Git，除非用户后续明确要求。

## 验证

- 检查新增文档和项目 README 索引；
- 检查新旧文档 Markdown 相对链接；
- 执行 `git diff --check`；
- 查看工作区状态和变更摘要。
