## 1. 半导体产业链（30秒版）

```
设计(Design) → 制造/晶圆代工(Foundry) → 封装测试(Package & Test) → 销售
   ↑兆易在这                ↑长鑫/台积电              ↑外包封测厂(OSAT)
  (fabless)              (兆易不做)              (兆易委外)
```

- **兆易做什么**：芯片设计（NOR Flash / DRAM / MCU / 模拟 / 传感器）
- **兆易不做什么**：晶圆制造（交长鑫）、封装（交封测厂）
- **含义**：兆易的数据 = 设计验证数据 + 委外的测试数据 + 供应链/产能数据 + 销售数据

---

## 2. 核心概念：良率 Yield（最重要，必问）

**良率 = 良品数 / 投入总数**。半导体最核心的KPI，直接决定成本和利润。

| 术语 | 含义 | 类比你熟悉的 |
|------|------|-------------|
| **Wafer Yield（晶圆良率）** | 一片晶圆上能切出多少好芯片 | 类似产线良品率 |
| **Die（裸片/晶粒）** | 晶圆上切下来的单颗芯片 | 单个产品 |
| **CP Yield** | 晶圆测试阶段良率 | 中间检验合格率 |
| **FT Yield** | 成品测试阶段良率 | 终检合格率 |
| **良率爬坡(Yield Ramp)** | 新产品量产初期良率逐步提升的过程 | 产线导入期爬坡 |
| **失效分析(FA, Failure Analysis)** | 分析芯片为什么坏、定位根因 | 你做的根因诊断！ |

> 🔑 **你的话术**："良率分析本质是找出'哪批/哪台/哪个参数导致不良'——和我做的CPK趋势归因（急性/慢性、漂移/散度）是同一个逻辑。"

## 3. 芯片测试数据（fabless公司数据主战场）

芯片流片回来要经过多轮测试，每次测试都产生海量数据：

| 术语 | 全称/含义 | 说明 |
|------|----------|------|
| **CP** | Chip Probing / 晶圆测试 | 晶圆还没切割，用探针台逐个die测试 |
| **FT** | Final Test / 成品测试 | 封装后成品测试 |
| **WAT/WLT** | Wafer Acceptance Test | 晶圆验收测试，测工艺参数是否合格 |
| **ATE** | Automated Test Equipment | 自动测试机台，产生测试数据的源头 |
| **Bin（分箱）** | 测试后按结果分类的"箱子" | Bin1=好品，其他Bin=各类失效，**核心分析维度** |
| **Bin Map / Wafer Map** | 晶圆上每个die的Bin分布图 | 看失效的空间分布（边缘失效？中心失效？） |
| **Test Program** | 测试程序 | 定义测哪些项、判定标准 |

> 🔑 **Bin分析**是半导体数据分析的日常：统计各Bin占比、看Wafer Map空间聚集（边缘掉良率通常=工艺问题）、追Bin随批次/时间的漂移。**这跟你做异常检测的"按维度分桶+趋势检测"一模一样。**

## 4. SPC在半导体（你的主场，直接对标）

**好消息：半导体的SPC和你在理想做的几乎完全一样。**

| 你做过的 | 半导体里叫什么 | 是否相同 |
|---------|--------------|---------|
| Nelson Rules判异 | 半导体也用Nelson/WECO Rules | ✅ 完全一样 |
| Cp/Cpk/Pp/Ppk能力指数 | 半导体同样用Cpk评估工艺能力 | ✅ 完全一样 |
| 控制限、控制图 | Control Chart, UCL/LCL | ✅ 完全一样 |
| CPK趋势预警 | 参数漂移监控(Parametric Drift) | ✅ 同一逻辑 |
| 波形/曲线异常检测 | 测试参数分布监控、outlier剔除 | ✅ 高度相似 |

半导体特有的补充概念（了解即可）：
- **PAT (Part Average Testing)**：用统计方法剔除"参数虽合格但偏离群体"的潜在坏品（异常值检测！）
- **SBL/DBL (Statistical/Dynamic Bin Limit)**：统计良率限，某片晶圆某Bin异常高就报警
- **Cpk目标**：半导体通常要求Cpk≥1.33或1.67（比汽车更严）

> 🔑 **金句**："我做的SPC引擎——Nelson Rules、Box-Cox变换、Cpk能力指数、自适应控制限——搬到半导体测试参数监控上几乎零改动，这是我最直接的迁移优势。"

## 5. 供应链 & 销售数据（存储行业尤其关键，重点深挖）

### 5.0 一句话本质

> **存储芯片是"大宗商品化"的半导体**——价格像原油一样周期波动，同质化高、拼成本和交期。数据团队的核心使命：**预判周期、管好库存、优化产能分配、支撑定价决策**。

### 5.1 为什么这么特殊：强周期性（Cyclicality）

存储（DRAM/NAND/NOR）是典型"猪周期"：

```
需求旺 → 涨价 → 厂商扩产 → 产能过剩 → 跌价 → 减产 → 供给收缩 → 又涨价 …
```

- 2023下行暴跌 → 2024触底 → 2025-2026超级周期上行（AI需求+海外退出利基+长鑫绑定）→ 兆易2026H1利润同比+10倍

> 🔑 **金句**："存储是强周期生意，数据分析的最高价值是**在周期拐点前做出预判**——什么时候备货、什么时候去库存、怎么锁产能。"

### 5.2 长鞭效应（Bullwhip Effect）——必懂

终端需求小波动，沿供应链上游层层放大：客户囤货→分销加单→原厂看到"虚高需求"→过度扩产→周期崩盘。
> 数据团队要**穿透虚假需求看真实终端需求**（sell-through vs sell-in），别被长鞭带节奏。

### 5.3 供应链结构（fabless特有）

```
上游：晶圆代工(长鑫/中芯) + 封测厂(OSAT) + 原材料
  ↓  兆易(设计+品牌+销售)  ↓
下游：直销大客户(比亚迪/蔚来/Meta/字节) + 分销商(代理商) → 终端
```

### 5.4 供应链必懂术语

| 术语 | 含义 | 你的对应 |
|------|------|---------|
| **Sell-in / Sell-through** | 卖给渠道 / 渠道卖给终端(真实需求) | — |
| **Wafer Start（投片）** | 开始投产晶圆，周期长(3-6月)需提前规划 | 排产计划 |
| **WIP（在制品）** | 生产中未完成的库存 | — |
| **Die Bank（裸片库存）** | 测好未封装的裸片库存，接单再快速封装→兼顾交期和柔性 | 缓冲库存策略 |
| **Lead Time** | 下单到交货周期 | 交期预测 |
| **Safety Stock** | 应对波动的安全库存 | 库存优化 |
| **Book-to-Bill** | 订单额/出货额，>1需求旺 | 景气度指标 |
| **DOI/DIO** | 库存周转天数 | 库存健康指标 |
| **NCNR** | 不可取消不可退订单，锁产能用 | — |

> **Die Bank**是存储特有聪明玩法：先测好存裸片，接单再封成不同规格。数据要优化Die Bank水位。

### 5.5 销售数据（直销 + 分销）

- **直销**：大客户直接对接，量大价稳
- **分销**：代理商覆盖长尾，占比高但看不到终端 → **打通sell-through看真实需求是核心课题**

| 销售术语 | 含义 |
|---------|------|
| **ASP** | 平均售价，周期波动大，核心指标 |
| **Design-in / Design-win** | 芯片被客户设计进产品/中标量产（半导体销售灵魂，认证3-5年，高粘性） |
| **Forecast Accuracy** | 预测准确率，数据团队KPI |
| **Backlog（在手订单）** | 已下单未交付，反映未来收入 |
| **Product Mix** | 产品组合，往高毛利(车规MCU/利基DRAM)引导 |

> **Design-win**是灵魂：芯片先被客户工程师设计进产品才有长期订单。数据团队追踪design-win漏斗、转化率。

### 5.6 连接点：S&OP（销售与运营计划）——高价值考点

> S&OP = 把**销售预测**和**供应链产能/库存**每月对齐，形成"需求-供给"平衡的统一计划。数据团队角色：**提供预测、量化差异、支撑决策**。

> 🔑 **高价值话术**："数据应用主管很大价值在支撑S&OP——用需求预测和库存/产能数据帮销售和运营对齐。我做EVI价值量化和供应链预警，本质就是给跨部门决策提供数据依据。"

### 5.8 可能被追问 + 答法

**Q：存储库存管理难在哪？**
> 跌价快——存储价格周期性下跌，库存放着就贬值；但缺货又丢订单。所以在"跌价风险"和"缺货损失"间动态平衡，还用Die Bank半成品缓冲兼顾柔性。数据做精准需求预测+库存水位优化。

**Q：怎么提高销售预测准确率？**
> 穿透渠道看真实需求——不只看sell-in，要打通sell-through剔除渠道囤货虚高，再结合design-win漏斗、Book-to-Bill景气指标、周期位置综合判断。我做趋势检测也是先剔噪再建模。

**Q：你没做过销售/供应链数据怎么胜任？**
> "云链"就是典型供应链数据治理——跨56家供应商打通数据、建预警、量化避损3.77亿。销售/需求预测方法论上是时序预测+多维归因，和我的CPK趋势诊断同源。术语快速补，数据方法论和跨部门落地能力是现成的。

## 6. 半导体数据栈/平台（可能被问）

| 类别 | 半导体常用 | 你会的对应 |
|------|-----------|-----------|
| 测试数据格式 | **STDF**（Standard Test Data Format，测试机标准输出） | 陌生，但就是结构化测试记录，可快速学 |
| 良率分析平台 | Yield Management System (YMS)、PDF Solutions、Synopsys | 概念=你的实时评估+看板系统 |
| 数据分析 | Python/SQL/JMP（统计软件）/Spotfire | Python/SQL你都会 |
| 数仓 | 通常有ODS/DWD/DWS分层 | 你用PG做过类似分层，大数据栈可快速上手 |
| BI | Tableau/PowerBI/Spotfire | 自研看板经验，理念相通 |

> **JMP** 和 **Spotfire** 是半导体行业最常见的统计分析/可视化工具，听过名字就行。如果面试官提到，说"用Python+统计做过同类分析，工具可快速上手"。
