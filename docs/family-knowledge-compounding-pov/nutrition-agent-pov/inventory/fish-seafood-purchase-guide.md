# 鱼类和海鲜购买建议

> 用于指导家庭营养师 Agent 在推荐鱼类、海鲜菜谱和采购清单时做风险过滤。  
> 本文件不是医疗建议，重点是家庭采购和菜谱推荐的实用判断。

---

## 1. 总体原则

鱼类推荐不能只看“超市有卖”或“是不是活鱼”，还需要同时判断：

- 蛋白质含量；
- 脂肪含量；
- 鱼刺风险；
- 汞和污染风险；
- 产地；
- 养殖还是野生；
- 是否有清晰标签和供应链；
- 是否适合宝宝当前咀嚼能力；
- 是否适合老人控盐、控油和复热。

---

## 2. 超市活鱼规则

用户已提醒：超市活鱼“门道很深”，不能因为活鱼就默认更安全或更适合。

推荐时需要注意：

- 活鱼也要看水质、品类、来源和周转；
- 不要默认“活鱼 = 更营养 / 更安全”；
- 如果来源、产地、养殖方式不清楚，推荐权重降低；
- 给宝宝推荐时，优先选择刺少、肉质稳定、来源清晰的鱼；
- 对刺多鱼类，即使营养好，也不优先推荐给宝宝直接吃。

---

## 3. 优先关注指标

### 3.1 蛋白质

优先选择：

- 高蛋白；
- 肉质适合家庭做法；
- 适合清蒸、炖汤、煎烤后少油处理；
- 宝宝可做成鱼肉块、鱼丸、鱼粥、鱼汤面。

### 3.2 脂肪

脂肪不是绝对坏，但需要区分：

- 三文鱼、青花鱼等脂肪较高，优点是有不饱和脂肪酸，但晚餐和老人份要控制量；
- 银鳕鱼脂肪也较高，宝宝可吃但不要每天高频重复；
- 白肉鱼通常更清淡，适合老人和宝宝；
- 油煎、油炸会显著增加油脂，不作为默认推荐。

### 3.3 鱼刺

宝宝优先级：

1. 刺少、易处理；
2. 可明确去刺；
3. 肉质软嫩；
4. 不容易复热后变柴或变腥。

刺多鱼类不推荐作为宝宝常规鱼肉来源。

### 3.4 产地和养殖方式

购买时优先记录：

- 产地；
- 品牌或供应商；
- 野生 / 养殖；
- 冷鲜 / 冷冻 / 活鱼；
- 是否有检测或溯源信息。

原则：

- 产地和养殖方式不清楚时，不给宝宝做高频推荐；
- 对宝宝和老人，稳定可靠比“稀有”更重要；
- 对大型掠食鱼、来源不明深海鱼，降低宝宝推荐权重。

---

## 4. 家庭常见鱼类推荐分层

### 4.1 更适合作为家庭常规候选

- 鲈鱼 / 海鲈鱼：清蒸友好，肉质稳定，但宝宝吃需仔细去刺；
- 多宝鱼：清蒸友好，适合家庭改善餐，宝宝吃需去刺；
- 鳕鱼块：处理方便，适合宝宝和老人，但要看配料和真实鱼种；
- 银鳕鱼：宝宝已吃过，脂肪较高，适合轮换，不要过度高频；
- 三文鱼：宝宝已吃过，脂肪较高，适合轮换，注意新鲜度和来源；
- 鲳鱼：刺相对可控，适合清蒸或少油做法；
- 桂鱼 / 鳜鱼：改善餐候选，清蒸友好，注意刺和价格。

### 4.2 可以吃，但宝宝不优先

- 黄花鱼：家常，刺需要注意；
- 带鱼：更适合成人/老人共用版，油煎红烧常见，不优先给宝宝；
- 鲫鱼：适合汤，但刺多，宝宝不建议直接吃鱼肉；
- 青花鱼 / 鲭鱼：营养价值高，但味道重、脂肪较高，宝宝需谨慎。

### 4.3 加工鱼制品

- 鱼丸；
- 虾滑；
- 鱼滑。

使用规则：

- 必须看配料表；
- 宝宝版默认避免添加剂、糖、成人调味料和过高钠；
- 成人/老人共用版也要注意钠含量；
- 不把加工鱼制品等同于新鲜鱼虾蛋白质。

---

## 5. 虾贝类规则

### 5.1 虾类

宝宝已吃过：

- 基围虾；
- 黑虎虾。

可作为候选：

- 虾仁；
- 大虾；
- 河虾；
- 虾滑。

规则：

- 宝宝吃虾要去壳、去虾线，切小或做虾滑 / 丸子；
- 虾滑要看配料表，避免高钠和添加剂；
- 晚餐不宜做得过重口。

### 5.2 贝壳类

成人可吃：

- 扇贝；
- 蛤蜊 / 花蛤；
- 蛏子；
- 青口贝；
- 生蚝；
- 鲍鱼；
- 瑶柱 / 干贝；
- 扇贝丝。

规则：

- 宝宝没吃过贝壳类，默认不推荐；
- 扇贝丝、干贝、瑶柱可给成人/老人共用版提鲜，但要注意钠和用量；
- 贝壳类要重视新鲜度和清洗吐沙；
- 爸爸和奶奶螃蟹过敏，螃蟹相关食材必须避免。

### 5.3 头足类

家里一般不吃：

- 鱿鱼；
- 墨鱼；
- 八爪鱼。

规则：

- 不作为默认推荐；
- 宝宝咀嚼不友好，不推荐；
- 如果用户临时购买，再作为特殊食材处理。

---

## 6. 青岛带来海鲜处理规则

奶奶、爷爷可能从青岛带来海鲜或干货，包括：

- 海捕虾；
- 鲅鱼；
- 平鱼；
- 偏口鱼；
- 带鱼；
- 鲍鱼；
- 海参；
- 干贝；
- 海米；
- 其他青岛海鲜或干货。

处理原则：

- 作为特殊库存录入，不默认长期稳定供应；
- 优先记录来源、到家日期、冷冻 / 冷藏状态和大概数量；
- 海捕虾可作为成人/老人共用版和宝宝候选蛋白，但宝宝吃前仍要去壳、去虾线、切小或做虾滑；
- 鲅鱼、平鱼、偏口鱼、带鱼等需要重点关注鱼刺和做法，宝宝默认不直接推荐整块鱼肉；
- 鲍鱼、海参更偏成人/老人改善餐，宝宝默认谨慎；
- 干贝、海米可用于成人/老人共用版提鲜，但钠和鲜味较强，宝宝默认不使用，除非用户明确确认；
- 爸爸和奶奶螃蟹过敏，青岛带来的海鲜也必须排除螃蟹相关食材和交叉混用风险。

---

## 7. Agent 推荐鱼类时的输出要求

当推荐鱼类菜谱时，Agent 应尽量说明：

```text
推荐鱼类：
为什么适合：蛋白质 / 脂肪 / 刺 / 做法 / 家庭成员适配
宝宝版：如何去刺、切块、调味、颗粒度
成人/老人共用版：少油少盐做法，是否适合复热
购买注意：看产地、养殖/野生、冷鲜/冷冻、配料表或溯源信息
不推荐原因：如刺多、脂肪高、来源不清、调味重、宝宝未尝试
```

如果信息不足，Agent 应提示用户购买时拍包装、标签或商品页，而不是直接假设鱼的来源和品质。
