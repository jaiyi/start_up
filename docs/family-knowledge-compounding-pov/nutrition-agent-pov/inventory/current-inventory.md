# 当前库存

> Source of truth：记录家里当前真实库存。推荐前必须读取本文件；如果本文件信息缺失或过期，Agent 必须先询问用户，不得假设库存充足。

## 更新规则

```text
1. 每周采购后更新新增库存。
2. 推荐菜单后只生成计划消耗，不直接扣减。
3. 用户确认执行后，记录 planned。
4. 饭后无反馈，默认正常，按计划扣减库存。
5. 饭后有反馈，以反馈修正实际消耗。
6. 状态不明、异味、过期或不适合宝宝/老人食材，不得为了清库存强行推荐。
```
