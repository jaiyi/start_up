# 家庭饮食规则

> 本文件记录家庭营养师 Agent 推荐、过滤和改造菜谱时必须遵守的规则。  
> 原则：安全限制优先于口味偏好；家庭执行可行性优先于理论最优。

---

## 1. 总体饮食方向

全家默认饮食方向：

- 早餐通常要炒两个快手菜，不能只用粥、糊、面包、牛奶或鸡蛋替代完整早餐；
- 早餐两个快手菜中，至少 1 个要有明确蛋白质，至少 1 个要有青菜、菌菇或根茎类；
- 早餐快手菜尽量 10-15 分钟内完成，少油少盐，不用肥肉；
- 高蛋白；
- 少油；
- 不要肥肉；
- 食材多样；
- 营养均衡；
- 兼顾宝宝、老人和重度脑力工作者；
- 兼顾姥爷高血压 / 糖尿病和奶奶高血糖风险。

推荐默认优先蛋白质来源：

- 鸡蛋；
- A2 牛奶；
- 无糖酸奶；
- 鸡胸肉；
- 鸡腿肉；
- 梅花肉；
- 里脊；
- 猪肉片 / 猪肉丝 / 猪肉末；
- 牛肋条；
- 牛腩；
- 牛排；
- 基围虾；
- 黑虎虾；
- 银鳕鱼；
- 三文鱼；
- 豆腐；
- 毛豆。

默认减少或避免：

- 肥肉；
- 五花肉；
- 重油菜；
- 重糖菜；
- 油炸；
- 腌制品；
- 加工肉；
- 过度依赖复杂调味料的菜。

---

## 2. 推荐优先级

推荐时按以下顺序判断：

1. 安全限制：过敏、忌口、宝宝年龄不适合、医疗限制；
2. 可实现性：当前库存是否足够，缺口是否可接受；
3. 家庭接受度：历史反馈、成员偏好、阿姨执行能力；
4. 时间条件：工作日 / 周末、早餐 / 午餐 / 晚餐；
5. 营养目标：蛋白质、蔬菜、少油少盐、主食结构；
6. 复热友好：是否适合姥姥姥爷晚餐复热；
7. 新鲜感：避免近期重复。

---

## 3. 宝宝餐规则

### 3.1 颗粒度

宝宝目前约 1 岁 2 个月，8 颗牙。

推荐形态：

- 碎丁；
- 小块；
- 软烂块；
- 肉末；
- 小肉丁；
- 丸子；
- 饼；
- 蒸糕；
- 厚蛋烧；
- 烩饭；
- 汤面。

避免或谨慎：

- 大片肉；
- 大片菜；
- 韧性强的片状食物；
- 筋膜多的肉；
- 需要大牙充分咀嚼的食物；
- 整颗坚果；
- 容易噎住的大块水果。

### 3.2 调味

宝宝餐可以少量使用：

- 宝宝专用酱油；
- 海苔碎；
- 虾皮；
- 洋葱爆锅；
- 番茄；
- 菌菇；
- 南瓜；
- 红枣；
- 黑芝麻。

宝宝餐默认不用：

- 添加糖；
- 普通成人调味料；
- 人工添加剂；
- 辣味；
- 油炸做法；
- 腌制品；
- 加工肉；
- 肥肉。

注意：

- 虾皮、海苔有钠，只能少量使用；
- 鱼丸等加工食材需要检查配料表，宝宝版默认避免添加剂、糖、成人调味料和过高钠。

### 3.3 宝宝蛋白质

宝宝常用蛋白质来源：

- 鸡蛋；
- 鸡胸肉；
- 黑猪梅花肉；
- 牛肋条；
- 基围虾；
- 黑虎虾；
- 银鳕鱼；
- 三文鱼。

规则：

- 鸡蛋每天尽量保证 1 个；
- 牛肋条一般晚上不吃，不好消化；
- 牛肋条优先安排在午餐，适合炖煮、汤或烩饭；
- 晚餐优先选择鸡蛋、鱼、虾滑、豆腐等相对轻的蛋白质。

### 3.4 宝宝与成人餐关系

推荐原则：

```text
食材共用；
调味分离；
烹饪可分锅。
```

也就是说：

- 尽量使用同一批食材，提高备菜效率；
- 宝宝版不加成人调味料；
- 成人/老人共用版可后调味；
- 宝宝版根据当前颗粒度切碎、小丁或软烂处理。

## 4. 过敏和敏感食物规则

| 成员 | 食物 | 规则 |
|---|---|---|
| 爸爸 | 螃蟹 | 避免 |
| 奶奶 | 螃蟹 | 避免 |
| 宝宝 | 香蕉 | 嘴周红，默认谨慎 / 避免 |
| 宝宝 | 芒果 | 没吃过，默认不主动推荐 |
| 宝宝 | 螃蟹 / 贝壳类 | 没吃过，默认不主动推荐 |
| 宝宝 | 花生 / 坚果 | 当前不吃，默认不推荐 |

海鲜规则：

- 虾类目前可作为家庭常用食材；
- 鱼类推荐需要关注蛋白质、脂肪、鱼刺、产地、养殖 / 野生、冷鲜 / 冷冻和供应链信息；
- 超市活鱼不默认等于更安全或更适合，需要看来源和水质；
- 螃蟹必须避开爸爸和奶奶；
- 贝壳类大人都吃，但宝宝没吃过，默认不放入宝宝餐；
- 扇贝丝可用于成人餐爆锅提鲜，宝宝餐默认不使用，除非用户明确确认；
- 青岛带来的海鲜需要作为特殊库存录入，常见包括海捕虾、鲅鱼、平鱼、偏口鱼、带鱼、鲍鱼、海参、干贝、海米等；
- 头足类家里一般不吃，不作为默认推荐。

---

## 5. 老人友好规则

### 5.1 姥爷

姥爷有高血压和糖尿病，推荐时默认：

- 控盐；
- 控糖；
- 少油；
- 避免肥肉；
- 避免高糖点心；
- 避免重口酱料；
- 注意主食结构，避免过量精制碳水；
- 每餐搭配蛋白质和蔬菜。

### 5.2 奶奶

奶奶有高血糖风险且螃蟹过敏，推荐时默认：

- 避免螃蟹；
- 控糖风险友好；
- 少油；
- 不推荐肥肉为主的菜；
- 海鲜偏好可以保留，但要排除螃蟹。

### 5.3 复热规则

姥姥姥爷阶段，老人晚餐通常复热中午饭。

因此工作日午餐要考虑：

- 复热后口感不差；
- 复热后食品安全可控；
- 不依赖现炒现吃的脆嫩口感；
- 不推荐复热后明显变腥、变柴或出水严重的菜作为老人晚餐主菜；
- 汤、炖菜、烩菜、烩饭类通常更适合复热。

## 6. 早餐规则

家庭早餐是组合型早餐。

早餐和午餐/晚餐菜谱不需要完全拆开：很多家庭常做快手菜也会在早上做。推荐早餐时，可以从家庭常做菜里选择适合早上快速完成、不过重油、能搭配主食和果盘的菜。

推荐时尽量包含：

- 鸡蛋类；
- 奶 / 酸奶；
- 2 个快手菜；
- 至少 1 个有肉；
- 青菜；
- 根茎类 / 蘑菇类；
- 主食；
- 果盘。

示例结构：

```text
鸡蛋 / 蛋羹
+ 水果酸奶碗
+ 快手肉菜
+ 快手蔬菜 / 菌菇 / 根茎
+ 玉米 / 面包 / 包子 / 饼
+ 2–3 种水果
```

偶尔可做：

- 扬州炒饭：适合早餐或早午餐，注意少油、少盐，搭配蔬菜和蛋白质；
- 扁豆焖面：姥爷比较擅长，适合作为家庭主食型菜，但姥爷本人需要注意主食量。

常见家庭菜：

- 菜花炒培根：培根是加工肉，成人/老人共用版少量使用，宝宝默认不推荐；
- 番茄红烩牛腩、咖喱土豆牛腩：适合炖煮类，宝宝版需要少调味或另做；
- 扁豆土豆焖排骨：适合家庭炖菜，注意排骨油脂和主食搭配；
- 菠菜炒鸡蛋、莴笋胡萝卜炒鸡蛋、尖椒炒鸡蛋：属于快手蛋菜，其中尖椒炒鸡蛋不推荐给宝宝；
- 小白菜肉片炖豆腐：适合老人和复热，宝宝版需切碎并清淡调味；
- 口蘑芦笋炒牛里脊：高蛋白、快手、适合家庭常用；
- 地三鲜家庭版：原版油重，应做少油版。

注意：

- 成人可吃坚果；
- 宝宝当前不吃花生和坚果类；
- 宝宝水果要避开香蕉和芒果默认推荐。

## 7. 工作日午餐规则

工作日午餐是家庭执行核心之一，由阿姨负责。

推荐时需要考虑：

- 阿姨可执行；
- 宝宝午餐；
- 老人午餐；
- 姥姥姥爷阶段中午通常是三菜一汤配米饭；
- 姥姥姥爷阶段老人晚餐复热；
- 高蛋白；
- 少油；
- 不要肥肉；
- 食材尽量来自周末采购、盒马或物美；
- 宝宝版和成人/老人共用版分开调味。

阿姨可执行输出应包括：

- 原菜谱总结；
- 家庭适配判断；
- 宝宝版改法；
- 成人/老人共用版改法；
- 控糖 / 控盐注意；
- 复热适配；
- 反馈记录点。

---

## 8. 周末和新菜规则

- 爸爸周末大菜不作为固定规划重点；
- 周末大菜可根据临时兴趣尝试；
- 初次尝试成功后，再加入常用菜谱库；
- 老饭骨等来源可用于学习食材处理技巧；
- 不直接照搬高油高盐高调味版本。

---

## 9. 应季养生规则

可以收集和推荐养生应季食谱。

优先方向：

- 应季食材；
- 节气饮食；
- 温和养生；
- 汤羹；
- 润燥；
- 清淡；
- 健脾胃；
- 少油；
- 老人友好；
- 宝宝可改造。

边界：

- 不做中医诊断；
- 不宣称治疗疾病；
- 不替代医生建议；
- 避免过度药膳化；
- 优先普通食材、家庭可买、可执行。

---

## 10. 微信确认规则

以下情况必须让用户确认：

- 小票 / 图片识别后的库存入库；
- 删除或归零重要库存；
- 标记过敏、忌口、慢病限制；
- 将某道菜设为长期不推荐；
- 对家庭成员画像做重大修改；
- 给宝宝新增未尝试过的高风险食材；
- 将贝壳类、螃蟹、坚果、花生加入宝宝相关推荐。
