## 2. 家庭整体饮食目标

全家整体饮食目标比较一致：

- 高蛋白；
- 少油；
- 不要肥肉；
- 食材多样；
- 营养均衡；
- 兼顾宝宝、老人和重度脑力工作者；
- 兼顾姥爷高血压 / 糖尿病和奶奶高血糖风险；
- 不做医疗诊断，只做家庭饮食执行提醒。

## 3. 工作日餐食结构

### 3.1 爸爸妈妈

- 工作日基本只在家吃早餐。
- 午餐和晚餐基本在单位解决。
- 早餐需要支撑重度脑力工作。
- 早餐重点是高蛋白、稳定、省心。

### 3.2 宝宝

- 宝宝早餐、午餐、晚餐分别做。
- 宝宝餐尽量和成人餐共用食材，提高备菜效率。
- 由于宝宝不能吃成人调味料，宝宝餐通常需要和成人餐分开调味、分开烹饪。
- 推荐原则是：**食材共用，调味分离，烹饪可分锅**。

### 3.3 老人

- 照护老人轮换期间一日三餐在家。
- 姥姥姥爷阶段，为节省时间和照看宝宝，晚餐通常复热中午饭。
- 因此工作日午餐需要考虑姥姥姥爷晚餐复热友好。

### 3.4 阿姨

- 工作日阿姨主要做午餐，也打扫家里。
- 阿姨不在家用餐。
- 阿姨年轻，接受力强，可以根据小红书链接执行。
- Agent 需要给阿姨输出家庭改造要点和反馈迭代建议。

## 4. 家庭早餐结构

家庭早餐通常不是单一食物，而是组合型早餐。

常见结构：

- 鸡蛋类：煮鸡蛋 / 蛋羹；
- 水果酸奶碗；
- 2 个快手菜；
- 其中至少 1 个有肉；
- 尽量有肉、有青菜、有根茎类 / 蘑菇类；
- 主食一般是玉米 + 面包 / 包子 / 饼；
- 果盘，约 2–3 种水果。

早餐推荐规则：

- 不能只推荐“牛奶鸡蛋”；
- 要推荐组合型早餐；
- 要兼顾爸爸妈妈高蛋白、宝宝可吃、老人可接受；
- 成人坚果可以进入早餐，宝宝当前不吃花生和坚果类，需要分开。

- 烩饭；

- 蝴蝶面；
- 小馒头；

### 5.3 宝宝常用蛋白质

- 鸡蛋；
- 鸡胸肉；
- 黑猪梅花肉；
- 牛肋条；
- 基围虾；
- 黑虎虾；
- 银鳕鱼；
- 三文鱼。

宝宝蛋白质规则：

- 鸡蛋每天尽量保证 1 个；
- 牛肋条一般晚上不吃，不好消化；
- 牛肋条更适合午餐、炖煮、汤或烩饭；
- 晚餐优先选择更轻的蛋白质，如鸡蛋、鱼、虾滑、豆腐等。

### 5.5 宝宝水果

- 早上吃一点水果；
- 下午跟着奶 / 酸奶吃一点水果；
- 香蕉会嘴周红，默认谨慎 / 避免；
- 芒果没吃过，默认不主动推荐。

### 5.6 宝宝调味和禁忌

宝宝餐可以使用：

- 少量宝宝专用酱油；
- 海苔碎；
- 虾皮；
- 洋葱爆锅；
- 番茄、菌菇、南瓜、红枣、黑芝麻等天然食材增味。

宝宝餐默认不给：

- 添加糖；
- 普通成人调味料；
- 人工添加剂；
- 花生；
- 坚果；
- 螃蟹；
- 贝壳类；
- 辣；
- 油炸；
- 腌制品；
- 加工肉；
- 肥肉。

特别规则：

- 虾皮、海苔有钠，宝宝餐只能少量使用；
- 宝宝没吃过螃蟹和贝壳类，默认不推荐；
- 宝宝可吃虾，但螃蟹和贝类要单独处理。

## 7. 采购方式

- 爸爸妈妈周末统一采购。
- 姥姥姥爷阶段主要使用盒马、物美超市能买到的食材。
- 奶奶爷爷阶段可能会从青岛带海鲜或食材。

Agent 后续应支持：

- 周末统一采购清单；
- 工作日宝宝餐和老人餐规划；
- 库存消耗优先级；
- 盒马 / 物美可买食材优先；
- 青岛海鲜作为特殊库存录入。

## 8. 周末大菜

- 爸爸周末偶尔根据临时兴趣做大菜。
- 频率不稳定，不作为工作日推荐核心。
- 初次尝试成功后，可以加入常用菜谱库。
- 老饭骨等来源可以用于学习食材处理技巧，而不一定直接照搬整道菜。
