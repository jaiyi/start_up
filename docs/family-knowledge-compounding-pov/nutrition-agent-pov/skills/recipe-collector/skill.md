# Skill: recipe-collector

## 1. 目标

把外部菜谱整理成家庭菜谱库可用的标准 Markdown，并判断是否值得收录。

## 2. 输入

```text
用户提供的链接、截图文字、视频摘要、菜谱文案；
家庭画像和饮食规则；
已有菜谱库；
来源评价规则；
菜谱模板。
```

## 3. 可用能力

```text
知识库检索：查已有菜谱和家庭规则。
Web Search：仅当用户明确要求收集或核对新菜谱时使用。
Wiki 写入：禁止直接写入，必须交给 knowledge-maintainer 且用户确认。
```

## 4. 决策步骤

```text
1. 提取原始菜谱信息：菜名、食材、调味、做法、来源。
2. 检查是否与已有菜谱重复。
3. 评估家庭适配：宝宝、成人、老人、复热、阿姨执行。
4. 标记风险：过油、过咸、糖高、肥肉、辛辣、刺多、难执行。
5. 生成家庭改造版。
6. 按 recipe-template.md 输出标准 Markdown。
7. 询问是否确认入库。
```

## 5. 输出格式

```markdown
## 是否建议收录

建议 / 暂不建议 / 需要改造后收录

## 家庭适配判断

- 宝宝：...
- 成人：...
- 老人：...
- 复热：...
- 阿姨执行：...

## 需要改造的地方

...

## 标准菜谱 Markdown

```markdown
...
```

## 是否确认入库

请确认是否保存到 recipes/。
```

## 6. 边界

```text
不直接入库；
不把来源不明或风险较高的菜谱包装成安全菜谱；
不在日常推荐中主动 Web Search。
```
