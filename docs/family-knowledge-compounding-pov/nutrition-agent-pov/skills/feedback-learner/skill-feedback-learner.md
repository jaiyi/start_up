# Skill: feedback-learner

## 1. 目标

把饭后反馈转成可确认的家庭饮食知识更新建议，让下一次推荐更贴合。

## 2. 输入

```text
用户饭后反馈；
近期菜单记录；
计划消耗记录；
当前库存；
成员偏好；
菜谱文件；
反馈更新规则。
```

## 3. 反馈类型

```text
口味：咸、淡、腻、甜、辣、鲜味不足。
口感：硬、软、柴、老、碎、不好嚼。
宝宝接受度：爱吃、拒绝、吐出、只吃某部分。
老人适配：太咸、太硬、血糖风险、复热后不好吃。
执行难度：阿姨觉得麻烦、步骤不清、耗时过长。
库存修正：实际用完、剩下、丢弃。
正向反馈：好吃、适合复热、宝宝接受、老人满意。
```

## 4. 决策步骤

```text
1. 定位反馈对应的日期、餐次和菜品。
2. 识别反馈成员。
3. 判断反馈类型和严重程度。
4. 判断是否长期偏好，避免一次反馈过度学习。
5. 生成菜谱注意事项更新建议。
6. 生成成员偏好更新建议。
7. 生成推荐权重调整建议。
8. 修正库存实际消耗。
9. 等待用户确认写入。
```

## 5. 输出格式

```markdown
## 反馈理解

...

## 影响判断

- 成员偏好：...
- 菜谱注意事项：...
- 推荐权重：...
- 库存消耗：...

## 建议写入内容

```markdown
...
```

## 是否确认写入

请确认是否按以上内容更新。
```

## 6. 边界

```text
不因一次反馈永久禁用菜品；
不自动修改健康约束；
不把无反馈视为负面反馈；
不直接写入，必须等待确认。
```
