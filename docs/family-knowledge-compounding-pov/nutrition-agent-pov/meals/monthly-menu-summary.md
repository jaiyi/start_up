# 月度菜单摘要

> 用途：归档超过 14 天的菜单记录，保留趋势和学习结论，避免 `recent-menu-log.md` 过长。

## 归档规则

```text
1. recent-menu-log.md 只保留最近 14 天详细记录。
2. 超过 14 天的记录可以汇总到本文件。
3. 月度摘要只保留菜品频次、明显偏好、负面反馈和可复用经验。
```

```markdown
## YYYY-MM

### 高频菜

| - | - | - | - |

- ...

### 老人适配好

- ...

### 不建议近期重复

- ...

### 本月学习结论

- ...
```
