# 近期菜单记录

> 用途：滚动记录最近 14 天推荐和实际执行菜单，避免近期重复推荐。超过 14 天的详细记录可归档到 `monthly-menu-summary.md`。

## 滚动规则

```text
1. 只保留最近 14 天详细记录。
2. 推荐过但未确认执行，记为 recommended。
3. 用户确认执行，记为 planned。
4. 已执行且饭后无反馈，记为 cooked，反馈默认为正常。
5. 已执行且有反馈，记为 adjusted，并关联 meal-feedback-log.md。
6. 近 3 天执行过的菜默认不推荐。
7. 近 7 天执行过的菜降低推荐。
8. 近 14 天多次推荐或执行的菜明显降低推荐。
9. 推荐过但未执行只轻微降低，不等同于吃过。
```

```markdown
- ...
```
