# 饭后反馈记录

> 用途：记录饭后反馈，并支持 feedback-learner 生成菜谱注意事项、成员偏好、推荐权重和库存修正建议。

## 反馈规则

```text
1. 饭后无反馈，默认本餐正常。
2. 无反馈不产生负向学习。
3. 一次负面反馈不等于永久禁用菜品。
4. 反馈需要区分成员、菜品、原因和严重程度。
5. 涉及长期偏好或菜谱修改，需要用户确认后写入。
6. 涉及实际库存差异，可以修正 planned-consumption-log.md 和 current-inventory.md。
```

## 反馈类型

```text
口味：咸、淡、腻、甜、辣、腥。
口感：硬、软、柴、老、碎、不好嚼。
宝宝接受度：爱吃、拒绝、只吃部分、吐出。
老人适配：太咸、太硬、血糖风险、复热后不好吃。
执行难度：阿姨觉得麻烦、步骤不清、耗时长。
库存修正：实际用完、剩下、丢弃。
正向反馈：好吃、适合复热、宝宝接受、老人满意。
```
