# 虾仁蒸鸡蛋羹

## 一句话定位

虾仁蒸鸡蛋羹 是 `宝宝高频餐 / 可共用备菜类` 候选菜，适合用于 lunch, baby_meal 场景，后续可根据实际反馈调整推荐权重。

## 适合家庭的原因

- 围绕家里常备食材或已筛选外部候选菜名；
- 可按宝宝版和成人/老人共用版分开调味；
- 默认遵守高蛋白、少油、不要肥肉的家庭方向；
- 可交给阿姨按步骤执行，并通过饭后反馈迭代。

## 食材

### 共用食材

- 虾仁
- 鸡蛋

### 宝宝额外食材

- 根据需要使用宝宝专用酱油、海苔碎、虾皮、洋葱、番茄或菌菇提味。

### 成人/老人共用版额外食材

- 生抽、老抽、蚝油、醋、胡椒、葱姜蒜等按菜品少量使用。

## 共用备菜

1. 共用食材先统一清洗、去皮、去筋膜或去刺。
2. 宝宝能吃的部分先切碎、小丁或处理到软烂。
3. 在加入成人调味料、糖、辣味、重酱之前，先分出宝宝份。
4. 成人/老人共用版再单独完成调味。

## 宝宝版

### 适用年龄和颗粒度

- 当前适配：1 岁 2 个月、8 颗牙；
- 优先形态：软烂、小丁、肉末、丸子、厚蛋烧、软饭、汤面；
- 避免大片、硬块、筋膜多、刺多或难咀嚼食材。

### 做法

1. 虾仁蒸鸡蛋羹 可以作为宝宝餐或共用备菜菜谱，宝宝份只保留清淡基础做法。
2. 鸡蛋类做嫩不做老，蛋块切小；蒸蛋/厚蛋烧都不淋成人酱油。
3. 虾仁/虾滑确认配料干净、低钠少添加，切小或做成小丸后彻底加热。
4. 汤羹类保持稀软顺滑，固体食材切小，汤面浮油撇掉。

### 宝宝调味和禁忌

- 不使用添加糖、普通成人调味料、人工添加剂、辣味、油炸做法、腌制品、加工肉和肥肉。
- 花生、坚果、螃蟹、贝壳类默认不推荐。
- 香蕉谨慎 / 避免，芒果默认不主动推荐。

## 成人/老人共用版

### 做法

1. 鸡蛋液调好后低温蒸至细嫩，虾仁、肉末或豆腐按熟成速度分段加入。
2. 成人份出锅后单独少量调味，宝宝份保持清淡。
3. 虾类不久煮，确认宝宝份低钠少添加，成人份单独调味。

### 控糖控盐提醒

- 成人/老人共用版统一少油少盐；姥爷注意控糖控盐，奶奶注意高血糖风险。

## 好吃的小妙招

- 鸡蛋液和温水按约 1:1.5 调，过筛后蒸出来更细腻。
- 碗口盖盘子或保鲜膜扎孔，避免水汽滴落形成蜂窝。
- 虾仁先切小丁或拍碎，等蛋羹半凝固后再放，避免沉底和蒸老。
- 蒸好后焖 2 分钟再出锅，宝宝份不放成人酱油，成人份另淋少量生抽。

## 阿姨执行提示

- 先确认当天是否有对应食材；
- 先做宝宝可共用的基础备菜，再做成人调味；
- 做完后反馈：宝宝接受度、老人是否觉得咸/油、执行是否麻烦。

## 复热与留餐

- 默认更适合现做现吃；
- 如需留餐，优先只留汤汁、炖煮部分或未混入口水的成人份。

## 采购清单

- 已有食材：以 `inventory/current-inventory.md` 为准；
- 需要补买：按实际库存补齐主蛋白、蔬菜和调味。

## 推荐逻辑

- 优先推荐：当主要食材已有、需要高蛋白少油、需要宝宝和成人共用备菜时。
- 降低推荐：当近期重复、宝宝颗粒度不合适、老人控糖控盐压力大或阿姨反馈执行复杂时。
