# 番茄牛腩老饭骨技法改良版

## 一句话定位

番茄牛腩老饭骨技法改良版 是 `技法参考 / 家庭化改造` 候选菜，适合用于 lunch, dinner, weekend 场景，后续可根据实际反馈调整推荐权重。

## 适合家庭的原因

- 围绕家里常备食材或已筛选外部候选菜名；
- 可按宝宝版和成人/老人共用版分开调味；
- 默认遵守高蛋白、少油、不要肥肉的家庭方向；
- 可交给阿姨按步骤执行，并通过饭后反馈迭代。

## 食材

### 共用食材

- 番茄
- 牛腩

### 宝宝额外食材

- 根据需要使用宝宝专用酱油、海苔碎、虾皮、洋葱、番茄或菌菇提味。

### 成人/老人共用版额外食材

- 生抽、老抽、蚝油、醋、胡椒、葱姜蒜等按菜品少量使用。

## 共用备菜

1. 共用食材先统一清洗、去皮、去筋膜或去刺。
2. 宝宝能吃的部分先切碎、小丁或处理到软烂。
3. 在加入成人调味料、糖、辣味、重酱之前，先分出宝宝份。
4. 成人/老人共用版再单独完成调味。

## 宝宝版

### 适用年龄和颗粒度

- 当前适配：1 岁 2 个月、8 颗牙；
- 优先形态：软烂、小丁、肉末、丸子、厚蛋烧、软饭、汤面；
- 避免大片、硬块、筋膜多、刺多或难咀嚼食材。

### 做法

1. 本菜不默认做宝宝版；如需共用，只在加成人调味、辣味、糖、重酱或加工肉之前分出适合宝宝的基础食材。
2. 分出的食材需重新处理成小丁、碎末、软烂块或清淡汤饭，不直接沿用成人成品。

### 宝宝调味和禁忌

- 不使用添加糖、普通成人调味料、人工添加剂、辣味、油炸做法、腌制品、加工肉和肥肉。
- 花生、坚果、螃蟹、贝壳类默认不推荐。
- 香蕉谨慎 / 避免，芒果默认不主动推荐。

## 成人/老人共用版

### 做法

1. 主蛋白和蔬菜先处理熟，再加米饭/面/土豆等主食合成一餐。
2. 姥爷份少主食、多蛋白和蔬菜，成人调味后置。
3. 牛肉类注意逆纹切、快炒或炖软，避免老人和宝宝吃到韧筋。

### 控糖控盐提醒

- 成人/老人共用版统一少油少盐；姥爷注意控糖控盐，奶奶注意高血糖风险。
- 本菜含主食或淀粉较多，姥爷份需要减少米面/粉丝/土豆总量。

## 好吃的小妙招

- 借鉴技法重点在焯水、炒番茄沙和炖煮火候，不照搬重油重盐。
- 牛腩焯水后用热水炖，炖到筷子能轻松插入再调味。
- 番茄分两次放，一次出汤底，一次保留酸甜。
- 冷藏后撇油再复热，老人份更清爽。

## 阿姨执行提示

- 先确认当天是否有对应食材；
- 先做宝宝可共用的基础备菜，再做成人调味；
- 做完后反馈：宝宝接受度、老人是否觉得咸/油、执行是否麻烦。

## 复热与留餐

- 可作为姥姥姥爷晚餐复热候选；
- 冷藏分装，复热时彻底加热；
- 绿叶菜和易老的肉类尽量现做或分开放。

## 采购清单

- 已有食材：以 `inventory/current-inventory.md` 为准；
- 需要补买：按实际库存补齐主蛋白、蔬菜和调味。

## 推荐逻辑

- 优先推荐：当主要食材已有、需要高蛋白少油、需要宝宝和成人共用备菜时。
- 降低推荐：当近期重复、宝宝颗粒度不合适、老人控糖控盐压力大或阿姨反馈执行复杂时。
