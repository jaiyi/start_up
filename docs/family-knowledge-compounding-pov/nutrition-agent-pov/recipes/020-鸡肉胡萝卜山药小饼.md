# 鸡肉胡萝卜山药小饼

## 一句话定位

鸡肉胡萝卜山药小饼 是 `宝宝高频餐 / 可共用备菜类` 候选菜，适合用于 baby_meal 场景，后续可根据实际反馈调整推荐权重。

## 适合家庭的原因

- 围绕家里常备食材或已筛选外部候选菜名；
- 可按宝宝版和成人/老人共用版分开调味；
- 默认遵守高蛋白、少油、不要肥肉的家庭方向；
- 可交给阿姨按步骤执行，并通过饭后反馈迭代。

## 食材

### 共用食材

- 胡萝卜
- 鸡肉
- 山药

### 宝宝额外食材

- 根据需要使用宝宝专用酱油、海苔碎、虾皮、洋葱、番茄或菌菇提味。

### 成人/老人共用版额外食材

- 生抽、老抽、蚝油、醋、胡椒、葱姜蒜等按菜品少量使用。

## 共用备菜

1. 共用食材先统一清洗、去皮、去筋膜或去刺。
2. 宝宝能吃的部分先切碎、小丁或处理到软烂。
3. 在加入成人调味料、糖、辣味、重酱之前，先分出宝宝份。
4. 成人/老人共用版再单独完成调味。

## 宝宝版

### 适用年龄和颗粒度

- 当前适配：1 岁 2 个月、8 颗牙；
- 优先形态：软烂、小丁、肉末、丸子、厚蛋烧、软饭、汤面；
- 避免大片、硬块、筋膜多、刺多或难咀嚼食材。

### 做法

1. 鸡肉胡萝卜山药小饼 可以作为宝宝餐或共用备菜菜谱，宝宝份只保留清淡基础做法。
2. 鸡肉切末或做丸/小饼时可用山药、蛋液增加嫩度，避免鸡胸发柴。
3. 主食做成软饭、软面、小饭团或小饼，保持湿润，不做过硬、过黏或过大的块。

### 宝宝调味和禁忌

- 不使用添加糖、普通成人调味料、人工添加剂、辣味、油炸做法、腌制品、加工肉和肥肉。
- 花生、坚果、螃蟹、贝壳类默认不推荐。
- 香蕉谨慎 / 避免，芒果默认不主动推荐。

## 成人/老人共用版

### 做法

1. 主蛋白和蔬菜先处理熟，再加米饭/面/土豆等主食合成一餐。
2. 姥爷份少主食、多蛋白和蔬菜，成人调味后置。

### 控糖控盐提醒

- 成人/老人共用版统一少油少盐；姥爷注意控糖控盐，奶奶注意高血糖风险。
- 本菜含主食或淀粉较多，姥爷份需要减少米面/粉丝/土豆总量。

## 好吃的小妙招

- 山药泥比面粉更适合做黏合，口感软且不硬。
- 胡萝卜擦细丝或焯软后切碎，避免夹生。
- 鸡肉泥先搅打上劲，再混山药和胡萝卜，煎时不容易散。
- 用不粘锅小火慢煎，表面金黄即可，不追求焦脆。

## 阿姨执行提示

- 先确认当天是否有对应食材；
- 先做宝宝可共用的基础备菜，再做成人调味；
- 做完后反馈：宝宝接受度、老人是否觉得咸/油、执行是否麻烦。

## 复热与留餐

- 默认更适合现做现吃；
- 如需留餐，优先只留汤汁、炖煮部分或未混入口水的成人份。
