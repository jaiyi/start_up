# 清蒸鳕鱼豆腐

## 一句话定位

清蒸鳕鱼豆腐 是 `清蒸鱼豆腐 / 轻负担高蛋白菜` 候选菜，适合用于 lunch, dinner 场景，后续可根据实际反馈调整推荐权重。

## 适合家庭的原因

- 符合高蛋白、少油、不要肥肉的家庭方向；
- 可围绕常备或周末采购食材安排，减少临时补买；
- 可按宝宝版和成人/老人共用版分开处理；
- 做法适合家庭厨房和阿姨执行，并可通过饭后反馈迭代。

## 食材

### 共用食材

- 鳕鱼
- 豆腐

### 宝宝额外食材

- 根据需要使用宝宝专用酱油、海苔碎、虾皮、洋葱、番茄或菌菇提味。

### 成人/老人共用版额外食材

- 生抽、蚝油、醋、胡椒、葱姜蒜等按菜品少量使用。

## 共用备菜

1. 共用食材先统一清洗、去皮、去筋膜或去刺。
2. 宝宝能吃的部分先切碎、小丁或处理到软烂。
3. 在加入成人调味料、糖、辣味、重酱之前，先分出宝宝份。
4. 成人/老人共用版再单独完成调味。

## 宝宝版

### 适用年龄和颗粒度

- 当前适配：1 岁 2 个月、8 颗牙；
- 优先形态：软烂、小丁、肉末、丸子、厚蛋烧、软饭、汤面；
- 避免大片、硬块、筋膜多、刺多或难咀嚼食材。

### 做法

1. 宝宝份必须确认无刺，鱼肉压小块，豆腐切小块，不加成人调味。
2. 宝宝份只保留清淡基础做法，不使用成人调味料、添加糖、辣味或重酱。
3. 如果当天不确定宝宝是否适合该食材，先询问用户再推荐。

### 宝宝调味和禁忌

- 不使用添加糖、普通成人调味料、人工添加剂、辣味、油炸做法、腌制品、加工肉和肥肉。
- 花生、坚果、螃蟹、贝壳类默认不推荐。
- 香蕉谨慎 / 避免，芒果默认不主动推荐。

## 成人/老人共用版

### 做法

1. 成人/老人份少量蒸鱼豉油即可，姥爷份控盐。
2. 成人/老人份在宝宝份分出后再少量调味。
3. 姥爷注意控糖控盐，奶奶注意高血糖风险，整体避免重油重酱。

### 控糖控盐提醒

- 成人/老人共用版统一少油少盐；
- 不额外加糖；
- 主食型菜要提醒姥爷控制主食量。

## 好吃的小妙招

- 鳕鱼彻底检查鱼刺，豆腐垫底吸收汤汁。
- 蒸鱼时间不要过长，避免鱼肉变柴。
- 宝宝份先分出清蒸原味部分，成人份再加葱姜蒸鱼豉油。

## 阿姨执行提示

- 先确认当天是否有对应食材；
- 先做宝宝可共用的基础备菜，再做成人调味；
- 做完后反馈：宝宝接受度、老人是否觉得咸/油、执行是否麻烦。

## 复热与留餐

- 不建议反复复热，鱼肉容易变柴或腥。

## 推荐逻辑

- 优先推荐：当主要食材已有、需要高蛋白少油、需要宝宝和成人共用备菜时。
- 降低推荐：当近期重复、宝宝颗粒度不合适、老人控糖控盐压力大或阿姨反馈执行复杂时。
