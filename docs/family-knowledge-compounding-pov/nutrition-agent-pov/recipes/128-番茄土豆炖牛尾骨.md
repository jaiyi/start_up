# 番茄土豆炖牛尾骨

## 一句话定位

番茄土豆炖牛尾骨是 `成人/老人优先的番茄清炖牛尾骨菜` 候选菜，适合用于 lunch, dinner, weekend, reheatable 场景，后续可根据老人控糖控盐反馈和执行成本调整推荐权重。

## 适合家庭的原因

- 牛尾骨提供浓郁肉香，番茄提供酸甜和鲜味，可减少重酱调味；
- 土豆增加饱腹感，但需要按主食管理，适合提醒姥爷和奶奶控量；
- 适合周末或阿姨有时间时一次炖好，成人/老人复热友好；
- 宝宝不默认食用，可只尝试少量清汤和剔骨软肉碎。

## 食材

### 共用食材

- 牛尾骨
- 番茄
- 土豆
- 洋葱（可选）
- 胡萝卜（可选）
- 姜片
- 葱段
- 清水

### 宝宝额外食材

- 不默认作为宝宝餐；如用户确认要给宝宝，可只取少量撇油清汤、剔骨软肉碎和少量软土豆泥。

### 成人/老人共用版额外食材

- 少量盐
- 少量生抽（可选）
- 黑胡椒（成人可选）
- 香叶或少量番茄膏（可选，注意配料表不要高钠高糖）

## 共用备菜

1. 牛尾骨提前用清水浸泡 30 分钟左右，中途换水，帮助去血水。
2. 牛尾骨冷水下锅，加姜片焯水，水开后撇去浮沫，捞出冲洗干净。
3. 番茄去皮切块；土豆去皮切块，清水浸泡防氧化；洋葱和胡萝卜切块备用。
4. 炖煮过程中不先加盐，等牛尾软烂、宝宝可取用部分分出后再调味。

## 宝宝版

### 适用年龄和颗粒度

- 当前适配：1 岁 2 个月、8 颗牙；
- 本菜不默认作为宝宝餐；
- 如偶尔尝试，只能给少量清汤、完全剔骨软肉碎和压成泥的土豆，不给骨头、不啃骨边肉。

### 做法

1. 牛尾骨炖到肉能轻松脱骨后，先撇去表面油脂。
2. 在成人调味前，取少量清汤、软肉和土豆。
3. 肉必须完全剔离骨头和碎骨，切碎或压散后再给宝宝。
4. 土豆压成泥或小碎块，避免大块噎住。
5. 宝宝份不加盐、不加生抽、不加番茄膏、不加黑胡椒。

### 宝宝调味和禁忌

- 不使用添加糖、普通成人调味料、人工添加剂、辣味、油炸做法、腌制品、加工肉和肥肉。
- 花生、坚果、螃蟹、贝壳类默认不推荐。
- 香蕉谨慎 / 避免，芒果默认不主动推荐。
- 牛尾骨有骨头和脂肪，宝宝不默认推荐；必须由成人完全剔骨、撇油、确认无碎骨。

## 成人/老人共用版

### 做法

1. 焯好的牛尾骨放入炖锅，加入清水、姜片、葱段，大火煮开后转小火炖到牛尾开始变软。
2. 加入番茄块和洋葱块，继续炖出番茄汤底。
3. 牛尾基本软烂后加入土豆块，炖到土豆软但不完全化掉。
4. 出锅前少量盐调味，可按成人口味加一点黑胡椒；老人份避免重盐重酱。
5. 冷藏后如表面凝固油脂较多，复热前先刮掉一部分油。

### 控糖控盐提醒

- 土豆算主食，姥爷和奶奶吃这道菜时应减少米饭、面条或馒头；
- 番茄汤底不额外加糖，靠番茄和洋葱自然甜味即可；
- 牛尾骨脂肪较高，需焯水、撇油，老人份不要喝太多油汤；
- 少盐即可，不建议同时加大量生抽、蚝油、番茄酱和盐。

## 好吃的小妙招

- 番茄分两次放：前半量炖汤底，后半量后放保留酸甜味。
- 土豆后放，避免炖太久全化成糊，老人控糖也更容易估算份量。
- 炖好冷藏一晚后，表层油脂更容易去掉，复热时更清爽。
- 洋葱可以增加自然甜味和香气，帮助减少盐和酱油。
- 如果汤味不够浓，优先延长炖煮或增加番茄，不优先加浓汤宝。

## 阿姨执行提示

- 牛尾骨必须焯水并冲洗干净，炖好后要撇油；
- 土豆不要切太小，避免完全炖化导致老人不易控制摄入量；
- 宝宝如要吃，只能在成人调味前取少量，并彻底剔骨；
- 做完后反馈：老人是否觉得油、土豆是否过量、牛尾是否炖到软烂。

## 复热与留餐

- 适合冷藏复热，复热时煮沸后再食用；
- 冷藏后先去除表层凝固油脂，再加热会更适合老人；
- 不建议反复多次复热，最好分装保存。

## 推荐逻辑

- 优先推荐：当周末需要成人/老人复热友好炖菜、家里有牛尾骨且近期红肉频率不高时。
- 降低推荐：当近期牛肉/红肉已较多、老人控糖压力大、当天已有土豆/玉米/面食等高碳水主食时。
