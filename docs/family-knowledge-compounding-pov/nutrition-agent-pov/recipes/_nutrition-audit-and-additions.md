# 菜谱营养学 Review 与补充建议

> 审阅日期：2026-09-29
> 审阅范围：`recipes/` 目录下 001-125 共 125 道编号菜谱，以及候选清单/烹饪提示文件
> 适用家庭约束：宝宝约 1 岁 2 个月、8 颗牙；成人/老人少油少盐；姥爷控糖控盐；奶奶有高血糖风险；宝宝默认不推荐花生/坚果/螃蟹/贝壳类；香蕉谨慎/避免，芒果不主动推荐。

> 说明：以下是家庭膳食结构层面的营养学建议，不替代医生、营养师针对糖尿病、肾病、过敏、贫血、消化问题等个体疾病的诊疗建议。

---

## 1. 总体结论

现有菜谱的优点很明显：**高蛋白、软烂、适合宝宝和成人分餐、鱼虾肉蛋豆覆盖多、蔬菜种类不少**。但从长期家庭营养结构看，仍有几个值得补齐的方向：

1. **全谷物/杂粮偏少**：已有燕麦、藜麦、小米、全麦、玉米，但比例不高，主食仍以米饭、面、粉丝、土豆为主。
2. **水果覆盖明显不足**：明确水果菜品很少，主要是酸奶水果燕麦碗、苹果排骨、红枣类。
3. **发酵食品/奶制品不足**：只有酸奶水果燕麦碗较明确；对钙、肠道菌群、早餐蛋白质结构支持不够。
4. **坚果/种子类不足**：有黑芝麻，但品类少。宝宝不能吃整颗坚果，但成人/老人可用磨粉或碎末补充健康脂肪。
5. **杂豆类不足**：豆腐很多，但红扁豆、鹰嘴豆、芸豆、黑豆等杂豆菜谱几乎没有。
6. **高钠隐患需要降频**：培根、梅干菜、鱼丸、虾滑、鸡汁、虾皮、海米、干贝、上汤等不宜高频给老人和宝宝。
7. **鱼虾类很多，但同质化偏高**：虾仁/虾滑/鳕鱼/豆腐组合很多，建议补充非海鲜蛋白、低盐豆类和禽肉变化，避免过敏原和钠集中。
8. **控糖友好说明还可以更细**：粥、软饭、焖饭、粉丝、土豆、玉米、红枣、酸甜口菜都需要按“总碳水”管理，而不是只看有没有加糖。

**最优先补充方向：**

- 无糖酸奶/奶制品；
- 全谷物：燕麦、小米、荞麦、胚芽米、糙米；
- 杂豆：红扁豆、鹰嘴豆、黑豆、芸豆；
- 安全水果：梨、蓝莓、苹果、橙子、猕猴桃；
- 深色蔬菜和十字花科轮换：油麦菜、芥蓝、紫甘蓝、彩椒、秋葵；
- 低盐非海鲜蛋白：鸡肉、瘦猪肉、瘦牛肉、鸡蛋、豆腐、豆浆/豆制品。

## 2. 现有覆盖较好的营养方向

### 2.1 优质蛋白覆盖很好

已有主蛋白包括：

- 鱼类：鳕鱼、银鳕鱼、三文鱼、鲈鱼、带鱼、鲅鱼、金枪鱼；
- 虾类：虾仁、虾滑、鲜虾；
- 肉类：牛肉、牛腩、猪肉、排骨、鸡肉、鸡腿、鸡胸；
- 蛋类：鸡蛋、蒸蛋、厚蛋烧；
- 豆制品：豆腐、干丝、毛豆、豆角、扁豆。

代表菜：

- `003-青菜鳕鱼山药香菇蒸丸子.md`
- `006-南瓜三文鱼菠菜粥.md`
- `021-银鳕鱼豆腐羹.md`
- `051-西兰花炒牛肉片.md`
- `095-清蒸鲈鱼.md`
- `103-番茄豆腐牛肉丸汤.md`
- `123-清蒸鳕鱼豆腐.md`

**建议：**后续不需要继续大量增加“虾仁/鳕鱼/豆腐丸子”同类菜，而应增加全谷物、杂豆、水果、奶制品和低钠调味方案。

### 2.2 宝宝餐形态设计比较完整

已有软饭、粥、蒸蛋、羹、丸子、小饼、饭团、蝴蝶面、疙瘩汤等，比较符合 1 岁 2 个月、8 颗牙宝宝的咀嚼阶段。

做得好的点：

- 多数菜谱都有“宝宝先分出清淡份，成人后调味”；
- 鱼类菜谱有去刺提醒；
- 丸子/软饭/羹类便于控制颗粒度；
- 对油炸、辣味、成人重调味有禁忌说明。

需要继续加强：

- 饭团不要做得太黏、太大；
- 玉米粒、蓝莓、葡萄类小圆粒必须压碎/切开；
- 粉丝、海苔、糯米笋要剪短、煮软，防吞咽风险；
- 虾、鱼、蛋、豆制品不要在宝宝首次尝试时同时叠加多个新过敏原。

### 2.3 蔬菜覆盖较好

现有蔬菜包括：

- 绿叶菜：菠菜、小白菜、小油菜、生菜、娃娃菜；
- 十字花科：西兰花、菜花、圆白菜、娃娃菜、小白菜；
- 橙红色蔬菜：胡萝卜、南瓜、番茄/西红柿；
- 根茎类：山药、土豆、白萝卜、冬瓜、莲藕；
- 菌菇类：香菇、口蘑、木耳、鲜蘑、羊肚菌、鸡枞。

**营养亮点：**维生素A前体、叶酸、钾、膳食纤维、植物化学物质覆盖较好。

## 3. 主要营养缺口与风险

## 3.1 高盐/隐形钠食材偏多，需要降频

下列菜谱或食材需要标为“高钠注意”：

| 食材/菜品 | 风险 |
|-----------|------|
| 培根 | 加工肉，高盐、饱和脂肪和亚硝酸盐风险，不适合宝宝，老人少吃 |
| 梅干菜 | 腌制菜，高钠，控糖控盐人群需少量 |
| 鱼丸、虾滑 | 常见成品含盐、淀粉和添加剂，需看配料表 |
| 鸡汁、上汤 | 钠含量通常较高 |
| 虾皮、海米、干贝 | 看似补钙/提鲜，但钠高且有海鲜过敏风险 |
| 蛋黄酱 | 脂肪高，部分产品含糖/盐 |

涉及菜谱例子：

- `031-菜花炒培根.md`
- `046-梅干菜肉末炒毛豆.md`
- `047-鸡汁小油菜炖干丝.md`
- `050-小白菜鱼丸汤.md`
- `070-上汤粉丝娃娃菜.md`
- `098-干贝冬瓜豆腐汤.md`
- `099-海米小白菜豆腐汤.md`
- `115-鸡蛋青菜虾皮软饼.md`

**建议规则：**

- 宝宝份默认不使用培根、梅干菜、鱼丸、虾滑、虾皮、海米、干贝、鸡汁、高汤；
- 老人份同餐如果使用高钠食材，就不要再额外放盐、生抽、蚝油；
- 家庭提鲜优先用番茄、菌菇、洋葱、葱姜、少量醋，而不是虾皮/鸡汁/浓汤宝。

---

## 3.2 控糖友好度需要按“总碳水”管理

对姥爷和奶奶来说，不只是“有没有加糖”的问题，还要看一餐中是否叠加：米饭/面条/粉丝/土豆/玉米/南瓜/红枣/水果/甜口酱汁。

需要注意的类型：

| 类型 | 例子 | 建议 |
|------|------|------|
| 粥/米糊/软饭 | 小米粥、米糊、软饭、烩饭 | 老人份少量，搭配蛋白和蔬菜，不单独喝大碗粥 |
| 淀粉蔬菜 | 土豆、玉米、南瓜、山药、莲藕 | 算作部分主食，不能再配大量米饭/面条 |
| 粉丝/面条 | 扁豆焖面、粉丝娃娃菜、蝴蝶面 | 控制份量，增加蔬菜和蛋白 |
| 甜味食材 | 红枣、苹果、酸甜口、鱼香汁 | 不额外加糖，红枣少量提味即可 |
| 水果早餐 | 酸奶水果燕麦碗 | 用无糖酸奶，水果小份，燕麦定量 |

---

## 3.3 水果明显不足

目前明确水果相关菜品较少：

- `029-酸奶水果燕麦碗.md`
- `071-苹果排骨.md`
- `002-黑芝麻红枣米糊.md`
- `012-黑芝麻山药红枣蒸糕.md`

建议补充安全、低加工、无添加糖的水果类小餐：

- 梨：蒸梨泥、梨丁；
- 蓝莓：压碎或切开，不能整颗给宝宝；
- 苹果：蒸苹果、苹果燕麦粥；
- 橙子：去籽、去膜、切小；
- 猕猴桃：少量尝试，观察口周刺激和腹泻；
- 草莓：充分清洗、切小，注意过敏观察。

不建议：

- 果汁；
- 蜂蜜水；
- 果酱；
- 甜味酸奶；
- 大量红枣当“天然糖”。

---

## 3.4 奶制品和发酵食品不足

目前只有 `029-酸奶水果燕麦碗.md` 明确覆盖酸奶。

建议补充：

- 原味无糖酸奶；
- 奶酪少量使用，优先低钠；
- 牛奶/配方奶仍按宝宝年龄和家庭习惯，不用菜谱替代正餐；
- 成人可增加低糖酸奶、牛奶、豆浆等早餐蛋白。

营养意义：

- 钙；
- 优质蛋白；
- 发酵乳制品对肠道菌群有帮助；
- 对早餐结构改善明显。

注意：

- 给宝宝选原味无糖酸奶，不选风味酸奶、乳酸菌饮料；
- 老人控糖也要避开含糖酸奶；
- 奶酪钠可能高，不适合大量使用。

---

## 3.5 全谷物和杂豆需要补齐

已有全谷物/杂粮：燕麦、藜麦、小米、全麦、玉米，但数量不多；豆制品很多，但真正的杂豆类不多。

建议补充：

| 类别 | 推荐食材 | 适合做法 |
|------|----------|----------|
| 全谷物 | 燕麦、小米、荞麦、胚芽米、糙米 | 粥、软饭、早餐碗、杂粮饭 |
| 杂豆 | 红扁豆、鹰嘴豆、黑豆、芸豆 | 炖饭、浓汤、豆泥、炖菜 |
| 宝宝适配 | 红扁豆、小米、燕麦 | 煮软、压泥、不过量 |
| 老人控糖适配 | 燕麦、荞麦、杂豆 | 小份替换精米面，搭配蛋白和蔬菜 |

注意：

- 杂粮不是越多越好，宝宝和老人都要看消化耐受；
- 杂豆要充分浸泡、煮烂，宝宝不吃整粒；
- 控糖人群仍要控制总量。

## 4. 建议补充的健康食材和对应菜品

### 4.1 全谷物 / 杂粮类

| 建议食材 | 营养价值 | 对应菜品 | 家庭适配 |
|----------|----------|----------|----------|
| 小米 | 温和主食、比白米更有矿物质和膳食纤维 | **南瓜小米牛肉碎粥** | 宝宝可吃；老人控制碗量 |
| 燕麦 | 可溶性膳食纤维，有助于早餐饱腹和血脂管理 | **无糖酸奶梨丁燕麦碗** | 成人早餐优先；宝宝需软化燕麦、少量尝试 |
| 荞麦 | 主食多样化，餐后血糖反应通常比精白面友好 | **番茄豆腐肉末荞麦面** | 老人可替代普通面；宝宝面条剪短煮软 |
| 胚芽米/糙米 | B族维生素、矿物质、膳食纤维更高 | **西兰花牛肉胚芽米软饭** | 宝宝需煮软；老人控制总主食 |
| 玉米面 | 增加粗粮变化 | **玉米面蔬菜鸡蛋蒸糕** | 宝宝版不加糖、不做太干 |

### 4.2 杂豆 / 植物蛋白类

| 建议食材 | 营养价值 | 对应菜品 | 家庭适配 |
|----------|----------|----------|----------|
| 红扁豆 | 植物蛋白、铁、膳食纤维，煮烂快 | **红扁豆胡萝卜豆腐炖饭** | 很适合宝宝和老人，但首次少量 |
| 鹰嘴豆 | 植物蛋白、膳食纤维、饱腹感强 | **鹰嘴豆南瓜鸡肉浓汤** | 成人/老人更适合；宝宝需打泥并少量 |
| 黑豆 | 植物蛋白、花青素、多酚 | **黑豆山药瘦肉汤** | 成人/老人可做；宝宝需确认消化耐受 |
| 无盐豆腐/豆浆 | 钙、蛋白质，口感软 | **西兰花豆腐鸡蛋羹** | 宝宝友好，注意大豆/鸡蛋过敏史 |

### 4.3 水果类

| 建议食材 | 营养价值 | 对应菜品 | 家庭适配 |
|----------|----------|----------|----------|
| 梨 | 水分、膳食纤维，口感温和 | **蒸梨燕麦粥** | 宝宝切小/压泥；老人不加糖 |
| 蓝莓 | 花青素、多酚 | **压碎蓝莓无糖酸奶杯** | 宝宝必须压碎或切开，不能整颗 |
| 苹果 | 果胶、膳食纤维 | **蒸苹果小米粥** | 比苹果排骨更适合日常低糖化 |
| 橙子 | 维C，帮助非血红素铁吸收 | **橙丁酸奶燕麦碗** | 去籽去膜切小；宝宝少量尝试 |
| 猕猴桃 | 维C、膳食纤维 | **猕猴桃原味酸奶小杯** | 易刺激口周，宝宝先少量观察 |

### 4.4 深色蔬菜 / 十字花科 / 黏滑蔬菜

| 建议食材 | 营养价值 | 对应菜品 | 家庭适配 |
|----------|----------|----------|----------|
| 芥蓝 | 维C、钙、叶酸、膳食纤维 | **芥蓝牛肉粒软饭 / 芥蓝炒牛肉** | 宝宝切碎焯软，成人少油快炒 |
| 油麦菜 | 绿叶菜轮换，口感较软 | **油麦菜豆腐肉末汤** | 宝宝可切碎煮软，老人友好 |
| 紫甘蓝 | 花青素、膳食纤维 | **紫甘蓝鸡蛋软饼** | 宝宝少量切碎，成人可凉拌但宝宝不吃凉拌版 |
| 彩椒 | 维C、类胡萝卜素 | **彩椒鸡丁豆腐炒饭** | 宝宝需去皮切小煮软，老人控主食量 |
| 秋葵 | 黏液多糖、膳食纤维 | **秋葵蒸蛋羹** | 宝宝友好但需切碎，观察口感接受度 |

### 4.5 健康脂肪 / 种子类

| 建议食材 | 营养价值 | 对应菜品 | 家庭适配 |
|----------|----------|----------|----------|
| 亚麻籽粉 | ALA ω-3脂肪酸、膳食纤维 | **亚麻籽粉无糖酸奶燕麦碗** | 仅成人/老人少量；宝宝不默认加 |
| 核桃粉/坚果粉 | 不饱和脂肪、矿物质 | **成人版核桃粉黑芝麻燕麦糊** | 宝宝不推荐整颗坚果；如需尝试必须咨询并用细粉少量 |
| 黑芝麻 | 钙、脂肪、风味 | **黑芝麻山药小米糊** | 已有黑芝麻菜，可保留但不加糖 |
| 橄榄油/菜籽油 | 不饱和脂肪 | **少油清炒芥蓝/西兰花** | 控量，每餐不是越多越好 |

## 5. 建议新增菜品候选清单

以下是建议进入候选池的菜名，不必一次性全部做成正式菜谱。优先级按“补缺口 + 家庭可执行 + 宝宝/老人适配”排序。

### A档：最建议优先新增

1. **南瓜小米牛肉碎粥**
   - 补：小米、铁、优质蛋白、宝宝软食。
   - 注意：老人份控制粥量；宝宝牛肉切碎煮软。

2. **红扁豆胡萝卜豆腐炖饭**
   - 补：杂豆、植物蛋白、膳食纤维。
   - 注意：红扁豆煮到完全软烂，宝宝首次少量。

3. **无糖酸奶梨丁燕麦碗**
   - 补：奶制品、发酵食品、燕麦、水果。
   - 注意：必须原味无糖酸奶；宝宝梨丁切小或蒸软。

4. **西兰花豆腐鸡蛋羹**
   - 补：钙、蛋白质、绿菜，低盐宝宝友好。
   - 注意：鸡蛋和豆制品过敏史；宝宝版不加盐。

5. **番茄豆腐肉末荞麦面**
   - 补：荞麦主食、多蛋白、番茄提味。
   - 注意：宝宝面剪短煮软；老人控制面量。

6. **油麦菜豆腐肉末汤**
   - 补：绿叶菜轮换、豆腐、低盐汤菜。
   - 注意：用鲜肉末和番茄/菌菇提味，不用鸡汁。

7. **蒸苹果小米粥**
   - 补：水果、温和主食、早餐变化。
   - 注意：老人小碗；不加糖、不加蜂蜜。

   - 补：深绿蔬菜、铁、维C协同。

### B档：适合轮换补充

   - 补：杂豆、南瓜、鸡肉。

    - 补：黏滑蔬菜、蛋白质、宝宝友好质地。

    - 补：主食质量、铁、十字花科蔬菜。

    - 补：水果多样性、发酵乳。
    - 注意：蓝莓必须压碎/切开；宝宝少量观察。

    - 补：维C、蛋白质、颜色多样性。
    - 注意：彩椒去皮切小；老人少饭多菜。

14. **黑豆山药瘦肉汤**
    - 补：黑豆、山药、瘦肉。
    - 注意：黑豆难消化，成人/老人优先，宝宝不作为默认菜。

15. **紫甘蓝鸡蛋软饼**
    - 补：花青素、蔬菜多样性。

### C档：成人/老人可选，宝宝不默认

## 6. 建议降权或标注“偶尔吃”的现有菜

| 菜品 | 原因 | 建议 |
|------|------|------|
| 菜花炒培根 | 加工肉、高钠 | 成人偶尔，宝宝不推荐 |
| 梅干菜肉末炒毛豆 | 腌制菜、高钠 | 老人少量，宝宝不推荐 |
| 干炸蘑菇 | 油炸 | 偶尔改善，不做常规 |
| 地三鲜家庭版 | 茄子吸油、淀粉多 | 改少油蒸/煎后快炒 |
| 上汤粉丝娃娃菜 | 高汤+粉丝，钠和主食叠加 | 少汤底、少粉丝 |
| 小白菜鱼丸汤 | 成品鱼丸钠和添加剂不确定 | 用鲜鱼丸/自制鱼泥更好 |
| 海米/干贝/虾皮相关菜 | 钠高、海鲜过敏风险 | 成人少量提味，宝宝默认不用 |
| 苹果排骨 | 酸甜口，糖风险 | 不加糖，苹果少量提味即可 |
| 鱼香肉丝 | 糖、盐、油都容易高 | 少油少糖，老人少量 |
| 金枪鱼蛋黄酱贝果 | 蛋黄酱脂肪高，金枪鱼钠/汞需注意 | 成人偶尔，不给宝宝默认推荐 |

## 7. 推荐的每周结构

### 宝宝

- 每天：1-2种蔬菜 + 1种优质蛋白 + 适量主食；
- 每周：鱼类 1-2 次即可，避免天天鱼虾；
- 每周：豆腐/鸡蛋/鸡肉/牛肉轮换；
- 水果：小份、切碎/蒸软，不榨汁；
- 新食材：一次只引入一种，观察 2-3 天。

### 成人/老人

- 每餐盘子结构建议：
  - 1/2 蔬菜；
  - 1/4 蛋白质；
  - 1/4 主食；
- 姥爷/奶奶：粥、面、粉丝、土豆、玉米、南瓜、山药、红枣、水果都要算入碳水；
- 每周至少安排：
  - 深绿叶菜 4-5 次；
  - 豆制品 3-4 次；
  - 鱼类 1-2 次；
  - 无糖酸奶/奶制品 3-5 次；
  - 全谷物/杂粮 3-5 次；
  - 水果小份每日或隔日。
