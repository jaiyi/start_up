# 宝宝版红烩牛尾骨

## 一句话定位

宝宝版红烩牛尾骨是 `番茄洋葱炖出自然酸甜味的软烂牛尾肉宝宝餐` 候选菜，适合用于 baby_meal, lunch, dinner, weekend, reheatable 场景，重点是完全剔骨、撇油、少量给肉，并把成人红烩的重酱重盐改成清淡版。

## 适合家庭的原因

- 用番茄、洋葱、胡萝卜提供自然酸甜和鲜味，不依赖番茄酱、糖、浓汤宝或重盐；
- 牛尾骨炖软后可取少量肉碎，补充铁和优质蛋白；
- 宝宝份可做成软烂肉碎 + 番茄胡萝卜浓汤汁，拌软饭或小米粥；
- 成人/老人份可在宝宝份分出后少量调味，适合一锅两吃。

## 食材

### 共用食材

- 牛尾骨
- 番茄
- 胡萝卜
- 洋葱
- 土豆（可选，宝宝份少量；老人控糖需注意）
- 姜片
- 葱段
- 清水

### 宝宝额外食材

- 软饭、小米粥或碎面（按当天主食安排少量搭配）
- 少量山药泥（可选，用于增加软糯口感）

### 成人/老人共用版额外食材

- 少量盐
- 少量生抽（可选）
- 黑胡椒（成人可选，宝宝不用）
- 少量番茄膏（可选，必须看配料表，避免高钠高糖）

## 共用备菜

1. 牛尾骨用清水浸泡 30 分钟左右，中途换水，帮助去血水。
2. 牛尾骨冷水下锅，加姜片焯水，水开后撇去浮沫，捞出后用温水冲洗干净。
3. 番茄去皮切块；胡萝卜切小块；洋葱切块；土豆如使用则切小块并清水浸泡。
4. 炖煮阶段先不加盐、不加酱油、不加番茄酱，先做宝宝可分出的清淡红烩基础锅。
5. 宝宝份必须在成人调味前分出，并再次检查骨头和油脂。

## 宝宝版

### 适用年龄和颗粒度

- 当前适配：1 岁 2 个月、8 颗牙；
- 优先形态：软烂肉碎、番茄胡萝卜浓汤汁、压碎土豆/山药、拌软饭或小米粥；
- 避免骨头、碎骨、筋膜、大块牛尾肉、油汤、大块洋葱和偏酸刺激的浓番茄汁。

### 做法

1. 牛尾骨焯水后放入炖锅，加清水、姜片和葱段，小火炖到牛尾肉能轻松脱骨。
2. 加入番茄、胡萝卜和洋葱，继续炖到蔬菜软烂、汤汁呈自然红色。
3. 如使用土豆，后半程再加入，炖到能用勺子压碎即可，不要让宝宝份土豆过多。
4. 成人调味前，取出一小份牛尾肉、胡萝卜、番茄汤汁和少量土豆或山药。
5. 牛尾肉必须完全剔骨，逐块检查是否有碎骨、硬筋和肥油，再切碎或压散。
6. 撇去宝宝份表面油脂，把肉碎和蔬菜压成适合宝宝咀嚼的浓稠状态。
7. 可少量拌入软饭、小米粥或碎面，不做过咸、过酸或过稠的大份量主食。

### 宝宝调味和禁忌

- 不使用添加糖、普通成人调味料、番茄酱、番茄沙司、浓汤宝、人工添加剂、辣味、油炸做法、腌制品、加工肉和肥肉。
- 花生、坚果、螃蟹、贝壳类默认不推荐。
- 香蕉谨慎 / 避免，芒果默认不主动推荐。
- 牛尾骨必须完全剔骨并检查碎骨，宝宝不能啃骨头，也不能吃骨边硬筋。
- 番茄酸度较高，宝宝第一次或近期少吃时先少量观察口周发红、腹泻或反酸。

## 成人/老人共用版

### 做法

1. 宝宝份分出后，成人/老人份继续小火收一点汤汁，让番茄和洋葱味道更浓。
2. 少量盐调味即可；如加生抽，只加一点点，不再额外重盐。
3. 成人可加少量黑胡椒；老人份建议不加或少加刺激性调味。
4. 如果加入土豆，老人份要把土豆算作主食，米饭或面条相应减少。
5. 盛出前撇去表面油脂，冷藏后复热时也先刮掉凝固油脂。

### 控糖控盐提醒

- 本菜的控糖重点是土豆、胡萝卜和搭配主食，姥爷和奶奶份要减少米饭/面条；
- 不额外加糖，不用番茄沙司调味；
- 牛尾骨脂肪较高，必须焯水、撇油，老人份不要喝太多油汤；
- 成人红烩容易做成重酱口，本菜只保留番茄洋葱自然红烩味。

## 好吃的小妙招

- 番茄分两次放：前半量炖汤底，后半量后放，颜色和酸甜味更好。
- 洋葱煮软后有自然甜味，可以替代糖和番茄酱。
- 胡萝卜切小一点更容易软烂，适合压进宝宝份汤汁里。
- 土豆后放，既能保持形状，也便于控制宝宝和老人碳水量。
- 炖好后静置几分钟再撇油，或者冷藏后刮掉表层凝固油脂，口感更清爽。

## 阿姨执行提示

- 牛尾骨必须焯水、冲净、慢炖到能脱骨；
- 宝宝份一定在加盐、生抽、黑胡椒前分出；
- 宝宝吃的肉必须完全剔骨、去肥油、去硬筋，并切碎或压散；
- 番茄汤汁如果太酸，可多炖一会儿或加洋葱增甜，不加糖；
- 做完后反馈：宝宝是否接受番茄酸味、肉是否足够软、是否有油腻感、老人是否觉得咸。

## 复热与留餐

- 成人/老人份适合冷藏复热，复热时煮沸后再食用；
- 宝宝份建议现做现吃，如需留餐，只留未入口污染的一小份并当天吃完；
- 冷藏后先去掉表层凝固油脂，再复热更适合宝宝和老人；
- 土豆复热后容易变粉散，复热时可少量加水调整浓稠度。

## 推荐逻辑

- 优先推荐：当家里有牛尾骨、想做一锅宝宝可少量改造的番茄炖菜、且近期红肉频率不高时。
- 降低推荐：当近期牛肉/红肉已较多、宝宝近期肠胃不适或对番茄酸味不接受、老人当天主食已经偏多、或阿姨没有时间慢炖和仔细剔骨时。
