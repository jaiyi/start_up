# 油麦菜豆腐鸡肉丸汤

## 一句话定位

油麦菜豆腐鸡肉丸汤是 `低盐高蛋白绿叶菜汤 / 宝宝和成人可共用基础汤` 候选菜，适合用于 baby_meal, lunch, dinner, reheatable 场景，后续可根据宝宝接受度和老人控盐反馈调整推荐权重。

## 适合家庭的原因

- 油麦菜补充绿叶菜，豆腐和鸡肉提供优质蛋白；
- 汤底清淡，不依赖鸡汁、浓汤宝、虾皮、海米等高钠提鲜；
- 鸡肉丸可做成软嫩小丸，适合宝宝当前咀嚼能力；
- 成人/老人份只需在宝宝份分出后少量调味，适合阿姨批量执行。

## 食材

### 共用食材

- 鸡胸肉或去皮鸡腿肉
- 北豆腐或嫩豆腐
- 油麦菜
- 山药或少量淀粉（帮助鸡肉丸变嫩，可选）
- 葱姜水或姜片
- 清水

### 宝宝额外食材

- 少量胡萝卜碎或香菇碎（可选，用于增加风味和颜色）
- 宝宝已确认可接受的低敏主食：软饭、碎面或小米粥（按当天搭配）

### 成人/老人共用版额外食材

- 少量盐
- 少量白胡椒粉（可选）
- 葱花或香菜（可选）
- 少量香油（可选，老人份慎用）

## 共用备菜

1. 鸡肉去皮、去筋膜，切小块后剁成肉泥。
2. 豆腐沥水后压成泥；油麦菜洗净，叶和梗分开切碎。
3. 如用山药，先去皮蒸熟或擦成细泥，少量加入鸡肉泥中增加嫩度。
4. 鸡肉泥、豆腐泥和少量葱姜水混合，顺一个方向搅到略有黏性。
5. 先煮宝宝可吃的清淡基础汤，分出宝宝份后再给成人/老人份调味。

## 宝宝版

### 适用年龄和颗粒度

- 当前适配：1 岁 2 个月、8 颗牙；
- 优先形态：软烂、小丸、肉末、碎菜、汤泡软饭；
- 避免大块鸡肉、大片油麦菜梗、过硬丸子或整块豆腐噎口。

### 做法

1. 鸡肉豆腐泥搓成小丸，大小控制在宝宝能咬开的迷你丸子；也可直接用勺子拨成小肉泥团。
2. 锅中加清水和一两片姜，水微开后下入鸡肉豆腐小丸，小火煮到完全熟透。
3. 加入切碎的油麦菜叶，煮到颜色变深且质地软。
4. 宝宝份不加盐、不加酱油、不加鸡精鸡汁；盛出后可把丸子压开确认内部熟透且足够软。
5. 如搭配软饭或碎面，先控制主食量，避免一餐过多碳水。

### 宝宝调味和禁忌

- 不使用添加糖、普通成人调味料、人工添加剂、辣味、油炸做法、腌制品、加工肉和肥肉。
- 花生、坚果、螃蟹、贝壳类默认不推荐。
- 香蕉谨慎 / 避免，芒果默认不主动推荐。
- 第一次尝试豆腐或鸡蛋辅助成型时，不要同时叠加其他新食材。

## 成人/老人共用版

### 做法

1. 宝宝份分出后，成人锅中继续加入油麦菜梗和叶，煮到软熟。
2. 少量盐调味即可，不额外使用鸡汁、浓汤宝或高钠汤底。
3. 成人可加少量白胡椒或葱花提味；老人份尽量保持清淡。
4. 如果作为晚餐汤菜，建议搭配一份非淀粉蔬菜和少量主食，避免只喝汤不吃蛋白。

### 控糖控盐提醒

- 本菜本身控糖压力较小，主要注意搭配的软饭、面条或粥的份量；
- 姥爷和奶奶份不要用鸡汁、浓汤宝、虾皮、海米提鲜；
- 豆腐和鸡肉都是优质蛋白，但汤也要少盐，避免“清汤喝多也摄入钠”。

## 好吃的小妙招

- 鸡胸肉容易柴，加入豆腐泥和少量山药泥后丸子会更嫩。
- 丸子下锅时保持水微开，不要大滚，丸子不容易散也更嫩。
- 油麦菜叶最后下，既保留颜色，也避免煮到发苦。
- 不用高汤也能有味道：鸡肉丸、豆腐和油麦菜本身会让汤有清甜味。
- 宝宝份丸子做小一点，成人份可以做大一点，便于同锅不同形态。

## 阿姨执行提示

- 鸡肉必须去筋膜并打/剁细，丸子煮熟后切开确认没有粉色生肉；
- 宝宝份先盛出，成人份后加盐；
- 油麦菜要充分清洗，梗给宝宝要切得更细、更软；
- 做完后反馈：宝宝是否能咬开丸子、是否喜欢油麦菜味、老人是否觉得咸。

## 复热与留餐

- 适合冷藏留成人/老人份，复热时煮沸后再食用；
- 宝宝份尽量现做现吃，如需留餐只留未入口污染的一小份，冷藏并当天吃完；
- 复热后油麦菜颜色会变暗，属于正常现象，但不建议反复加热。

## 推荐逻辑

- 优先推荐：当需要低盐高蛋白宝宝餐、绿叶菜摄入不足、家里有鸡肉和豆腐时。
- 降低推荐：当近期豆腐/鸡肉重复过多、宝宝对油麦菜接受度低、或当天已经安排大量汤粥类菜品时。
