# 番茄红烩牛腩

## 一句话定位

番茄红烩牛腩 是 `家庭常做午餐 / 晚餐候选` 候选菜，适合用于 lunch, dinner 场景，后续可根据实际反馈调整推荐权重。

## 适合家庭的原因

- 围绕家里常备食材或已筛选外部候选菜名；
- 可按宝宝版和成人/老人共用版分开调味；
- 默认遵守高蛋白、少油、不要肥肉的家庭方向；
- 可交给阿姨按步骤执行，并通过饭后反馈迭代。

## 食材

### 共用食材

- 番茄
- 牛腩

### 宝宝额外食材

- 根据需要使用宝宝专用酱油、海苔碎、虾皮、洋葱、番茄或菌菇提味。

### 成人/老人共用版额外食材

- 生抽、老抽、蚝油、醋、胡椒、葱姜蒜等按菜品少量使用。

## 共用备菜

1. 共用食材先统一清洗、去皮、去筋膜或去刺。
2. 宝宝能吃的部分先切碎、小丁或处理到软烂。
3. 在加入成人调味料、糖、辣味、重酱之前，先分出宝宝份。
4. 成人/老人共用版再单独完成调味。

## 宝宝版

### 适用年龄和颗粒度

- 当前适配：1 岁 2 个月、8 颗牙；
- 优先形态：软烂、小丁、肉末、丸子、厚蛋烧、软饭、汤面；
- 避免大片、硬块、筋膜多、刺多或难咀嚼食材。

### 做法

1. 番茄红烩牛腩 可以作为宝宝餐或共用备菜菜谱，宝宝份只保留清淡基础做法。
2. 牛肉优先午餐安排，做成肉末、小丁或炖到软烂，晚餐不作为高频重肉。
3. 蔬菜类切碎或煮软后再给宝宝，片状、丝状食材不要太长。

### 宝宝调味和禁忌

- 不使用添加糖、普通成人调味料、人工添加剂、辣味、油炸做法、腌制品、加工肉和肥肉。
- 花生、坚果、螃蟹、贝壳类默认不推荐。
- 香蕉谨慎 / 避免，芒果默认不主动推荐。

## 成人/老人共用版

### 做法

1. 主蛋白先焯水、煎香或煸香，再加入根茎、番茄或菌菇小火炖到软烂。
2. 炖菜适合留餐，复热时小火热透，绿叶菜另做更好。
3. 牛肉类注意逆纹切、快炒或炖软，避免老人和宝宝吃到韧筋。

### 控糖控盐提醒

- 成人/老人共用版统一少油少盐；姥爷注意控糖控盐，奶奶注意高血糖风险。

## 好吃的小妙招

- 牛腩焯水后用热水炖，避免肉遇冷收缩。
- 番茄一半炒出沙、一半后放保留酸甜层次。
- 红烩味型不要依赖糖和浓酱，靠番茄、洋葱和长时间炖煮出味。
- 炖好后冷藏再撇一次凝固油，老人份更清爽。

## 阿姨执行提示

- 先确认当天是否有对应食材；
- 先做宝宝可共用的基础备菜，再做成人调味；
- 做完后反馈：宝宝接受度、老人是否觉得咸/油、执行是否麻烦。

## 复热与留餐

- 可作为姥姥姥爷晚餐复热候选；
- 冷藏分装，复热时彻底加热；
- 绿叶菜和易老的肉类尽量现做或分开放。

## 采购清单

- 已有食材：以 `inventory/current-inventory.md` 为准；
- 需要补买：按实际库存补齐主蛋白、蔬菜和调味。

## 推荐逻辑

- 优先推荐：当主要食材已有、需要高蛋白少油、需要宝宝和成人共用备菜时。
- 降低推荐：当近期重复、宝宝颗粒度不合适、老人控糖控盐压力大或阿姨反馈执行复杂时。
