## 3. 家庭常做午餐 / 晚餐候选

- 菜花炒培根；
- 番茄红烩牛腩；
- 咖喱土豆牛腩；
- 扁豆土豆焖排骨；
- 扁豆焖面；
- 菠菜炒鸡蛋；
- 小白菜肉片炖豆腐；
- 莴笋胡萝卜炒鸡蛋；
- 口蘑芦笋炒牛里脊；
- 肉片炒糯米笋；
- 圆白菜鸡蛋胡萝卜丝炒粉丝；
- 地三鲜家庭版；
- 尖椒炒鸡蛋；
- 干炸蘑菇；
- 肉末胡萝卜炖鲜蘑；
- 梅干菜肉末炒毛豆；
- 鸡汁小油菜炖干丝；
- 西红柿鸡蛋汤；
- 白萝卜牛肉汤；
- 海带牛肉汤；
- 小白菜鱼丸汤；
- 宝宝疙瘩汤。

执行提醒：

- 菜花炒培根：培根是加工肉，适合成人/老人共用版少量使用，宝宝默认不推荐；
- 番茄红烩牛腩、咖喱土豆牛腩：适合家庭炖煮类，宝宝版需要少调味或另做；
- 扁豆土豆焖排骨、扁豆焖面：主食/淀粉占比高，姥爷需要注意主食量；
- 菠菜炒鸡蛋、莴笋胡萝卜炒鸡蛋：适合早餐或正餐快手菜；
- 口蘑芦笋炒牛里脊：高蛋白、快手、适合家庭常用；
- 肉片炒糯米笋：适合快手炒菜，宝宝版需谨慎糯米笋咀嚼难度，成人/老人共用版少油少盐；
- 圆白菜鸡蛋胡萝卜丝炒粉丝：适合作为早餐或正餐快手菜，姥爷需要注意粉丝主食量；
- 小白菜肉片炖豆腐：适合老人和复热，宝宝版需切碎并清淡调味；
- 地三鲜家庭版：原版通常油重，应做少油版；
- 尖椒炒鸡蛋：成人菜，宝宝不推荐辣椒；
- 干炸蘑菇：油炸菜，作为偶尔改善菜，不作为宝宝和老人常规推荐；
- 肉末胡萝卜炖鲜蘑：适合家庭炖菜，宝宝版可切碎、清淡调味，成人/老人共用版少油少盐；
- 梅干菜肉末炒毛豆：下饭菜，梅干菜偏咸，姥爷和奶奶份需少量，宝宝默认不推荐；
- 鸡汁小油菜炖干丝：适合清淡豆制品菜，注意鸡汁钠含量，宝宝版需另做或少调味。

## 4. 外部渠道筛选后保留候选

> 以下来自外部渠道补充候选池，已经按用户反馈筛选。未列入的同组其他菜默认不喜欢，不进入当前候选清单。

### 4.1 快手炒菜 / 早餐午餐两用

- 西兰花炒牛肉片；
- 山药木耳炒肉片；
- 莴笋木耳炒肉片；
- 黄瓜木耳炒鸡蛋；
- 小白菜鸡蛋肉片炒粉丝；
- 炝拌藕片。

执行提醒：

- 小白菜鸡蛋肉片炒粉丝：由“小白菜鸡蛋炒肉片”调整而来，增加粉丝；姥爷需要注意粉丝主食量；
- 炝拌藕片：早餐可吃，宝宝默认不吃凉拌调味版，成人/老人共用版注意少盐少糖。

### 4.2 稳定复做家常菜 / 三菜一汤

- 番茄土豆炖牛腩；
- 香菇土豆炖鸡腿；
- 香菇鸡肉焖饭；
- 冬瓜肉丸汤；
- 肉末酿豆腐；
- 内酯豆腐三鲜汤；
- 羊肚菌虾滑炒芦笋；
- 酱爆口蘑鸡腿肉；
- 油鸡枞炒生菜；
- 番茄牛肉豆腐煲；
- 牛肉娃娃菜；
- 虾仁豆腐煲；
- 火烧云土豆焖鸡；
- 上汤粉丝娃娃菜；
- 苹果排骨；
- 莴笋丝炒吊龙丝。

执行提醒：

- 炖牛腩、炖鸡腿类适合复热，但需要撇油、少盐；
- 香菇鸡肉焖饭、火烧云土豆焖鸡属于主食/淀粉友好型菜，姥爷需要注意主食量；
- 内酯豆腐三鲜汤适合补充午餐汤类，但宝宝版需要确认三鲜具体食材和钠含量；
- 羊肚菌虾滑炒芦笋、虾仁豆腐煲适合补充虾类蛋白，宝宝版需少盐并注意虾滑配料；
- 酱爆口蘑鸡腿肉需要家庭化少酱少盐，宝宝不吃酱爆调味版；
- 油鸡枞炒生菜更适合成人/老人共用版，宝宝默认不推荐菌油重调味版；
- 番茄牛肉豆腐煲、牛肉娃娃菜适合高蛋白清淡方向，可作为午餐和复热候选；
- 上汤粉丝娃娃菜需要注意汤底和粉丝主食量；
- 苹果排骨偏酸甜口，姥爷和奶奶份需控糖，宝宝版需另做或少量尝试；
- 莴笋丝炒吊龙丝适合快手高蛋白菜，宝宝版需改成更软的小肉丁。

### 4.3 技法参考 / 家庭化改造

- 番茄牛腩老饭骨技法改良版；
- 萝卜牛腩清炖版；
- 少油版葱爆牛肉；
- 家庭版滑蛋虾仁；
- 少油版鱼香肉丝。

执行提醒：

- 老饭骨 / 王刚类只学习技法，不照搬重油重盐；
- 葱爆牛肉、鱼香肉丝需要明显少油、少盐、少糖；
- 宝宝不直接吃成人调味版，只共用肉菜备料。

### 4.4 爸爸妈妈 / 周末轻食

- 番茄虾仁意面。

执行提醒：

- 更适合爸爸妈妈或周末轻食；
- 老人控糖时注意意面量；
- 宝宝可借用番茄、虾仁等食材另做清淡版。

### 4.5 宝宝高蛋白 / 软烂颗粒度适配

- 鸡肉山药胡萝卜蒸丸子；
- 牛肉胡萝卜山药小丸子；
- 鳕鱼胡萝卜豆腐丸子；
- 虾仁西兰花豆腐饼；
- 鸡肉西葫芦小饼；
- 牛肉番茄生菜软饭；
- 虾仁西兰花胡萝卜软饭；
- 鳕鱼菠菜小饭团；
- 三文鱼玉米小饭团；
- 番茄虾滑蝴蝶面；
- 西红柿鸡蛋疙瘩汤；
- 虾仁蔬菜厚蛋烧；
- 牛肉蔬菜厚蛋烧。

已删除：

- 鸡肉南瓜软饭；
- 南瓜鸡肉疙瘩汤。

执行提醒：

- 饼类只放宝宝餐，不放大人早餐；
- 牛肉类优先午餐，晚餐少安排重肉；
- 软饭和饭团注意颗粒度，不需要打泥。

### 4.6 汤类补充

- 白萝卜排骨汤；
- 小白菜豆腐汤；
- 菠菜鸡蛋汤。

执行提醒：

- 用于补齐姥姥姥爷午餐“三菜一汤 + 米饭”；
- 绿叶汤更适合现做现吃；
- 排骨汤需要撇油，姥爷和奶奶份少盐。

### 4.7 鱼虾海鲜 / 青岛海鲜扩展

- 清蒸鲈鱼；
- 少油煎焖带鱼；
- 海参小米粥；
- 干贝冬瓜豆腐汤；
- 海米小白菜豆腐汤；
- 鲅鱼炖蒜苔。

执行提醒：

- 鱼类需要关注刺、产地、养殖 / 野生和脂肪含量；
- 带鱼、鲅鱼宝宝默认不直接吃整块鱼肉；
- 干贝、海米用于成人/老人共用版提鲜，宝宝默认不使用；
- 海参更偏成人/老人改善餐。
