# 银鳕鱼豆腐羹

## 一句话定位

银鳕鱼豆腐羹 是 `宝宝高频餐 / 可共用备菜类` 候选菜，适合用于 baby_meal 场景，后续可根据实际反馈调整推荐权重。

## 适合家庭的原因

- 围绕家里常备食材或已筛选外部候选菜名；
- 可按宝宝版和成人/老人共用版分开调味；
- 默认遵守高蛋白、少油、不要肥肉的家庭方向；
- 可交给阿姨按步骤执行，并通过饭后反馈迭代。

## 食材

### 共用食材

- 鳕鱼
- 豆腐

### 宝宝额外食材

- 根据需要使用宝宝专用酱油、海苔碎、虾皮、洋葱、番茄或菌菇提味。

### 成人/老人共用版额外食材

- 生抽、老抽、蚝油、醋、胡椒、葱姜蒜等按菜品少量使用。

## 共用备菜

1. 共用食材先统一清洗、去皮、去筋膜或去刺。
2. 宝宝能吃的部分先切碎、小丁或处理到软烂。
3. 在加入成人调味料、糖、辣味、重酱之前，先分出宝宝份。
4. 成人/老人共用版再单独完成调味。

## 宝宝版

### 适用年龄和颗粒度

- 当前适配：1 岁 2 个月、8 颗牙；
- 优先形态：软烂、小丁、肉末、丸子、厚蛋烧、软饭、汤面；
- 避免大片、硬块、筋膜多、刺多或难咀嚼食材。

### 做法

1. 银鳕鱼豆腐羹 可以作为宝宝餐或共用备菜菜谱，宝宝份只保留清淡基础做法。
2. 鱼肉熟后再次检查鱼刺，取大刺少的部位，按当前咀嚼能力切碎或压散。
3. 豆腐切小块或压碎，减少整块滑入口腔造成的咀嚼压力。
4. 汤羹类保持稀软顺滑，固体食材切小，汤面浮油撇掉。

### 宝宝调味和禁忌

- 不使用添加糖、普通成人调味料、人工添加剂、辣味、油炸做法、腌制品、加工肉和肥肉。
- 花生、坚果、螃蟹、贝壳类默认不推荐。
- 香蕉谨慎 / 避免，芒果默认不主动推荐。

## 成人/老人共用版

### 做法

1. 先做清爽汤底，再按耐煮到易熟的顺序加入主蛋白、豆腐和蔬菜。
2. 汤羹类优先少油、最后调盐，适合三菜一汤或老人留餐。
3. 鱼类关注鱼刺、腥味、产地和复热表现，食用前再次查刺。
4. 豆腐类少翻动，保持完整，老人份少盐但可用菌菇/番茄提鲜。

### 控糖控盐提醒

- 成人/老人共用版统一少油少盐；姥爷注意控糖控盐，奶奶注意高血糖风险。

## 好吃的小妙招

- 银鳕鱼脂肪较高，先蒸熟再入羹，汤面浮油可撇掉。
- 豆腐切小丁最后加入，轻推不要大力翻。
- 用蛋花或少量淀粉水让羹自然浓稠，宝宝更好舀食。
- 鱼肉入锅前必须确认无刺。

## 阿姨执行提示

- 先确认当天是否有对应食材；
- 先做宝宝可共用的基础备菜，再做成人调味；
- 做完后反馈：宝宝接受度、老人是否觉得咸/油、执行是否麻烦。

## 复热与留餐

- 默认更适合现做现吃；
- 如需留餐，优先只留汤汁、炖煮部分或未混入口水的成人份。

## 采购清单

- 已有食材：以 `inventory/current-inventory.md` 为准；
- 需要补买：按实际库存补齐主蛋白、蔬菜和调味。

## 推荐逻辑

- 优先推荐：当主要食材已有、需要高蛋白少油、需要宝宝和成人共用备菜时。
- 降低推荐：当近期重复、宝宝颗粒度不合适、老人控糖控盐压力大或阿姨反馈执行复杂时。
