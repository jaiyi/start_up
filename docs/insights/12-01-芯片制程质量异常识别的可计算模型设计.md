# 12-01 · 芯片制程质量异常识别的可计算模型设计

> 讨论稿 / 会更新 · 最近更新 2026-09-30
>
> **一句话结论**：`12-芯片制程质量异常识别框架.md` 是工艺专家视角的机理框架；这一篇把它转成数据挖掘和工程落地方案：把 Inline、WAT、CP、FT、可靠性、图像和客诉数据统一到 lot / wafer / die / site / block / time 维度，设计可计算算子、异常分数、图像特征、多模态模型和闭环决策规则，用来提前识别 spec 内异常、maverick wafer / die / lot 和潜在出货风险。

---

## 0. 这篇在回答什么

上一篇 `12-芯片制程质量异常识别框架.md` 解决的是工艺质量专家的知识表达：

> 哪些制程异常、测试异常、图像 pattern 和可靠性现象，可能对应哪些芯片失效风险。

这一篇要进一步回答：

> 如何把这些专家知识转成可落地计算的特征、算子、模型、分数和系统流程。

目标不是做一个泛泛的“AI 质检模型”，而是建立一个可以持续运行的质量风险识别系统：

```text
多源质量数据
  ↓
数据对齐与清洗
  ↓
特征算子
  ↓
异常检测 / 风险预测 / 规则引擎
  ↓
lot / wafer / die / block 风险评分
  ↓
hold / screen / downgrade / release / fab feedback / design feedback
```

适用产品线：

- NOR Flash；
- NAND Flash；
- DRAM；
- GD32 MCU；
- 指纹 / 触控传感器；
- 模拟 / 电源芯片。

## 1. 总体建模对象：先定义质量分析的实体粒度

芯片质量数据不是一张扁平表。必须先明确实体层级。

### 1.1 核心实体

| 实体 | 说明 | 典型用途 |
|---|---|---|
| Product | 产品型号 / die revision / package | 横向比较同产品不同批次 |
| Lot | 晶圆批次 | lot hold、lot release、供应商追责 |
| Wafer | 单片晶圆 | wafer map pattern、maverick wafer |
| Die | 单颗裸 die | CP 级风险评分、maverick die |
| Site | 测试 site / probe site | 排除测试机台或探针卡问题 |
| Reticle field | 光刻曝光场 | 识别 reticle repeat / stepper 问题 |
| Block / Sector / Page | 存储阵列单元 | Flash / NAND / SRAM bitmap 分析 |
| Pin / IO | 引脚 / pad | IO leakage、ESD、封装 open/short |
| Tool / Chamber | 制程设备 / 腔体 | tool fingerprint、chamber drift |
| Time window | 工艺时间窗口 | trend、漂移、异常批次追踪 |

### 1.2 推荐统一主键

每条数据最好能对齐到以下 key：

```text
product_id
revision
fab
process_node
lot_id
wafer_id
die_x
die_y
reticle_x
reticle_y
package_lot
osat
cp_tester
ft_tester
test_site
timestamp
```

对存储类芯片，还需要：

```text
die_id
plane_id
block_id
page_id
wordline_id
bitline_id
sector_id
address
bit_index
```

对封装和模组类，还需要：

```text
package_id
substrate_lot
bond_wire_lot
mold_compound_lot
fpc_lot
module_lot
```

核心原则：

> 没有 genealogy，模型只能做相关性描述；有 genealogy，模型才可能定位到 fab / OSAT / tool / chamber / material 的真实来源。

## 2. 数据层设计

### 2.1 数据类型

| 数据类型 | 示例 | 主要价值 |
|---|---|---|
| Inline 数值 | CD、overlay、膜厚、etch depth、particle count | 发现过程漂移和设备异常 |
| WAT / PCM | Vt、Idsat、Ioff、leakage、contact R、RO | 工艺结构级健康度 |
| CP 参数 | Vmin、Fmax、IDDQ、IO leakage、BIST result | die 级质量边界 |
| FT 参数 | 高低温功能、接口、功耗、模拟参数 | 封装后最终边界 |
| Reliability | HTOL、HAST、TC、P/E、retention、disturb | 长期风险和应力 delta |
| 图像数据 | CD-SEM、defect image、wafer map、X-ray、SAM、raw sensor image | 形貌和空间 pattern |
| 客户反馈 | RMA、客诉模式、现场日志、date code | 反向校准预警规则 |

### 2.2 数据建模层级

建议按 4 层建模：

```text
Raw Layer
  原始文件、原始测试值、原始图片、原始 bin log

Standard Layer
  单位统一、字段标准化、坐标对齐、时间对齐、异常值标记

Feature Layer
  统计特征、空间特征、图像 embedding、应力 delta、多参数组合特征

Decision Layer
  wafer score、die score、lot score、risk reason、recommended action
```

### 2.3 数据清洗基本规则

必须显式处理：

- 单位不一致：nm / um、mA / uA、℃、V、MHz；
- 测试条件不一致：temperature、voltage、frequency、mode；
- tester / site 偏差；
- probe contact 异常；
- retest pass 数据；
- 缺失值；
- 不同产品 revision；
- 不同 fab / process option；
- 不同封装形式。

关键原则：

> 不要把测试系统异常误当成芯片异常；建模前必须先做 tester / site / probe card / handler 的偏差消除。

## 3. 算子总览：把专家语言转成数学特征

### 3.1 六大类基础算子

| 算子类别 | 输入 | 输出 | 识别问题 |
|---|---|---|---|
| 中心漂移算子 | 参数序列 / lot 分布 | mean shift score | 工艺中心偏移 |
| 离散度算子 | wafer / lot 参数分布 | sigma / IQR / tail score | 均匀性变差、尾部变厚 |
| 空间 pattern 算子 | wafer map / bitmap | edge / radial / cluster / reticle score | 制程空间异常 |
| 边界 margin 算子 | V/T/F shmoo、Vmin、Fmax | margin score | 低压、高温、高频风险 |
| 应力 delta 算子 | stress 前后参数 | delta score / degradation rate | 可靠性退化风险 |
| 多参数 out-of-family 算子 | 多维特征向量 | anomaly score | maverick lot / wafer / die |

### 3.2 复合风险分数

每个实体可以形成统一风险分数：

```text
RiskScore = w1 * DriftScore
          + w2 * TailScore
          + w3 * SpatialScore
          + w4 * MarginScore
          + w5 * StressDeltaScore
          + w6 * MultiParamOutlierScore
          + w7 * DownstreamCorrelationScore
```

其中权重不建议一开始就用复杂模型自动学习。早期可以：

1. 专家设初始权重；
2. 用历史 RMA / reliability fail 回测；
3. 再逐步用模型校准权重。

## 4. 中心漂移算子

### 4.1 适用场景

用于识别：

- lot-to-lot drift；
- wafer-to-wafer shift；
- chamber drift；
- recipe drift；
- material batch shift。

典型参数：

- Vt；
- Idsat；
- Ioff；
- ring oscillator；
- contact R；
- via R；
- metal R；
- Flash erase / program time；
- SRAM Vmin；
- ADC offset；
- bandgap voltage；
- sensor baseline。

### 4.2 基础特征

对每个 `product_id + test_item + condition` 建历史基线。

```text
mu_ref = historical median or EWMA mean
sigma_ref = historical robust sigma
x_lot = current lot median
```

中心漂移分数：

```text
DriftZ = (x_lot - mu_ref) / sigma_ref
DriftScore = abs(DriftZ)
```

推荐用 robust 版本：

```text
RobustZ = 0.6745 * (x - median_ref) / MAD_ref
```

优点：不容易被历史异常批次污染。

### 4.3 趋势漂移特征

对连续批次做斜率：

```text
TrendSlope = slope(EWMA(parameter_mean over recent N lots))
TrendScore = abs(TrendSlope) / allowed_slope
```

触发条件示例：

```text
abs(RobustZ) > 3
or TrendScore > 1
or 连续 7 批同方向偏移
```

### 4.4 对应失效风险

| 参数漂移 | 风险 |
|---|---|
| Vt 偏高 + RO 慢 | MCU / DRAM / SRAM 低压或高频 fail |
| Vt 偏低 + Ioff 高 | 高温漏电、低功耗异常、retention 风险 |
| contact R 升高 | 固定地址 fail、接口 margin、EM 风险 |
| Flash erase time 右移 | 擦除效率下降、endurance 风险 |
| bandgap 偏移 | 模拟输出漂移、ADC / LDO 参数异常 |

## 5. 离散度与尾部算子

### 5.1 为什么比均值更重要

很多质量风险不是均值变坏，而是尾部变厚：

```text
平均值正常
  但 P99 / P99.9 明显恶化
  → 少量边缘 die 可能在客户现场失效
```

### 5.2 基础特征

对每个 lot / wafer / test_item 计算：

```text
mean
median
std
MAD
IQR
P1 / P5 / P95 / P99 / P99.9
min / max
range
skewness
kurtosis
tail_count
```

Tail count 示例：

```text
TailCountHigh = count(x > mu_ref + k * sigma_ref)
TailRatioHigh = TailCountHigh / total_count

TailCountLow = count(x < mu_ref - k * sigma_ref)
TailRatioLow = TailCountLow / total_count
```

建议 k：

- 常规：3σ；
- 关键质量项：2.5σ；
- 高可靠性产品：2σ 或按 guardband 定义。

### 5.3 分布距离特征

比较当前 lot 与历史正常族群分布。

可用指标：

```text
KS statistic
Wasserstein distance
Jensen-Shannon divergence
Population Stability Index, PSI
```

PSI 常用解释：

| PSI | 含义 |
|---|---|
| < 0.1 | 稳定 |
| 0.1 - 0.25 | 有漂移，需要关注 |
| > 0.25 | 明显漂移，需要调查 |

### 5.4 对应失效风险

| 分布异常 | 风险 |
|---|---|
| Flash program time tail 变厚 | 少量 cell 编程困难，后续 retention / verify fail |
| erase time tail 变厚 | 擦除效率边缘，P/E 后 fail 风险 |
| SRAM Vmin tail 右移 | 客户低压偶发死机 |
| IO leakage tail 变厚 | ESD clamp / pad oxide 弱点 |
| ADC offset tail 变厚 | 模拟精度离散，校准边界不足 |
| sleep current tail 变厚 | 低功耗模式异常，IoT 产品续航风险 |

## 6. 空间 pattern 算子

空间 pattern 是晶圆质量分析的核心。它把“数值异常”变成“制程线索”。

### 6.1 输入形式

```text
WaferMap = {
  wafer_id,
  die_x,
  die_y,
  value or bin,
  test_item,
  condition
}
```

value 可以是：

- pass / fail；
- bin code；
- leakage；
- Vmin；
- Fmax；
- erase time；
- ECC count；
- ADC offset；
- sensor baseline。

### 6.2 坐标归一化

把 die 坐标转成极坐标和归一化位置：

```text
x_norm = (x - x_center) / wafer_radius
y_norm = (y - y_center) / wafer_radius
r = sqrt(x_norm^2 + y_norm^2)
theta = atan2(y_norm, x_norm)
```

这些是 edge / radial / half-wafer 检测的基础。

### 6.3 Edge ring 算子

识别 wafer 边缘异常。

特征：

```text
EdgeMean = mean(value where r > r_threshold)
CenterMean = mean(value where r <= r_threshold)
EdgeCenterDelta = EdgeMean - CenterMean
EdgeFailRate = fail_count(edge) / die_count(edge)
CenterFailRate = fail_count(center) / die_count(center)
EdgeRisk = EdgeFailRate / max(CenterFailRate, epsilon)
```

触发：

```text
EdgeRisk > threshold
or abs(EdgeCenterDelta) > k * historical_sigma
```

常见指向：

- 膜厚边缘效应；
- 刻蚀边缘效应；
- CMP 边缘异常；
- 温控 / plasma 均匀性问题。

### 6.4 Radial gradient 算子

识别从中心到边缘的连续梯度。

建模：

```text
value = a + b * r + error
RadialSlope = b
RadialR2 = R^2
```

如果：

```text
abs(RadialSlope) 高
且 RadialR2 高
```

说明参数随半径有系统变化。

常见指向：

- 旋涂均匀性；
- 薄膜沉积；
- 刻蚀；
- 退火；
- CMP。

### 6.5 Cluster 算子

识别局部聚集异常。

可用方法：

- DBSCAN；
- Moran's I；
- Getis-Ord Gi*；
- connected component；
- nearest-neighbor distance。

特征：

```text
ClusterCount
LargestClusterSize
ClusterDensity
MeanNearestNeighborDistance
LocalFailRate / GlobalFailRate
```

典型判别：

```text
LocalFailRate >> GlobalFailRate
+ defect image cluster 重叠
→ particle / contamination / chuck 局部问题
```

### 6.6 Reticle repeat 算子

识别光刻 reticle / stepper 问题。

输入：

```text
die_x, die_y
reticle_x, reticle_y
fail_bin or parameter
```

特征：

```text
ReticleCellFailRate[reticle_x, reticle_y]
ReticleRepeatScore = variance_across_reticle_cells / random_expected_variance
```

或计算：

```text
同一 reticle 相对位置的 fail rate 是否显著高于随机分布
```

典型判别：

```text
reticle repeat pattern
+ overlay / CD 图像异常
→ mask / stepper / litho issue
```

### 6.7 Scratch / line pattern 算子

识别线状异常。

可用方法：

- Hough transform；
- line fitting；
- skeletonization；
- anisotropy score。

特征：

```text
LineScore
LineLength
LineOrientation
FailDensityAlongLine / GlobalFailDensity
```

典型判别：

```text
高 LineScore
+ defect image scratch
→ 搬运、机械刮伤、颗粒拖拽
```

### 6.8 Half-wafer / quadrant 算子

识别半片或象限异常。

特征：

```text
LeftRightDelta
TopBottomDelta
QuadrantMaxDelta
HalfWaferRisk = max(abs(left-right), abs(top-bottom)) / sigma_ref
```

常见指向：

- chamber 气流；
- chuck 接触；
- 温控；
- 设备状态；
- 曝光或处理非均匀。

## 7. 图像算子

图像算子把视觉检测结果转成可和数值测试关联的特征。

### 7.1 图像输入类型

| 图像 | 用途 |
|---|---|
| CD-SEM | 线宽、孔径、边缘粗糙、形貌异常 |
| Overlay image | 层间对准偏差 |
| Defect image | particle、scratch、residue、bridge、open |
| SEM review | 缺陷复判和类别确认 |
| X-ray | die attach void、wire bond、焊球异常 |
| SAM | delamination、封装分层、空洞 |
| Raw sensor image | dead pixel、row / column noise、SNR |
| Wafer map image | edge、cluster、radial、reticle repeat |

### 7.2 传统视觉特征

适合早期落地，解释性强。

常用特征：

```text
area
perimeter
aspect_ratio
circularity
edge_roughness
line_width
space_width
hole_diameter
void_ratio
crack_length
contrast
texture_entropy
orientation
connected_component_count
```

对应风险：

| 图像特征 | 风险 |
|---|---|
| line_width 偏小 / 偏大 | CD 漂移、速度 / 漏电 / open-short 风险 |
| edge_roughness 增大 | litho / etch 稳定性变差 |
| void_ratio 偏高 | die attach 热阻、功率可靠性风险 |
| crack_length 增大 | 封装机械可靠性风险 |
| connected_component_count 增加 | 颗粒 / 残留 / 污染风险 |
| row / column noise 增加 | sensor readout / ADC 通道异常 |

### 7.3 深度视觉 embedding

适合 defect image / SEM review / X-ray / SAM 大量数据。

方法：

- CNN / ViT 分类模型；
- self-supervised embedding；
- image autoencoder；
- contrastive learning；
- anomaly detection on embeddings。

输出特征：

```text
ImageClassProbabilities
ImageEmbedding[1..d]
ImageAnomalyScore
NearestKnownDefectDistance
VisualClusterId
```

重点不是只输出类别，而是输出：

- 是否属于历史常见缺陷；
- 与哪个已知失效模式最接近；
- 是否是新型未知缺陷；
- 是否与 wafer map / CP fail 空间重叠。

### 7.4 图像和坐标叠加算子

最有质量价值的是把图像坐标和 die 坐标对齐。

算子：

```text
DefectToDieDistance
DefectInDieFlag
DefectNearCriticalAreaFlag
DefectOverlapFailDieRatio
DefectClusterToFailClusterIoU
```

其中：

```text
IoU = Area(defect_cluster ∩ fail_cluster) / Area(defect_cluster ∪ fail_cluster)
```

典型判别：

| 特征组合 | 预警方向 |
|---|---|
| defect cluster 与 CP fail cluster IoU 高 | 局部污染或制程缺陷高度可疑 |
| defect 接近 SRAM / Flash array critical area | 存储阵列潜在 fail 风险 |
| X-ray void 区域与高温 fail package 重合 | 封装散热问题 |
| SAM delamination 与 TC fail 重合 | 分层导致热机械可靠性风险 |

## 8. V / T / F Shmoo 算子

### 8.1 输入

```text
entity_id
voltage
temperature
frequency
mode
pass_fail
measurement_value
```

### 8.2 基础特征

| 特征 | 含义 |
|---|---|
| Vmin | 最低通过电压 |
| Vmax | 最高通过电压 |
| Fmax | 最高通过频率 |
| Tmin / Tmax | 温度通过边界 |
| PassArea | shmoo 图中 pass 区域面积 |
| BoundarySlope | pass/fail 边界斜率 |
| HoleCount | pass 区域中的异常 fail 洞 |
| IslandCount | fail 区中的异常 pass 岛 |

### 8.3 风险解释

| 特征组合 | 指向 |
|---|---|
| Vmin 右移 + Fmax 左移 | logic / SRAM / interface margin 变差 |
| 高温 pass area 明显缩小 | leakage、retention、模拟漂移 |
| 低温启动 fail 边界扩大 | oscillator / PLL / bandgap startup 风险 |
| pass 区域出现孤立 fail hole | 测试不稳定、时序毛刺、边缘 die、设备接触问题 |
| 同 wafer 多 die shmoo 形状相似偏移 | 系统性制程漂移 |

## 9. 应力 delta 与退化速率算子

### 9.1 输入

```text
measurement_before_stress
measurement_after_stress
stress_type
stress_duration
stress_condition
```

### 9.2 基础特征

```text
AbsoluteDelta = x_after - x_before
RelativeDelta = (x_after - x_before) / max(abs(x_before), epsilon)
DegradationRate = Delta / stress_time
NormalizedDelta = Delta / historical_sigma_delta
```

### 9.3 产品相关 delta

| 产品 | Delta 特征 | 预警风险 |
|---|---|---|
| NOR / eFlash | retention bake 前后 bit error 增量 | charge leakage / oxide 弱点 |
| NOR / NAND | P/E cycling 前后 erase / program time 增量 | endurance 风险 |
| NAND | P/E 后 raw BER 增量、read retry shift | ECC margin 风险 |
| DRAM | 高温 stress 后 retention time 下降 | capacitor leakage / weak cell |
| MCU | HTOL 后 standby current 增量 | leakage / BTI / oxide 风险 |
| 传感器 | 湿热后 baseline drift | 封装湿气 / 表面材料风险 |
| 模拟电源 | HTOL 后 Vout / Iq drift | reference / bias / leakage 风险 |
| 封装 | TC 后 contact resistance 增量 | 焊点 / bond wire / delamination 风险 |

```text
nor_read_margin_mean

```

### 关键组合算子

```text
NorRetentionRisk = f(
```

```text
NorEraseRisk = f(

```

```text
NorInterfaceRisk = f(
```

## 11. 模型体系设计

不要试图用一个大模型解决所有质量问题。更实际的是分层模型。

### 11.1 第一层：规则与统计过程控制

用于强物理约束和合规放行。

方法：

- spec limit；
- guardband limit；
- SPC rule；
- Cpk / Ppk；
- hard fail rule；
- retest rule；
- mandatory hold rule。

适合：

- ESD / latch-up；
- safety critical；
- 明确 out-of-spec；
- 已知高风险组合。

### 11.2 第二层：无监督异常检测

用于识别 spec 内异常。

模型：

- Isolation Forest；
- One-Class SVM；
- Local Outlier Factor；
- Autoencoder；
- Gaussian Mixture Model；
- robust covariance / Mahalanobis distance。

输出：

```text
DieAnomalyScore
WaferAnomalyScore
LotAnomalyScore
FeatureContribution
NearestNormalCluster
```

适合：

- 新产品早期；
- 客诉标签不足；
- 找 maverick die / wafer / lot；
- 多参数组合异常。

### 11.3 第三层：监督风险预测

当有历史 reliability fail / RMA / 客户现场标签后，可以训练监督模型。

模型：

- Logistic Regression；
- Random Forest；
- Gradient Boosting / XGBoost / LightGBM；
- calibrated classifier；
- survival model；
- quantile regression。

标签：

```text
reliability_fail
retention_fail_after_bake
field_return_within_6_months
rma_confirmed_failure
customer_high_temp_read_fail
mcu_boot_fail
sensor_false_touch
analog_drift_fail
```

输出：

```text
FailureProbability
RiskBucket
TopContributingFeatures
RecommendedAction
```

### 11.4 第四层：图模型和因果关联

用于跨阶段追踪和 root cause 缩小范围。

图节点：

- lot；
- wafer；
- die；
- product；
- tool；
- chamber；
- recipe；
- material batch；
- package lot；
- test program；

边：

- processed_by；
- tested_by；
- packaged_by；
- same_reticle_position；

## 12. 风险评分与决策规则

### 12.1 分数结构

建议每个实体都有分数：

```text
DieRiskScore
WaferRiskScore
LotRiskScore
ProductRiskScore
```

综合分：

```text
RiskScore = w1 * DriftScore
          + w2 * TailScore
          + w3 * SpatialScore
          + w4 * MarginScore
          + w5 * StressDeltaScore
          + w6 * MultiParamOutlierScore
          + w7 * ImageAnomalyScore
          + w8 * DownstreamCorrelationScore
```

### 12.2 风险等级

| 等级 | 条件 | 动作 |
|---|---|---|
| R0 正常 | 所有分数在正常族群内 | release |
| R1 关注 | 单项轻微 out-of-family | monitor / trend watch |
| R2 加严 | 多项边缘或 tail 变厚 | add screen / guardband |
| R3 隔离 | 空间 pattern 明显或可靠性 delta 异常 | hold wafer / hold lot |
| R4 停出 | 与 RMA / reliability fail 强相关 | stop ship / containment |

### 12.3 决策规则示例

```text
IF RetentionBakeDelta > threshold
AND TunnelLeakageTailScore > threshold
AND ReadMarginP01 < guardband
THEN RiskBucket = R3
ACTION = hold lot + add retention screen + fab oxide review
```

```text
IF WaferMapClusterScore high
AND DefectClusterToFailClusterIoU high
THEN RiskBucket = R3
ACTION = hold affected wafers + defect SEM review + tool/chamber trace
```

```text
IF DieAnomalyScore high
AND all individual tests pass
AND feature contributions include Vmin, Fmax, RO
THEN RiskBucket = R2
ACTION = downgrade or add low-voltage/high-frequency guardband
```

## 13. 验证与评估指标

质量模型不能只看 AUC。因为真实业务更关心漏放风险和误杀成本。

### 13.1 离线评估

指标：

- recall at high-risk bucket；
- false hold rate；
- precision for R3/R4；
- RMA lift；
- reliability fail capture rate；
- maverick wafer detection rate；
- time-to-detect；
- engineering review workload。

关键指标定义：

```text
RMA Lift = RMA rate in flagged group / RMA rate in unflagged group

False Hold Rate = good lots held / all held lots

Capture Rate = known bad lots flagged / all known bad lots
```

### 13.2 回测方式

按时间切分：

```text
train: 过去 12-18 个月
validation: 接下来 3 个月
test: 最近 3 个月
```

不能随机切分，因为制程数据强时间相关。

要分层评估：

- by product；
- by fab；
- by process node；
- by package；
- by customer application；
- by failure mode。

### 13.3 线上评估

上线后看：

- 每周 flagged lot 数；
- 每周 hold / release 决策；
- 工程师确认率；
- 追加筛选命中率；
- 后续 FT / reliability fail 是否下降；
- RMA 是否下降；
- 是否出现过漏报重大风险。

- 专项 guardband；

- SEM review 分类；

- 把工程师 review 结果作为标签；

## 17. 最终收束

把工艺专家输入转成数据挖掘系统，关键不是把所有数据丢给一个模型，而是把专家判断拆成可计算算子：

- 均值是否偏移；
- 分布是否变宽；
- 尾部是否变厚；
- wafer map 是否有 pattern；
- 图像形貌是否异常；
- stress 前后 delta 是否异常；
- 多参数组合是否 out of family；
- 上游异常是否能解释下游 CP / FT / reliability / RMA。

真正可落地的模型应该是：

```text
规则守底线
+ 统计抓漂移
+ 空间算子找制程线索
+ 图像模型提形貌异常
+ 无监督模型找 maverick
+ 监督模型预测真实风险
+ 工程师反馈持续校准
```

最终目标不是替代质量工程师，而是让质量工程师更早看到：

> 哪个 lot / wafer / die 虽然现在 pass，但已经不像正常族群，应该被 hold、加严筛选、降级、反馈 fab 或进入客户 containment。
