# 11 · 芯片失效类型与检测判别框架

> 讨论稿 / 会更新 · 最近更新 2026-09-30
>
> **一句话结论**：芯片质量分析不能只看“坏了什么”，而要把产品类型、异常表现、电性边界、空间分布、时间演化、电流波形和物理证据串成证据链。对存储、MCU、传感器和模拟电源芯片来说，真正有判断力的工程师看的是“特征组合”，不是单点症状。

---

## 0. 这篇在回答什么

以兆易创新这类产品组合为代表，典型芯片线包括：

- 存储芯片：NOR Flash、NAND Flash、部分 DRAM / 利基型 DRAM；
- MCU：GD32 通用 MCU，包括 ARM Cortex-M 与 RISC-V MCU；
- 传感器：指纹识别、触控、人机交互相关芯片；
- 模拟及周边：电源管理、模拟信号链、与 MCU / 存储配套的外围芯片。

这篇不讨论单个公司具体批次或具体产品的失效数据，而是从**芯片工艺与质量工程**角度，建立一个通用分析框架：

1. 这些芯片大类分别容易出现哪些失效；
2. 失效在系统里通常表现成什么异常；
3. 用什么检测方法可以把异常特征测出来；
4. 哪些“测量特征组合”可以指向对应失效机理；
5. 实际工程上如何形成从现象到失效原因的判断链。

---

## 1. 总体框架：先分失效来源

芯片失效不能一上来就归因到“芯片坏了”。更合理的第一层分类是：

| 失效来源 | 典型表现 | 优先关注 |
|---|---|---|
| 设计边界失效 | 高温、低压、高频或特定模式下失败 | 设计 margin、验证覆盖、状态机边界 |
| 制程缺陷失效 | 固定地址、固定 bit、固定 pin、固定区域失败 | 光刻、蚀刻、金属、via、氧化层、颗粒 |
| 可靠性老化失效 | 使用一段时间后恶化，高温或高压加速 | TDDB、HCI、BTI、EM、Flash oxide 退化 |
| 封装与板级失效 | 按压、冷热循环、换板后现象变化 | 焊点、bond wire、delamination、PCB 应力 |
| 电气过应力失效 | 突然死亡、电流大、IO 漏电、低阻 | ESD、EOS、latch-up、反接、浪涌 |
| 测试遗漏 / 应用匹配 | 出厂过，客户系统失败 | 测试覆盖、应用时序、电源、软件初始化 |

核心判断原则：

> 单一异常只能提出假设；多个维度特征一致，才形成失效判断。

## 2. 通用检测维度

### 2.1 复现性

检测方法：

- ATE 功能测试；
- 板级复现测试；
- 多次上电 / 下电循环；
- 温度循环测试；
- 电压扫描测试；
- 长时间运行测试。

特征组合：

| 特征 | 更可能方向 |
|---|---|
| 每次固定失败 | 硬缺陷、固定地址缺陷、金属 open / short、IO 损伤 |
| 偶发失败 | 时序 margin、电源噪声、接口 SI、软件竞态、温度漂移 |
| 上电初期失败，重启后恢复 | POR / BOR、晶振、PLL、电源 ramp、复位释放时序 |
| 运行一段时间后失败 | 热问题、retention、漏电、EMI、老化、软件累积错误 |

### 2.2 V / T / F Shmoo

即同时或分别扫描：

- V：电压；
- T：温度；
- F：频率。

检测方法：

- 低压 / 标压 / 高压测试；
- 低温 / 常温 / 高温测试；
- SPI / QSPI / DRAM / MCU 主频扫描；
- pass / fail map；
- 边界裕量统计。

特征组合：

| 特征 | 更可能方向 |
|---|---|
| 低压失败，高压正常 | SRAM / DRAM cell margin、sense margin、时序余量、POR / BOR、电源完整性 |
| 高温失败，常温正常 | 漏电、retention、阈值漂移、Flash 电荷泄漏、DRAM weak cell、模拟参考漂移 |
| 高频失败，低频正常 | setup / hold margin、SPI / QSPI SI、clock skew、IO 驱动、dummy cycle 配置 |
| 低温失败，高温正常 | 晶振起振、PLL lock、bandgap / LDO 启动、封装应力、Flash P/E pump margin |

### 2.3 电流特征

检测方法：

- IDDQ / standby current；
- sleep / deep sleep current；
- active current profile；
- IO leakage；
- curve tracer I-V；
- 上电电流波形；
- 电源分析仪 / 示波器 + 电流探头。

特征组合：

| 特征 | 更可能方向 |
|---|---|
| 待机电流明显偏大 | 栅氧漏电、PN 结漏电、ESD clamp 损伤、制程污染、IO 反灌 |
| 高温下漏电指数级上升 | junction leakage、oxide defect、weak cell、离子污染、潮湿污染 |
| 某个 IO 漏电异常 | ESD diode 损伤、pad oxide 损伤、latch-up 通道损伤、焊接短路 |
| 上电瞬间电流过大后掉电 | latch-up、内部短路、电源保护、负载短路 |
| 某功能开启后电流异常 | 对应模块局部损伤、bias 异常、charge pump 异常、LDO / bandgap 异常 |

### 2.4 空间分布

检测方法：

- memory bitmap；
- fail bit map；
- 地址扫描；
- March test；
- checkerboard pattern；
- wafer map；
- lot yield trend；
- CP / FT 数据比对。

特征组合：

| 特征 | 更可能方向 |
|---|---|
| 固定 bit 一直错 | memory cell 硬缺陷、bitline open / short、sense amp 局部问题、via / contact 缺陷 |
| 固定 row / column 错 | wordline driver、row / column decoder、bitline / wordline 缺陷 |
| 固定 block / sector 总失败 | Flash / NAND 局部 block 缺陷、高压路径异常、erase path 异常 |
| wafer 边缘失效率高 | 光刻均匀性、薄膜厚度、etch uniformity、implant / CMP 边缘效应 |
| 某几个 lot 集中异常 | 工艺窗口漂移、设备状态、材料批次、recipe / clean 异常 |
| 随机散点缺陷 | particle contamination、随机 metal short / open、defect density 偏高 |

### 2.5 时间演化

检测方法：

- 高温 bake；
- HTOL；
- P/E cycling；
- read disturb stress；
- program disturb stress；
- power cycling；
- thermal cycling。

特征组合：

| 特征 | 更可能方向 |
|---|---|
| 刚写正常，放置或 bake 后错 | Flash retention loss、charge leakage、oxide defect |
| P/E 次数越多越差 | endurance degradation、tunnel oxide 退化、trap 累积 |
| 读次数越多错误越多 | read disturb、阈值分布被扰动 |
| 冷热循环后失效率升高 | 封装热疲劳、焊点裂纹、delamination、CTE mismatch |
| 长时间高温高压后参数漂移 | BTI、HCI、EM、TDDB、模拟参考漂移 |

## 3. NOR Flash：围绕擦写、保持、扰动和接口

NOR Flash 主要用于代码存储和启动，典型风险是：数据长期是否稳定、擦写是否可靠、高速读取是否有 margin。

### 3.1 读失败

表现：

- 固定地址读错；
- 某些 bit 翻转；
- 低速读正常，高速 SPI / QSPI 读异常；
- 常温正常，高温读错；
- 上电初期正常，运行一段时间后异常。

检测方法：

- 全地址读校验；
- 不同 SPI / QSPI 频率读；
- 不同 dummy cycle 读；
- VCC shmoo；
- 温度 shmoo；
- read margin test；
- retention bake 后再读；
- 示波器观察 CLK / IO 眼图。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 高速读错，低速正常；增加 dummy cycle 后改善 | SPI / QSPI timing margin 不足、采样边沿或 dummy cycle 配置问题 |
| 高温读错，常温正常；bake 后错误增加 | retention margin 不足、cell 漏电、sense margin 变差 |
| 固定 sector / 固定地址读错；重写后仍在同一区域 | 局部阵列缺陷、wordline / bitline / decoder 缺陷 |
| 换板或缩短连线后改善 | 板级 SI、阻抗、反射、串扰问题 |

### 3.2 Program fail

表现：

- page program 后 verify fail；
- program time 变长；
- 某些 bit 难以从 1 写成 0；
- 写入后立即正常，放置后读错。

检测方法：

- page program + verify；
- program time 统计；
- 不同温度 / 电压 program；
- P/E cycling；
- status register 检查。

判别组合：

| 特征组合 | 指向 |
|---|---|
| verify fail + program time 变长 + 高温更明显 | charge injection 效率下降、tunnel oxide 退化、高压路径 margin 不足 |
| P/E cycling 后 program fail 上升 | endurance 到限、oxide trap 累积 |
| 局部 page / sector program fail | 局部 cell 或高压分配路径缺陷 |

### 3.3 Erase fail

表现：

- sector / block 擦不干净；
- 擦除后仍有 bit 保持 programmed 状态；
- erase time 变长；
- 某 sector 反复失败。

检测方法：

- sector erase + blank check；
- erase time 分布；
- erase retry；
- 高低温 erase；
- P/E cycling 后测试。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 擦除后仍有 bit 不是 1 | tunnel oxide 退化、trapped charge、erase path 异常 |
| erase time 越来越长 | endurance degradation、erase efficiency 下降 |
| 固定 sector 擦除失败 | 局部 block 老化或制程缺陷 |

### 3.4 Retention / disturb

表现：

- 刚写入正常，存放一段时间后错误；
- 高温 bake 后 bit error 增多；
- 老数据比新数据更容易错；
- 频繁读取某区域后相邻区域出错。

检测方法：

- 固定 pattern 写入；
- 85℃ / 125℃ bake；
- bake 后读出比较；
- 不同 P/E cycle 后 retention；
- repeated read stress；
- 相邻 wordline / bitline 错误分布分析。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 错误随 bake 时间增加 | charge leakage、retention loss |
| P/E 越高 retention 越差 | endurance-induced retention degradation |
| 频繁读 A 区后邻近区域错误增加 | read disturb、cell 间耦合、阈值分布过窄 |

---

## 4. NAND Flash：围绕 BER、ECC、坏块和扰动

NAND 不能只问“有没有错”，而要看 raw BER、ECC correction count、坏块增长、die / plane / block 分布。

### 4.1 Raw BER / ECC margin

表现：

- ECC 纠错数量逐渐升高；
- 高温保存后 bit error 增多；
- 读取次数多后错误增加；
- 老数据错误明显高于新数据。

检测方法：

- raw data 读取；
- ECC correction count 统计；
- BER histogram；
- page / block / die / plane 分布；
- read retry level 扫描。

判别组合：

| 特征组合 | 指向 |
|---|---|
| ECC correction count 随存放时间上升 | retention loss |
| ECC correction count 随读取次数上升 | read disturb |
| ECC correction count 随 P/E cycle 上升 | endurance wear |
| read retry 后恢复 | Vt shift、read reference voltage 不匹配、阈值分布漂移 |
| 错误集中在某 block / plane / die | 局部 block、plane 或 die 缺陷 |

### 4.2 Bad block 增长

表现：

- 初始坏块数量异常；
- grown bad block 增多；
- program / erase 某 block 经常失败；
- 某 die / plane 坏块集中。

检测方法：

- 初始坏块扫描；
- P/E cycling 后坏块统计；
- erase / program fail log；
- plane / die 分布统计。

判别组合：

| 特征组合 | 指向 |
|---|---|
| grown bad block 快速增加 | endurance 不足、局部工艺缺陷、controller 管理策略问题 |
| 坏块集中在某 die / plane | die 局部缺陷、plane decoder / pump 问题、封装内 die 连接异常 |
| erase fail 与 program fail 同时集中在某 block | block 局部高压路径或阵列缺陷 |

### 4.3 Program / read disturb

检测方法：

- repeated read stress；
- neighbor page program stress；
- stress 前后 BER 比较；
- 相邻 page / block 错误分布分析。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 高频读 A 后，B 的 BER 上升 | read disturb |
| 写相邻 page 后，原 page 出错 | program disturb、cell-to-cell coupling |
| 错误集中在相邻 wordline | wordline disturb、阈值分布干扰 |

---

## 5. DRAM：围绕 retention、refresh、timing 和 disturb

DRAM 对电荷保持、刷新策略、时序和噪声高度敏感。

### 5.1 Retention fail

表现：

- 高温下数据保持失败；
- 降低 refresh 频率后错误增多；
- 某些 bit 固定容易丢数据；
- 常温正常，高温失败。

检测方法：

- 写入 pattern；
- 暂停 refresh；
- 调整 refresh interval；
- 高温测试；
- retention time sweep。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 高温 + 延长 refresh interval 后固定 bit 翻转 | weak cell、电容漏电、access transistor 漏电 |
| 正常 refresh 通过，降低 refresh 失败 | retention margin 不足，但不是完全硬坏 |
| 固定 row / column retention fail | wordline / bitline / sense amp 局部缺陷 |

### 5.2 Timing margin fail

表现：

- 降频正常，升频失败；
- 放宽 timing 后恢复；
- 低压失败，高压正常；
- 某些温度点失败。

检测方法：

- tRCD / tRP / tRAS / tRC shmoo；
- 频率扫描；
- 电压扫描；
- 温度扫描；
- memory controller timing 放宽 / 收紧。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 放宽 timing 后恢复 | sense amp speed margin 不足、bitline develop time 不足、process slow corner |
| 降频恢复 | DRAM 或 controller 接口 timing margin、SI / PI 问题 |
| 低压 + 高频更容易失败 | 电源裕量和时序裕量共同不足 |

### 5.3 Row hammer / disturb

检测方法：

- hammer test pattern；
- 高频访问 aggressor row；
- 检查 victim row bit flip；
- 不同 refresh 策略对比。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 只在相邻 row 翻转 | row disturb / row hammer |
| 增加 refresh 后改善 | cell charge margin 不足，disturb 累积导致漏电 |
| 特定 pattern 更容易触发 | cell coupling、版图邻近效应 |

## 6. MCU：启动、Flash、SRAM、时钟、电源、IO 和软件耦合

MCU 失效最复杂，因为 CPU、Flash、SRAM、时钟、电源管理、ADC、通信接口、软件状态机耦合在一起。

### 6.1 不启动 / 偶发启动失败

表现：

- 上电无响应；
- 偶发卡死在 boot；
- 低温或高温启动失败；
- 复位后偶发跑飞；
- 下载器无法连接。

检测方法：

- 上电 ramp sweep；
- POR / BOR 阈值测试；
- reset pin 波形；
- VDD 电源波形；
- 晶振起振波形；
- PLL lock 状态；
- SWD / JTAG 连接测试；
- boot pin 状态检查；
- 上电电流 profile。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 慢上电失败，快上电正常 | POR margin、BOR 阈值、reset release 时序、电源 ramp 不符合规格 |
| 低温启动失败 | 晶振起振 margin、PLL lock、bandgap / LDO 启动慢 |
| 上电电流正常但 SWD 连不上 | boot 配置、debug pin 复用、option bytes、内部 Flash boot 异常 |
| 上电电流异常大 | latch-up、EOS、电源短路、IO 反灌 |

### 6.2 内部 Flash 异常

表现：

- 程序丢失；
- 固件 CRC 错；
- page 擦写失败；
- 在线升级后变砖；
- 某些 page 写不进去。

检测方法：

- 固件 CRC 校验；
- page erase / program 测试；
- 断电写入测试；
- 高温 retention bake；
- P/E cycling；
- 不同 VDD 下读写测试。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 写入后立即正常，放置后 CRC 错 | embedded Flash retention 不足、高温电荷泄漏、program margin 不足 |
| 在线升级后偶发变砖 | 写 Flash 时掉电、bootloader 无双区保护、option byte 被误写、流程未校验 |
| 低压写 Flash 失败 | charge pump margin 不足、VDD 低于 program spec、电源纹波过大 |

### 6.3 SRAM / 程序跑飞

表现：

- 随机 HardFault；
- 长时间运行后死机；
- 特定温度 / 电压下异常；
- 栈数据损坏；
- 变量偶发变值。

检测方法：

- March C / March SS；
- checkerboard pattern；
- walking 1 / 0；
- stack canary；
- HardFault log；
- PC / LR / SP dump；
- 电压 / 温度 shmoo；
- EMI stress。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 固定地址 SRAM 错 | SRAM cell、bitline / wordline、decoder 缺陷 |
| 低压下随机 bit 错 | SRAM cell stability、Vmin margin、电源噪声 |
| HardFault 随机且伴随 VDD dip | brownout、电源瞬态不足、外设大电流切换 |
| HardFault 总在同一函数附近 | 软件越界、栈溢出、空指针、中断竞态、Flash wait state 错误 |

### 6.4 IO / 外设异常

表现：

- 某 GPIO 永久高 / 低；
- UART / SPI / I2C 偶发通信失败；
- ADC 值漂移；
- PWM 输出异常；
- CAN / USB 枚举失败。

检测方法：

- IO curve trace；
- GPIO toggle test；
- UART / SPI / I2C loopback；
- 示波器看波形；
- 逻辑分析仪抓协议；
- pin leakage；
- ESD 后复测。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 某 IO 永久高 / 低 | pad driver 损坏、ESD clamp 短路、pin 焊接短路、pin mux 配置错误 |
| 高速 SPI 错，低速正常 | IO timing margin、走线反射、上拉不合适、采样边沿错误、drive strength 配置不当 |
| I2C 偶发挂死，SCL / SDA 被拉低 | 从设备状态机异常、总线毛刺、上拉不合适、热插拔、软件缺 bus recovery |

### 6.5 ADC / 模拟模块异常

检测方法：

- ADC INL / DNL；
- offset / gain error；
- noise histogram；
- reference voltage；
- 不同源阻抗输入测试；
- 温漂测试。

判别组合：

| 特征组合 | 指向 |
|---|---|
| ADC 所有通道一起偏移 | Vref 漂移、bandgap 异常、电源噪声、校准参数错误 |
| 单通道异常 | mux leakage、IO pad leakage、外部电路、焊接污染 |
| 采样值周期性波动 | 开关电源纹波、digital switching noise、采样时间太短、源阻抗过高 |

---

## 7. 指纹 / 触控传感器：环境和系统级因素很强

这类芯片经常不是纯芯片本体问题，而是芯片、模组、FPC、盖板、接地、电源、算法共同作用。

### 7.1 无响应 / 灵敏度下降

表现：

- 触摸无反应；
- 指纹无法采集；
- 模组不识别；
- 需要重按；
- 局部区域识别差。

检测方法：

- raw capacitance；
- baseline tracking；
- delta count；
- touch threshold sweep；
- 湿热测试；
- ESD stress；
- FPC 弯折 / 按压测试。

判别组合：

| 特征组合 | 指向 |
|---|---|
| raw baseline 正常，但 delta 很小 | 灵敏度不足、电极退化、盖板太厚、阈值过高 |
| baseline 大幅漂移 | 湿度、污染、接地差、charger noise、材料介电常数变化 |
| 按压 FPC 后恢复 | FPC 接触不良、焊点虚焊、连接器问题 |

### 7.2 误触 / 假触发

检测方法：

- 空触 baseline noise；
- charger 插拔测试；
- EMI 注入测试；
- 湿手测试；
- 接地阻抗测试。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 充电时误触明显增加 | charger common-mode noise、地参考不稳、电源滤波不足、算法抗噪不足 |
| 潮湿环境误触 | 水膜改变电容路径、表面污染、防水算法不足、guard ring 设计不足 |
| 固定区域异常敏感 | sensor array 局部一致性差、电极缺陷、装配应力 |

### 7.3 指纹图像异常

检测方法：

- raw image frame；
- SNR；
- dead pixel map；
- row / column noise；
- ADC offset / gain calibration；
- ESD 前后对比。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 固定行 / 列异常 | row / column readout、ADC channel、sensing array 局部缺陷 |
| 图像整体噪声大 | 电源噪声、地弹、AFE 增益不足、模组接地不好、外部 EMI |
| ESD 后 dead pixel 增加 | sensing electrode 或 AFE 被 ESD 损伤 |

---

## 8. 模拟 / 电源芯片：重点看参数漂移、启动和环路稳定

模拟 / 电源芯片不是简单的 pass / fail，很多问题表现为参数随温度、负载、输入电压、时间漂移。

### 8.1 输出电压异常

表现：

- 输出偏高 / 偏低；
- load transient 后恢复慢；
- 某温度下输出漂移；
- 上电 overshoot。

检测方法：

- line regulation；
- load regulation；
- temperature sweep；
- reference voltage；
- dropout voltage；
- 输出纹波测试。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 所有负载下输出都偏高 / 偏低 | bandgap reference 偏移、feedback ratio 偏差、trim 错误、封装应力 |
| 只有重载偏低 | pass device Rds_on 偏大、current limit 提前触发、热阻太大、输入电源能力不足 |
| 高温下输出漂移明显 | reference 温漂、bias 漂移、封装应力、漏电增加 |

### 8.2 启动失败 / 反复打嗝

检测方法：

- startup waveform；
- soft-start 波形；
- input / output current；
- power good 信号；
- 不同负载启动；
- 不同输入 ramp。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 轻载能启动，重载不能启动 | soft-start 不足、current limit 太低、启动浪涌过大、输出电容过大 |
| 某输入 ramp 下失败 | UVLO 阈值、bias 启动窗口窄、power sequencing 问题 |
| 启动后立即保护 | 过流误触发、负载短路、补偿不稳定、热保护异常 |

### 8.3 环路不稳定

检测方法：

- load transient；
- Bode plot；
- 输出纹波频谱；
- step load response；
- 不同输出电容 ESR 测试。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 负载跳变后振铃严重 | phase margin 不足、compensation 不匹配、输出电容 ESR 不合适 |
| 某种电容下振荡，换电容恢复 | 环路稳定性与外部器件匹配问题 |
| 高频纹波异常 | layout 寄生、电感饱和、开关节点噪声耦合 |

---

## 9. 封装、板级、ESD / EOS：最容易被误判成芯片本体问题

### 9.1 封装 / 焊接问题

检测方法：

- X-ray；
- SAM 超声扫描；
- cross-section；
- dye & pry；
- thermal cycling；
- board bending test；
- 按压复现；
- 四线电阻测试。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 按压芯片或 PCB 后现象变化 | BGA 焊点裂纹、QFN 虚焊、bond wire 接触不良、PCB 微裂纹 |
| 冷热循环后失效变多 | CTE mismatch、焊点疲劳、delamination、die attach 问题 |
| SAM 看到 delamination | 潮气侵入、reflow profile 不当、popcorn crack、封装材料问题 |

### 9.2 ESD / EOS 损伤

检测方法：

- curve trace；
- pin-to-pin resistance；
- thermal emission；
- EMMI；
- OBIRCH；
- decap + optical inspection；
- SEM / FIB cross-section。

判别组合：

| 特征组合 | 指向 |
|---|---|
| 某 pin I-V 曲线异常 + 漏电大 | ESD pad 损伤、EOS、latch-up 通道损伤 |
| 电源脚对地低阻 + 热点明显 | 内部短路、power clamp 击穿、金属熔融、latch-up 烧毁 |
| decap 后看到金属烧蚀 | EOS、过压 / 过流、电源反接、热插拔浪涌 |
| 突然死亡且无时间退化过程 | 更偏 ESD / EOS，而不是可靠性老化 |

---

## 10. 典型“特征组合 → 失效判断”速查

### 10.1 Flash retention 失效

特征组合：

- 写入后立即读正常；
- 高温 bake 后错误增加；
- P/E 次数越高越严重；
- 错误 bit 随时间增加；
- 高温比常温明显。

判断方向：

- 电荷泄漏；
- tunnel oxide 退化；
- trap-assisted leakage；
- endurance-induced retention loss。

### 10.2 接口时序 / 信号完整性问题

特征组合：

- 低速正常，高速失败；
- 换短线或换板后改善；
- 降低 SPI / QSPI / DRAM 频率恢复；
- 示波器看到过冲、振铃、眼图闭合；
- 温度影响不一定明显。

判断方向：

- timing margin 不足；
- PCB SI 问题；
- drive strength 不匹配；
- 采样边沿错误；
- dummy cycle 配置不足。

### 10.3 制程局部缺陷

特征组合：

- 固定地址 / 固定 bit / 固定 row 失败；
- 与温度、电压关系不强；
- 擦写重试也在同一区域失败；
- fail bitmap 有空间规律。

判断方向：

- particle defect；
- metal open / short；
- via defect；
- wordline / bitline defect；
- decoder 局部缺陷。

### 10.4 漏电 / 弱单元

特征组合：

- 高温失败明显；
- 低压失败明显；
- 常温标压可能通过；
- retention margin 差；
- standby current 偏高。

判断方向：

- weak cell；
- junction leakage；
- oxide defect；
- SRAM / DRAM stability margin 不足；
- Flash charge leakage。

### 10.5 EOS / ESD 损伤

特征组合：

- 突然死亡；
- 某 IO 漏电大；
- 电源电流异常；
- pin I-V 曲线异常；
- 热点集中；
- 物理分析有烧蚀或击穿。

判断方向：

- ESD damage；
- EOS overstress；
- latch-up；
- IO 过压；
- 电源反接；
- 热插拔浪涌。

### 10.6 封装 / 焊接问题

特征组合：

- 按压或弯板后状态变化；
- 冷热循环后失效复现；
- X-ray / SAM 异常；
- 同一芯片换板后现象变化；
- 失效偶发且位置相关。

判断方向：

- 焊点裂纹；
- bond wire 接触不良；
- package delamination；
- die attach 问题；
- PCB 微裂纹。

## 11. 实际工程分析顺序

### 第一步：复现和分类

先确认：

- 必现还是偶发；
- 单颗还是批量；
- 板级还是芯片级；
- 上电失败、读写失败、通信失败、参数漂移还是功耗异常；
- 是否与软件版本、板卡版本、批次、供应商、温度、电源相关。

### 第二步：做 V / T / F Shmoo

看失败边界：

- 低压边界；
- 高温边界；
- 高频边界；
- 上电 ramp 边界。

这一步能快速判断问题更偏：

- 设计 margin；
- 制程弱点；
- 应用超规格；
- 老化退化；
- 接口问题。

### 第三步：看空间分布

对存储类尤其重要：

- 固定 bit；
- 固定 row；
- 固定 block；
- 某 die / plane；
- 某 wafer 区域；
- 某 lot。

这一步用来区分：

- 随机软错误；
- 局部硬缺陷；
- 系统性工艺问题。

### 第四步：看时间演化

做：

- 高温 bake；
- P/E cycling；
- HTOL；
- read disturb；
- power cycling；
- thermal cycling。

如果错误随时间或应力累积，优先考虑可靠性退化。

### 第五步：看电流和波形

测：

- standby current；
- active current；
- IO leakage；
- power rail ripple；
- reset waveform；
- clock waveform；
- communication waveform。

这一步经常能把问题从“芯片坏”修正为“板级、电源、接口或软件问题”。

### 第六步：物理失效分析

在电性定位收敛后再做：

- X-ray；
- SAM；
- EMMI；
- OBIRCH；
- decap；
- SEM / FIB；
- cross-section。

不要一开始盲目开盖。物理分析成本高，如果前面的电性证据链不清楚，开盖后也可能只有现象，没有根因。

---

## 12. 质量工程师的核心能力

真正有价值的质量判断，不是背失效机理名词，而是能把客户现场现象翻译成可测量特征。

典型能力包括：

1. 把“偶发死机”拆成电源、时钟、复位、SRAM、Flash、软件和 EMI 假设；
2. 把“读数据错”拆成 retention、read disturb、接口 timing、板级 SI 和 controller 配置；
3. 把“芯片坏了”拆成芯片本体、封装、焊接、板级、电源和使用条件；
4. 用 V / T / F shmoo 找边界，而不是只在常温标压下重复测试；
5. 用 fail bitmap 和 wafer map 看空间规律；
6. 用电流、波形和物理分析补足证据链；
7. 最后形成可执行闭环：筛选条件、制程反馈、设计改进、应用建议、客户复现方法。

最终判断句式应该是：

> 在某电压 / 温度 / 频率 / 时间 / 应力条件下，失效呈现某种空间分布和电流波形特征，因此优先指向某类失效机理；下一步用某检测方法验证或排除。

---

## 13. 一句话收束

对兆易创新这类存储 + MCU + 传感器 + 模拟产品组合来说：

- Flash 类芯片：重点看擦写、保持、扰动、阈值漂移；
- DRAM 类芯片：重点看漏电、刷新、弱单元、时序；
- MCU 类芯片：重点看启动、嵌入式 Flash、SRAM、时钟、电源、IO 和软件耦合；
- 传感器类芯片：重点看 ESD、湿度、噪声、灵敏度漂移和模组装配；
- 模拟 / 电源芯片：重点看参数漂移、环路稳定、保护失效和过应力。

而识别失效的关键不是“一个现象对应一个原因”，而是：

> **复现性 + V/T/F 边界 + 空间分布 + 时间演化 + 电流波形 + 物理证据** 的组合判断。
