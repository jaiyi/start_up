# 12 · 芯片制程质量异常识别框架

> 讨论稿 / 会更新 · 最近更新 2026-09-30
>
> **一句话结论**：上一篇更偏“失效后验证假设”，这一篇前移到制程和量产质量控制：通过 Inline、PCM/WAT、CP、FT、可靠性筛选和客诉闭环识别 **spec 内异常**，在 NOR Flash、NAND Flash、DRAM、MCU、传感器和模拟电源芯片流到客户现场前，把潜在失效种子拦住。

---

## 0. 这篇和上一篇的关系

`11-芯片失效类型与检测判别框架.md` 主要回答：

> 客户现场或实验室已经出现失效后，如何根据异常表现提出失效假设，并用测试和物理分析验证。

这一篇回答另一个更前置的问题：

> 在晶圆制造、晶圆测试、封装测试和可靠性筛选过程中，如何从检测数据里提前识别异常，判断哪些产品虽然还没有 fail，但已经偏离正常族群，未来可能在客户侧失效。

两者区别：

| 维度 | 失效后分析 | 制程中预警 |
|---|---|---|
| 问题对象 | 已经坏的样品 | 尚未明显失效的 lot / wafer / die |
| 核心问题 | 为什么坏 | 哪些产品可能以后坏 |
| 主要证据 | 客户现象、电性复现、FA 物理证据 | Inline、WAT、CP、FT、可靠性和统计分布 |
| 判断重点 | 机理验证 | 异常分布、边缘品、maverick 识别 |
| 工程动作 | 失效定位、8D、客户处置 | hold lot、加严 guardband、追加筛选、反馈制程 / 设计 |

这对兆易创新这类 Fabless 芯片公司尤其重要。Fabless 不直接拥有晶圆厂，但必须有能力读懂晶圆厂、封测厂和客户现场返回的数据，把它们串成质量闭环。

## 1. Fabless 视角下的质量数据链

以存储 + MCU + 传感器 + 模拟电源产品组合为例，一颗芯片从制程到客户现场大致有 6 层质量数据。

```text
晶圆制造过程
  ↓
Inline Metrology / Defect Inspection
  ↓
PCM / WAT 工艺监控结构
  ↓
CP 晶圆级测试
  ↓
封装过程检测
  ↓
FT 成品测试 + Reliability Screening
  ↓
客户现场 / RMA / 客诉闭环
```

每一层看的不是同一个东西：

| 层级 | 主要数据 | 能提前识别什么 |
|---|---|---|
| Inline | CD、Overlay、膜厚、刻蚀、颗粒、CMP | 光刻、薄膜、刻蚀、污染、均匀性异常 |
| PCM / WAT | Vt、Idsat、Ioff、leakage、contact / via R、RO | 工艺角漂移、漏电、互连、氧化层、速度风险 |
| CP | die 功能、memory BIST、Vmin、Fmax、IO leakage、wafer map | die 级弱点、空间异常、marginal die |
| 封装过程 | wire bond、die attach、X-ray、SAM、warpage | 焊接、封装分层、空洞、应力风险 |
| FT | 成品功能、DC/AC、高低温、接口、功耗、模拟参数 | 封装引入问题、系统级边界弱品 |
| Reliability | HTOL、HAST、TC、ESD、P/E、retention、disturb | 长期可靠性、湿热、老化、耐久和抗扰动风险 |

Fabless 质量工程的核心，不只是看代工厂给的 pass / fail，而是看：

> 当前 lot / wafer / die 是否 still in spec but out of family。

也就是：还没有超规格，但已经不像正常产品族群。

## 2. 制程异常识别的核心：不是超规格，而是分布异常

### 2.1 均值偏移

例子：

- Vt 整体偏高；
- Idsat 整体偏低；
- contact resistance 整体升高；
- Flash erase time 整体变长；
- standby current 整体偏高；
- bandgap 输出整体偏移。

含义：

> 工艺中心点发生漂移，虽然可能仍在 spec 内，但设计和应用 margin 已经变小。

可能后果：

- MCU 低压启动失败；
- SRAM Vmin 变差；
- 高频 Fmax 降低；
- Flash 擦写变慢；
- 高温漏电增加；
- 模拟输出温漂变大。

### 2.2 分布变宽

例子：

- 同 lot Vt sigma 变大；
- Flash program / erase time 分布变宽；
- SRAM Vmin 分布变宽；
- IO leakage tail 变厚；
- ADC offset / gain 分布变宽；
- sensor baseline 分布变宽。

含义：

> 工艺均匀性变差，平均值可能正常，但尾部 die 更容易成为未来失效种子。

质量工程上重点看：

- sigma；
- P95 / P99 / P99.9；
- tail count；
- Cpk / Ppk；
- marginal bin；
- retest pass unit。

### 2.3 尾部异常

例子：

- 平均 leakage 正常，但 top 0.1% 偏高；
- 少量 die program time 很长；
- 少量 block ECC correction count 很高；
- 少量 MCU sleep current 偏大；
- 少量 analog trim code 靠近边界。

含义：

> 单项都 pass，但尾部产品在高温、低压、高频、长期使用或客户复杂场景下更容易 fail。

这是最容易被传统测试遗漏的风险。

### 2.4 空间图形异常

常见 wafer map pattern：

- edge ring；
- center-to-edge gradient；
- radial pattern；
- reticle repeating pattern；
- scratch line；
- local cluster；
- half-wafer abnormal；
- checkerboard pattern；
- chamber fingerprint。

这些空间 pattern 往往比单个 fail 更有诊断价值：

| 空间图形 | 常见指向 |
|---|---|
| edge ring | 边缘膜厚、刻蚀、CMP、温度均匀性 |
| radial pattern | 旋涂、刻蚀、退火、CMP 均匀性 |
| reticle repeat | 光刻、mask、stepper、reticle defect |
| scratch line | 搬运、机械刮伤、颗粒拖拽 |
| local cluster | 局部污染、particle、chuck 接触异常 |
| half-wafer | chamber、气流、温控、夹具、设备状态 |

### 2.5 跨阶段相关性异常

最有价值的判断通常来自跨阶段关联：

```text
Inline / WAT 异常
  → CP 边界变差
  → FT / reliability fail 上升
  → 客户现场某类问题增加
```

例子：

| 上游异常 | 下游表现 | 产品风险 |
|---|---|---|
| tunnel oxide leakage tail 增大 | CP retention bake fail 上升 | NOR / eFlash 数据保持风险 |
| capacitor leakage 上升 | DRAM retention time 左移 | 高温 refresh fail |
| ring oscillator 变慢 | MCU Fmax / Vmin fail 增加 | 高频 / 低压运行风险 |
| contact R tail 变厚 | 固定 row / column fail 增加 | 互连高阻 / open 风险 |
| bandgap trim code 靠边 | 高低温输出漂移变大 | 模拟参考 / 电源输出风险 |
| sensor baseline noise 上升 | 湿热 / 充电误触增加 | 触控 / 指纹体验风险 |

## 3. Inline：晶圆制造过程检测

Inline 是在晶圆制造过程中还没有形成最终芯片前做的过程检测。

### 3.1 光刻 CD / Overlay

检测方法：

- CD-SEM；
- overlay measurement；
- reticle-level map；
- wafer-level CD uniformity；
- critical layer trend。

异常特征：

- CD 均值偏移；
- CD sigma 变大；
- overlay 偏移；
- reticle repeating pattern；
- wafer 边缘 CD 异常。

可能后果：

- 晶体管 Vt / Idsat 偏移；
- SRAM cell margin 下降；
- decoder timing 异常；
- metal short / open；
- Flash wordline / bitline coupling 异常；
- MCU 高频或低压失效。

典型判别组合：

| 测量特征组合 | 预警方向 |
|---|---|
| CD 偏窄 + leakage tail 增加 + standby current 偏高 | 短沟道效应 / 漏电风险 |
| Vt 偏移 + ring oscillator 速度偏移 + Fmax 边界变差 | 逻辑工艺角漂移 |
| Overlay 偏移 + 固定 row / column fail 增加 | 接触孔或互连对准问题 |
| reticle repeat + 同位置 CP fail | 光刻 / mask / stepper 相关问题 |

### 3.2 薄膜 / 氧化层

检测方法：

- ellipsometry；
- oxide thickness monitor；
- gate leakage；
- TDDB monitor；
- breakdown voltage；
- Flash tunnel oxide monitor。

异常特征：

- oxide thickness 均值偏薄；
- gate leakage tail 增大；
- breakdown voltage 下降；
- TDDB lifetime 变短；
- Flash retention monitor 变差。

可能后果：

- Flash retention fail；
- Flash endurance fail；
- MCU embedded Flash 数据丢失；
- 高温漏电；
- 栅氧击穿；
- 长期可靠性下降。

典型判别组合：

| 测量特征组合 | 预警方向 |
|---|---|
| gate leakage 上升 + TDDB 分布左移 + 高温 bake 后 bit error 增加 | 氧化层质量异常 |
| tunnel oxide monitor 异常 + erase / program time 分布变宽 | Flash P/E 和 retention 风险 |
| breakdown voltage tail 下降 + HTOL 后 leakage 增量变大 | 长期栅氧可靠性风险 |

### 3.3 离子注入 / 阈值电压

检测方法：

- Vt monitor；
- Idsat；
- Ioff；
- subthreshold slope；
- sheet resistance；
- ring oscillator。

异常特征：

- NMOS / PMOS Vt 偏移；
- Idsat 下降；
- Ioff 上升；
- ring oscillator 速度偏快或偏慢；
- wafer 内 radial drift。

可能后果：

- MCU 低压启动失败；
- SRAM Vmin 变差；
- DRAM access transistor leakage；
- 模拟 reference 偏移；
- timing margin 不足；
- 待机电流偏高。

典型判别组合：

| 测量特征组合 | 预警方向 |
|---|---|
| Vt 偏高 + Idsat 偏低 + ring oscillator 变慢 + Fmax fail 增加 | slow corner，高频 / 低压失效风险 |
| Vt 偏低 + Ioff 上升 + standby current tail 变厚 | 漏电风险，高温 fail 和低功耗异常 |
| sheet resistance 漂移 + RO 空间 gradient | implant / anneal / silicide 均匀性问题 |

### 3.4 Contact / Via / Metal

检测方法：

- contact resistance；
- via chain resistance；
- metal line resistance；
- Kelvin structure；
- continuity test；
- EM monitor；
- wafer map。

异常特征：

- contact resistance 均值升高；
- via chain tail 变厚；
- metal resistance 变大；
- open fail 增加；
- 某 metal layer 异常集中；
- reticle 或区域性 pattern。

可能后果：

- 固定地址 / row / column fail；
- MCU 某外设不稳定；
- 高频 timing fail；
- IR drop 增大；
- 电迁移寿命变短；
- 封测后 open / intermittent fail。

典型判别组合：

| 测量特征组合 | 预警方向 |
|---|---|
| via resistance tail 增大 + 高频 fail 增加 + 温度相关性弱 | 互连高阻 / 接触问题 |
| metal resistance 偏高 + 大电流路径温升 + HTOL 后 fail 增加 | EM 风险 |
| contact R cluster + CP fail cluster 重叠 | 局部 contact / via 工艺异常 |

### 3.5 颗粒 / 污染

检测方法：

- inline defect inspection；
- particle count；
- wafer map cluster；
- fail bit map；
- SEM review；
- defect classification。

异常特征：

- 随机散点 fail；
- 局部 cluster；
- scratch-like pattern；
- 同设备 / 同 chamber wafer 异常；
- memory bitmap 局部集中错误。

可能后果：

- metal short / open；
- bitline / wordline short；
- leakage path；
- 固定 bit / 固定 block fail；
- 低良率；
- 早期寿命失效。

典型判别组合：

| 测量特征组合 | 预警方向 |
|---|---|
| defect map cluster + CP fail map cluster 重叠 | 颗粒或局部污染导致的功能失效 |
| defect density 升高 + random single bit fail 增加 | 阵列良率风险 |
| scratch pattern + line-shaped fail map | 搬运 / 机械刮伤 / 颗粒拖拽 |

### 3.6 CMP / 平坦化

检测方法：

- post-CMP thickness；
- dishing / erosion measurement；
- resistance monitor；
- wafer uniformity map；
- cross-section sample。

异常特征：

- wafer edge thickness 异常；
- metal resistance 区域性偏高；
- via resistance 变差；
- pattern-density 相关失效；
- edge die fail 增加。

可能后果：

- metal open / thinning；
- via contact 不良；
- RC delay 增大；
- EM lifetime 下降；
- 高速接口 margin 变差。

典型判别组合：

| 测量特征组合 | 预警方向 |
|---|---|
| edge die fail 增加 + metal resistance 边缘偏高 + via chain tail 变厚 | CMP / 金属厚度均匀性问题 |
| pattern-density 区域 fail + dishing / erosion 异常 | 局部金属厚度和互连可靠性风险 |

## 4. 图像数据：制程质量预警中的高价值信号

芯片制造过程不仅涉及图像，而且图像是核心质量数据。光刻图形、缺陷图、CD-SEM、overlay 图、wafer map、X-ray、SAM 和传感器 raw image，都可以揭示数值测试不容易发现的空间异常、形貌异常和过程漂移。

对制程质量预警来说，图像的价值不止是“把缺陷图片分类”，而是和 WAT、CP、FT、reliability、tool / chamber genealogy 联合判断：某个 lot / wafer / die 是否虽然 pass，但已经 out of family。

### 4.1 图像不是辅助材料，而是过程质量数据

芯片质量里的图像大致分两类：

1. **真实物理图像**：光学显微、CD-SEM、SEM review、X-ray、SAM、FIB / SEM、EMMI / OBIRCH 等；
2. **测试数据图像化**：wafer map、bin map、parameter map、fail bit map、retention fail map、dead pixel map、baseline map 等。

第一类直接看形貌和缺陷；第二类看空间分布和统计 pattern。两者都可以作为质量预警信号。

关键不是“有没有一张图”，而是图像能否回答：

- 异常是随机散点，还是有空间聚集；
- 是边缘、径向、半片、局部 cluster，还是 reticle repeat；
- 图形形貌是否偏离设计目标；
- 图像异常是否和 WAT / CP / FT / reliability 数据同向；
- 图像异常是否对应具体 tool、chamber、recipe、mask 或封装批次。

### 4.2 五类关键图像

| 图像类型 | 典型来源 | 质量价值 |
|---|---|---|
| 光刻 / CD-SEM / Overlay 图像 | Litho、CD-SEM、overlay metrology | 看线宽、套刻、形貌、边缘粗糙、塌胶、桥连、断线 |
| Defect inspection / SEM review 图像 | 明场 / 暗场检测、e-beam、SEM review | 看 particle、scratch、residue、stain、void、open / short |
| Wafer map / bin map / parameter map | CP、WAT、inline、FT 数据可视化 | 看 edge ring、cluster、radial、reticle repeat、scratch、hot zone |
| 封装 X-ray / SAM / AOI 图像 | OSAT 封装检测、板级检测 | 看 die attach void、bond wire、delamination、warpage、焊点异常 |
| FA 图像 / EMMI / OBIRCH / FIB / SEM | 客诉或可靠性失效后的 FA | 反向校准上游 inline / WAT / CP / FT 预警规则 |

其中前四类更偏制程和出货前预警；第五类更偏失效后分析，但它能反向训练质量规则：哪些上游 spec 内异常最终真的变成客户失效。

### 4.3 图像 pattern 与制程异常的映射

| 图像 / Map pattern | 典型指向 | 后续验证 |
|---|---|---|
| edge ring | 边缘膜厚、刻蚀、CMP、温控异常 | edge-center 参数对比、tool/chamber split、边缘 die CP fail |
| radial pattern | 旋涂、刻蚀、退火、CMP 均匀性 | radial 参数拟合、膜厚 / sheet R map、WAT gradient |
| reticle repeat | 光刻、mask、stepper、reticle defect | reticle 坐标重叠、CD / overlay 图像复查 |
| scratch line | 搬运、机械刮伤、颗粒拖拽 | defect review、路径追溯、设备搬运记录 |
| local cluster | 局部污染、particle、chuck 接触异常 | SEM review、defect map 与 CP fail map 叠图 |
| half-wafer | chamber、气流、温控、夹具、设备状态 | tool history、chamber split、同设备 wafer 对比 |
| fixed row / column | decoder、wordline、bitline、readout circuit | fail bitmap、版图位置映射、SEM / FA 抽样 |
| dead pixel cluster | sensor array、ADC channel、局部电极缺陷 | raw image、noise map、ESD / 湿热前后对比 |

工程上最有价值的是叠图：

```text
defect image / CD-SEM / wafer map
  + WAT 参数分布
  + CP / FT fail bin
  + reliability delta
  + tool / chamber genealogy
  → 判断是否需要 hold、screen、降级或反馈制程
```

### 4.4 按产品线看图像数据价值

| 产品线 | 高价值图像 / Map | 可识别风险 |
|---|---|---|
| NOR Flash | 存储阵列缺陷图、wordline / bitline 形貌、contact / via 缺陷、fail bit map、sector map、wafer map | 阵列周期性缺陷、固定 sector fail、retention 弱区、erase / program 空间异常 |
| NAND Flash | block / plane / die map、raw BER map、ECC count map、SEM review、defect map | bad block 异常增长、plane 局部风险、read disturb / program disturb 空间模式 |
| DRAM | capacitor / cell array 图像、retention fail map、row / column fail map、wafer map | weak cell、refresh 风险、row hammer 敏感区域、sense amp / decoder 局部问题 |
| GD32 MCU | eFlash / SRAM fail bitmap、logic defect inspection、wafer map、package X-ray / SAM | eFlash retention、SRAM Vmin、固定 row / column fail、封装热阻 / 应力问题 |
| 指纹 / 触控 | raw fingerprint image、dead pixel map、row / column noise map、raw capacitance map、baseline map、模组 AOI | dead pixel、行列噪声、灵敏度下降、湿热漂移、表面污染、FPC / 模组异常 |
| 模拟 / 电源 | die attach void X-ray、SAM delamination、metal / via defect image、EMMI / OBIRCH hotspot | 热阻异常、局部过热、EM 风险、leakage path、EOS / 局部短路 |

典型判断例子：

```text
阵列周期性缺陷图像
+ fail bit map 同周期异常
→ 可能是 wordline / bitline / litho pattern 问题
```

```text
defect cluster
+ 固定 block erase fail
→ 局部污染或阵列缺陷风险
```

```text
retention weak bit map
+ 高温 refresh fail
+ wafer radial pattern
→ capacitor leakage 或工艺均匀性风险
```

```text
SAM delamination
+ 高温 FT fail
→ 封装热阻或封装应力风险
```

```text
baseline map 局部漂移
+ 湿热后 drift 增大
→ 封装湿气 / 表面污染 / 材料介电变化风险
```

```text
OBIRCH hotspot
+ Iq tail 变厚
→ leakage path / 局部短路风险
```

### 4.5 AI 质量预警：从缺陷分类到多模态风险判断

芯片制造里的 AI 应用可以分两层。

第一层是图像分类：

- particle；
- scratch；
- bridge；
- open；
- residue；
- pattern collapse；
- stain；
- void；
- delamination；
- dead pixel。

这能替代部分人工复判，提高分类一致性和 review 效率，但价值上限有限。

更高价值的是多模态质量预警：

> 把 defect image、SEM review、CD / overlay 图像、wafer map、WAT 参数、CP / FT bin、reliability 结果、tool / chamber genealogy 串起来，判断某个 lot / wafer / die 是否 out of family，以及是否存在出货风险。

典型多模态链路：

```text
CD-SEM 图形边缘粗糙
+ WAT Vt sigma 变大
+ SRAM Vmin tail 变厚
→ 工艺均匀性导致 SRAM margin 风险
```

```text
defect cluster image
+ wafer map cluster
+ CP fail cluster
→ 局部污染或设备异常风险
```

```text
X-ray die attach void 偏高
+ 高温 load test fail
+ thermal shutdown 提前触发
→ 封装散热和功率可靠性风险
```

这类系统的核心不是训练一个“看图模型”，而是建立质量数据 harness：

- 图像归档；
- 缺陷类别标准化；
- wafer / die 坐标对齐；
- WAT / CP / FT / reliability 数据打通；
- tool / chamber / recipe genealogy 追踪；
- 客诉和 RMA 反向标注；
- 自动生成 lot hold / screen / fab feedback 建议。

## 5. PCM / WAT：工艺结构的早期预警

PCM / WAT 是 Fabless 质量团队看工艺健康度的关键入口。

### 4.1 关键测项

| 测项 | 主要意义 | 对应风险 |
|---|---|---|
| NMOS / PMOS Vt | 工艺角、阈值稳定性 | 速度、功耗、SRAM Vmin、模拟偏移 |
| Idsat | 驱动能力 | Fmax、启动、接口速度 |
| Ioff | 漏电 | standby current、高温 fail、低功耗异常 |
| Gate leakage | 栅氧质量 | TDDB、长期可靠性、Flash retention |
| Junction leakage | PN 结质量 | 高温漏电、DRAM retention、传感器噪声 |
| Contact / via R | 互连接触 | open、高阻、timing、EM |
| Metal R | 金属厚度 / 线宽 | IR drop、RC delay、EM |
| Ring oscillator | 综合速度指标 | MCU Fmax、时钟 margin、低压运行 |
| Capacitor leakage | 电容质量 | DRAM retention、模拟滤波、传感器 baseline |
| ESD / latch-up monitor | 防护能力 | 客户现场 IO 损伤风险 |

### 4.2 WAT 异常识别方式

不只看单项 spec，而要看：

- lot-to-lot trend；
- wafer-to-wafer variation；
- within-wafer uniformity；
- tool / chamber split；
- multi-parameter correlation；
- out-of-family score。

典型判别组合：

| WAT 特征组合 | 预警方向 |
|---|---|
| Vt 偏高 + Idsat 偏低 + RO 慢 | slow corner，低压 / 高频风险 |
| Vt 偏低 + Ioff 高 + standby current 高 | leakage 风险，低功耗和高温风险 |
| contact R tail 厚 + via chain fail 增加 | 互连高阻 / open 风险 |
| gate leakage 高 + TDDB 弱 | 氧化层可靠性风险 |
| capacitor leakage 高 + retention monitor 弱 | DRAM / 传感 / 模拟保持风险 |

---

## 6. CP：晶圆级测试中的异常识别

CP 是把过程异常映射到具体 die 的关键阶段。

### 6.1 CP 不应只做 pass / fail

CP 数据至少应保留：

- bin code；
- 测试项原始值；
- fail address / fail bit；
- wafer x/y 坐标；
- wafer id / lot id；
- retest 信息；
- test temperature / voltage；
- tester / probe card 信息。

质量工程关注：

> 哪些 die 虽然 pass，但参数已经接近边界，且与空间位置或上游 WAT 异常相关。

### 6.2 CP 常见异常模式

| CP 异常 | 可能含义 |
|---|---|
| edge die fail 增加 | 工艺均匀性、CMP、刻蚀、膜厚边缘问题 |
| reticle repeat fail | 光刻 / mask / stepper 问题 |
| local cluster fail | 颗粒 / 污染 / chuck / 局部制程异常 |
| Vmin 分布右移 | SRAM / logic margin 变差 |
| Fmax 分布左移 | slow corner、互连 RC、时钟路径风险 |
| leakage tail 变厚 | 漏电、ESD clamp、氧化层、污染 |
| retest pass 比例升高 | 边缘品、测试接触、温度、电源或时序 margin 问题 |

### 6.3 CP 里的 maverick die

maverick die 指：

> 单项测试都 pass，但多个参数组合起来明显偏离同 wafer / 同 lot 的正常族群。

识别方法：

- robust z-score；
- Mahalanobis distance；
- PCA；
- clustering；
- nearest-neighbor outlier；
- multi-parameter guardband。

典型组合：

| 多参数组合 | 风险 |
|---|---|
| Vmin 偏高 + Fmax 偏低 + RO 慢 | 低压 / 高频运行风险 |
| sleep current 偏高 + IO leakage 偏高 | 低功耗异常 / pad leakage 风险 |
| Flash erase time 偏长 + retention margin 边缘 | Flash 长期可靠性风险 |
| ADC offset 偏大 + trim code 靠边 | 模拟参数漂移风险 |

---

## 7. 封装过程与 FT：防止封装引入的边缘失效

### 7.1 封装过程检测

检测方法：

- wire bond pull / shear；
- die attach void；
- molding inspection；
- X-ray；
- SAM；
- MSL；
- reflow simulation；
- package warpage；
- electrical continuity；
- open / short。

异常特征组合：

| 特征组合 | 预警方向 |
|---|---|
| die attach void 偏高 + 高温 FT fail 增加 | 热阻上升、局部过热、功率器件风险 |
| SAM delamination + TC 后 fail 增加 | 封装分层、热疲劳、潮湿敏感风险 |
| wire pull 边缘 + intermittent open | bond wire 接触可靠性风险 |
| package warpage 大 + board-level fail | 焊接可靠性 / 应力风险 |

### 7.2 FT 成品测试

FT 重点不是重复 CP，而是补足封装后和应用边界：

- 高低温功能；
- DC / AC 参数；
- IO leakage；
- standby / sleep current；
- high speed interface；
- analog trim verification；
- memory read / write；
- low voltage / high frequency guardband。

FT 异常组合：

| 特征组合 | 预警方向 |
|---|---|
| CP pass，FT open / short 增加 | 封装 / bonding / solder 相关问题 |
| 高温 FT fail，但常温 pass | leakage、retention、模拟温漂、封装热阻 |
| 低压 FT fail 增加 | Vmin、POR/BOR、SRAM、logic speed margin |
| 高频接口 FT fail | IO timing、封装寄生、测试板 SI、die speed |

---

## 8. 可靠性筛选：识别未来会坏的产品

可靠性测试的价值在于让潜在失效提前暴露。

### 8.1 常见项目

| 项目 | 主要识别 |
|---|---|
| HTOL | 高温长期工作老化、BTI、HCI、EM、oxide degradation |
| HAST / uHAST | 湿热、封装、离子污染、腐蚀 |
| TC | 热循环、焊点、封装分层、CTE mismatch |
| THB | 湿热偏压、漏电、腐蚀 |
| ESD HBM / CDM | 静电防护能力 |
| Latch-up | 闩锁风险 |
| P/E cycling | Flash endurance |
| Retention bake | Flash / eFlash 数据保持 |
| Read / program disturb | Flash / NAND 干扰风险 |
| MSL / reflow | 潮湿敏感、爆米花、封装应力 |

### 8.2 关注 delta 而不是只看最终 pass / fail

应力前后 delta 经常比绝对值更敏感：

| Delta 特征 | 预警方向 |
|---|---|
| bake 前后 bit error 增量 | retention / charge leakage 风险 |
| P/E 前后 erase time 增量 | Flash endurance / oxide trap 风险 |
| HTOL 前后 leakage 增量 | oxide、junction、BTI、HCI 风险 |
| TC 前后接触电阻增量 | 焊点、bond wire、封装热疲劳 |
| ESD 前后 IO leakage 增量 | IO 保护结构弱点 |
| 湿热前后 sensor baseline drift | 传感器封装 / 表面材料 / 水汽风险 |

## 9. 按兆易创新主要产品线看过程监控重点

以下是针对“存储 + MCU + 传感器 + 模拟电源”产品组合的过程质量监控框架。这里讨论的是产品类型的一般质量工程逻辑，不代表任何具体批次或公司内部数据。

---

## 9.1 NOR Flash

NOR Flash 的质量核心：

> cell Vt 分布、tunnel oxide、P/E 分布、read margin、retention、endurance、SPI/QSPI timing。

### 重点监控项

| 维度 | 指标 |
|---|---|
| Cell 状态 | erased Vt、programmed Vt、read window、tail bit |
| 氧化层 | tunnel oxide leakage、TDDB、breakdown、charge loss |
| 擦写 | program time、erase time、verify fail、retry count |
| 保持 | retention bake BER、P/E 后 retention、老数据 read margin |
| 扰动 | read disturb、program disturb、邻近 WL / BL 错误 |
| 接口 | SPI / QSPI Fmax、dummy cycle margin、IO leakage、drive strength |

### 典型异常组合

| 测量特征组合 | 预警失效 |
|---|---|
| Vt distribution widening + read window 变窄 | 后续 read fail / 高温读错 |
| tunnel leakage tail 增大 + retention bake bit error 增加 | 数据保持风险 |
| erase time 整体右移 + blank check tail fail | 擦除路径 / oxide trap 风险 |
| program time 变长 + verify fail 增加 | program efficiency 下降 |
| 固定 sector fail + wafer cluster | 局部阵列 / 制程缺陷 |
| 高速 QSPI fail + 低速 pass | 接口 timing / SI / IO margin 风险 |

---

## 9.2 NAND Flash

NAND 的质量核心：

> 不是追求零 bit error，而是看 raw BER、ECC margin、bad block、read retry、disturb 是否在可管理范围内。

### 重点监控项

| 维度 | 指标 |
|---|---|
| 坏块 | initial bad block、grown bad block、die / plane 分布 |
| BER | raw BER、ECC correction count、BER histogram |
| 阈值 | Vt valley、read retry level、threshold shift |
| 耐久 | P/E cycling 后 BER、program / erase fail |
| 扰动 | read disturb、program disturb、neighbor page fail |
| 空间 | block / plane / die / wafer map |

### 典型异常组合

| 测量特征组合 | 预警失效 |
|---|---|
| raw BER tail 变厚 + ECC correction count 接近上限 | ECC margin 不足，后续数据风险 |
| read retry level 偏移变大 + retention 后 BER 上升 | Vt drift / retention 风险 |
| P/E 后 BER 快速上升 + grown bad block 增加 | endurance margin 不足 |
| initial bad block 某 die / plane 偏高 | die / plane 局部阵列或高压路径问题 |
| repeated read 后相邻 page BER 上升 | read disturb 风险 |
| program neighbor page 后原 page BER 上升 | program disturb / cell coupling 风险 |

---

## 9.3 DRAM

DRAM 的质量核心：

> retention、refresh、weak cell、sense margin、timing shmoo、row disturb。

### 重点监控项

| 维度 | 指标 |
|---|---|
| 电容 / cell | capacitor leakage、retention time、weak bit map |
| 刷新 | refresh interval sweep、high temperature retention |
| 时序 | tRCD、tRP、tRAS、tRC、Vmin、Fmax |
| 空间 | bank / row / column fail map |
| 扰动 | hammer pattern、victim row bit flip、refresh sensitivity |

### 典型异常组合

| 测量特征组合 | 预警失效 |
|---|---|
| capacitor leakage 上升 + high-temp retention fail 增加 | weak cell / retention margin 不足 |
| refresh interval 缩短后恢复 | 不是硬坏，而是 retention 边界不足 |
| 放宽 timing 后恢复 + 低压更明显 | sense amp 或 bitline develop margin 不足 |
| 高频访问 aggressor row 后相邻 row bit flip | row hammer / row disturb 风险 |
| fail 集中在某 bank / column | 局部 sense amp、decoder 或 bitline 风险 |

---

## 9.4 GD32 MCU

MCU 的质量核心：

> logic speed / leakage、eFlash、SRAM、POR/BOR、clock、LDO / bandgap、IO、外设和低功耗。

### 重点监控项

| 模块 | 指标 |
|---|---|
| Logic | RO、Fmax、Vmin、Vt、Idsat、Ioff |
| eFlash | erase / program、verify fail、retention bake、P/E cycling、charge pump current |
| SRAM | BIST、March test、checkerboard、Vmin、bit fail map |
| Clock | oscillator startup、PLL lock、frequency drift |
| Reset / Power | POR/BOR threshold、LDO output、bandgap、sleep current |
| IO / 外设 | IO leakage、VIH/VIL、VOH/VOL、drive strength、SPI/I2C/UART/CAN/USB timing |
| Analog | ADC INL/DNL、offset/gain、noise、Vref |

### 典型异常组合

| 测量特征组合 | 预警失效 |
|---|---|
| RO 慢 + Vt 偏高 + Fmax fail 增加 | slow corner，高频 / 低压运行风险 |
| Ioff tail 上升 + standby current 偏高 + 高温 leakage 变大 | 低功耗异常和高温可靠性风险 |
| eFlash 写后 CRC 正常，但 bake 后 CRC fail 增加 | eFlash retention / endurance 风险 |
| 常温标压 pass，低压 SRAM bit fail tail 增加 | SRAM cell stability margin 不足 |
| 慢 ramp 上电失败 + BOR threshold 分布异常 | POR / BOR margin 风险 |
| 低温 oscillator startup time 变长 + PLL lock fail 增加 | 时钟启动风险 |
| IO leakage tail 上升 + curve trace 异常 | ESD clamp / pad oxide 风险 |
| 高频 SPI fail + 低速 pass + IO edge slew 异常 | IO timing / drive strength / 封装寄生风险 |
| ADC 全通道同向偏移 + Vref drift | bandgap / reference / trim 风险 |

---

## 9.5 指纹 / 触控传感器

传感器的质量核心：

> sensing array 一致性、baseline、noise、SNR、dead pixel、ESD、湿热和模组装配。

### 重点监控项

| 维度 | 指标 |
|---|---|
| 阵列 | electrode open / short、raw capacitance map、dead pixel map |
| 基线 | baseline distribution、baseline drift、baseline sigma |
| 信号 | delta count、SNR、noise floor、row / column noise |
| 模拟前端 | AFE offset / gain、ADC channel offset |
| 环境 | 湿热后 drift、charger noise、EMI sensitivity |
| 可靠性 | ESD 后 leakage、ESD 后 dead pixel、FPC 弯折 / 按压 |

### 典型异常组合

| 测量特征组合 | 预警失效 |
|---|---|
| baseline sigma 变大 + noise floor 上升 + 湿热后 drift 增加 | 阵列一致性 / 封装湿气 / 表面材料风险 |
| 固定 row / column 图像异常 + ADC channel offset 异常 | readout circuit 或 ADC 通道问题 |
| ESD 后 dead pixel 增加 + IO leakage 变大 | sensing electrode / AFE ESD 损伤风险 |
| 充电状态下 noise 明显上升 | charger common-mode noise / 接地 / 电源滤波风险 |
| 按压或弯折后恢复 | FPC、焊点、连接器或模组装配风险 |

---

## 9.6 模拟 / 电源芯片

模拟 / 电源芯片的质量核心：

> reference、trim、tempco、load transient、current limit、Iq、环路稳定和保护阈值。

### 重点监控项

| 维度 | 指标 |
|---|---|
| 参考源 | bandgap voltage、tempco、noise |
| 输出 | LDO / DC-DC output、line regulation、load regulation、dropout |
| 负载 | current limit、load transient、step response |
| 功耗 | quiescent current、shutdown current、high-temp leakage |
| 保护 | UVLO、thermal shutdown、short protection、power good |
| 稳定性 | Bode plot、phase margin、output ripple、ESR sensitivity |
| 校准 | trim code distribution、trim margin |

### 典型异常组合

| 测量特征组合 | 预警失效 |
|---|---|
| bandgap 均值偏移 + trim code 靠边 + 高低温输出漂移变大 | reference / trim margin 风险 |
| current limit 分布偏低 + 重载启动 fail 增加 | 启动和负载能力风险 |
| quiescent current tail 变厚 + 高温漏电上升 | leakage / bias circuit 异常 |
| 负载跳变后振铃严重 + Bode phase margin 低 | 环路稳定性风险 |
| 某种输出电容下振荡，换电容恢复 | 外部器件匹配和补偿风险 |

## 10. 建立质量预警系统：应该抽取哪些特征

如果把质量分析系统化，可以为每个 lot / wafer / die 抽取 6 组特征。

### 10.1 中心趋势特征

包括：

- mean；
- median；
- lot mean；
- wafer mean；
- center value；
- chamber mean。

识别：

- 工艺中心漂移；
- 设备偏移；
- recipe 偏移；
- 材料批次偏移。

### 10.2 离散度和尾部特征

包括：

- sigma；
- range；
- IQR；
- P95 / P99 / P99.9；
- tail ratio；
- Cpk / Ppk；
- guardband fail count。

识别：

- 均匀性变差；
- tail die 增多；
- spec 内边缘品；
- 同批次低概率现场失效风险。

### 10.3 空间特征

包括：

- edge-center delta；
- radial gradient；
- cluster density；
- reticle repeat score；
- neighbor correlation；
- hot zone；
- wafer map similarity。

识别：

- wafer 边缘异常；
- 局部污染；
- 光刻 / reticle；
- chamber fingerprint；
- 搬运或刮伤问题。

### 10.4 应力响应特征

包括：

- before / after bake delta；
- after cycling delta；
- read disturb delta；
- HTOL drift；
- thermal cycling fail increase；
- ESD 后 leakage delta。

识别：

- oxide 弱点；
- retention / endurance 风险；
- 金属 / via 弱点；
- 封装热疲劳；
- IO 保护弱点。

### 10.5 多参数组合特征

典型组合：

- Vt + Ioff + standby current；
- tunnel leakage + erase time + retention fail；
- contact R + Fmax + low voltage fail；
- bandgap + trim code + temp drift；
- SRAM Vmin + ring oscillator + sleep current；
- sensor baseline + noise + humidity drift。

识别：

> 单项未超限，但整体画像明显异常的 maverick die / wafer / lot。

### 10.6 下游反馈特征

包括：

- CP bin；
- FT bin；
- burn-in fail；
- reliability fail；
- RMA fail mode；
- customer field return；
- lot genealogy；
- tool / chamber history。

识别：

- 上游过程参数和下游失效的真实关联；
- 哪些 spec 内异常需要 guardband；
- 哪些测试项需要加严或新增；
- 哪些 fab / OSAT 环节需要 root cause。

## 11. 质量工程方法：SPC、Maverick 和 Guardband

### 11.1 SPC 不是只看控制线

常用方法：

- X-bar / R chart；
- Cpk / Ppk；
- Western Electric rules；
- EWMA；
- moving average；
- lot-to-lot trend；
- tool / chamber split comparison。

重点识别：

- 连续多批同方向偏移；
- 分布突然变宽；
- 均值合格但 Cpk 下降；
- 某台设备加工的 wafer tail 异常；
- 某 chamber 产品后续 CP fail 偏高。

### 11.2 Maverick lot / wafer / die

定义：

- Maverick lot：整批虽然合格，但明显偏离历史族群；
- Maverick wafer：某片 wafer 异常；
- Maverick die：某颗 die 虽 pass，但异常边缘。

识别方法：

- robust z-score；
- Mahalanobis distance；
- PCA；
- clustering；
- wafer map pattern recognition；
- CP bin outlier；
- multi-parameter guardband。

典型风险：

> 单项参数全部 in spec，但多个参数同时偏到边缘，这类 die 比单项 fail 更危险，容易在客户现场变成偶发问题。

### 11.3 Guardband 策略

Guardband 的目的不是提高测试好看程度，而是拦住客户场景下可能失效的边缘品。

常见做法：

- 低压 guardband；
- 高频 guardband；
- 高温 guardband；
- leakage guardband；
- retention bake guardband；
- ECC correction count guardband；
- trim code guardband；
- retest pass unit 加严。

不同产品 guardband 重点不同：

| 产品 | 重点 guardband |
|---|---|
| NOR Flash | read margin、erase/program time、retention bake、P/E 后 margin |
| NAND Flash | raw BER、ECC count、read retry、grown bad block |
| DRAM | retention time、refresh interval、timing shmoo、Vmin |
| MCU | eFlash retention、SRAM Vmin、Fmax、POR/BOR、sleep current、IO leakage |
| 传感器 | baseline noise、SNR、dead pixel、湿热 drift、ESD 后 leakage |
| 模拟 / 电源 | bandgap、trim code、temp drift、load transient、current limit、Iq |

## 12. 从异常识别到质量动作

识别异常后，工程动作要分级。

### 12.1 立即隔离

适用：

- 明确 out of spec；
- wafer map 明显异常；
- lot 与历史族群明显不同；
- 可靠性应力出现异常 fail；
- 下游 FT / 客诉已有关联。

动作：

- hold lot；
- hold wafer；
- stop ship；
- 追加测试；
- 按 wafer / lot / chamber 分层隔离。

### 12.2 加严筛选

适用：

- spec 内但 out of family；
- tail 变厚；
- 某些 guardband fail 增加；
- 与高温、低压、高频或应力相关。

动作：

- 增加低压 / 高频测试；
- 增加高温测试；
- 增加 retention bake；
- 增加 P/E cycling 抽测；
- 提高 ECC / BER 筛选阈值；
- 对 retest pass unit 做降级或剔除。

### 12.3 反馈制程

适用：

- 与 inline / WAT 参数相关；
- 有 wafer map / chamber / reticle pattern；
- 多批次趋势一致。

动作：

- fab root cause；
- tool / chamber split；
- recipe 调整；
- inline monitor 加严；
- WAT item 或 limit 调整；
- 与晶圆厂建立 lot genealogy 追踪。

### 12.4 反馈设计 / 测试

适用：

- 多个 fab / lot 都有类似边界问题；
- 设计 margin 对过程波动敏感；
- 当前 CP / FT 覆盖不了客户场景。

动作：

- 设计 margin review；
- 加强 BIST / margin test；
- 调整 test pattern；
- 增加 shmoo 项；
- 增加应用相关测试；
- 优化 datasheet 约束和应用指南。

### 12.5 客户 containment

适用：

- 已有客户风险；
- 某批次已出货；
- 风险与具体应用条件有关。

动作：

- 追溯 lot / wafer / date code；
- 提供筛选后的替换料；
- 给出应用侧降频 / 电压 / 温度 / 上电时序建议；
- 建立 RMA 复现流程；
- 给客户 8D 中期和最终报告。

## 13. 典型预警链路示例

### 13.1 NOR Flash retention 风险

```text
Inline / WAT:
  tunnel oxide leakage tail 增大

CP:
  program / erase time 分布变宽
  read margin 变窄

Reliability:
  retention bake 后 bit error 增加

风险判断:
  高温长期使用后数据保持风险上升

动作:
  hold 相关 lot
  加严 retention bake / read margin guardband
  反馈 fab 排查 oxide process
```

### 13.2 NAND ECC margin 风险

```text
CP:
  raw BER tail 变厚
  read retry level 偏移

Reliability:
  P/E 后 BER 增长速度偏快
  grown bad block 增加

风险判断:
  ECC margin 不足，客户长期写入后数据风险上升

动作:
  提高 ECC correction count 筛选阈值
  分层管控 die / plane / wafer
  反馈阵列和高压路径制程窗口
```

### 13.3 MCU 低压启动风险

```text
WAT:
  Vt 偏高
  Idsat 偏低
  RO 变慢

CP / FT:
  Fmax 分布左移
  Vmin 分布右移
  慢 ramp 上电 fail 增加

风险判断:
  slow corner + POR/BOR margin 不足，客户低压或慢上电场景可能启动失败

动作:
  增加低压 / ramp guardband
  对相关 lot 降级或剔除边缘 die
  反馈设计 review reset / clock / LDO margin
```

### 13.4 传感器误触风险

```text
CP / FT:
  baseline sigma 变大
  noise floor 上升

Reliability:
  湿热后 baseline drift 增加
  charger noise 下误触上升

风险判断:
  sensing array / 封装 / 接地 / 算法抗噪 margin 不足

动作:
  加严 baseline noise / humidity drift limit
  排查封装材料和模组装配
  调整算法阈值或应用接地建议
```

### 13.5 模拟电源输出漂移风险

```text
WAT / FT:
  bandgap 均值偏移
  trim code 靠近边界

Reliability:
  HTOL 后 Vout drift 增大
  高温下 Iq tail 变厚

风险判断:
  reference / bias margin 不足，客户极限温度下参数漂移风险

动作:
  加严 trim code guardband
  增加高低温 FT
  反馈 bandgap / bias 设计和工艺参数
```

## 14. 对个人能力建设的启发

如果目标是进入芯片质量、工艺质量、供应商质量或智能制造质量分析方向，真正需要培养的不是单点测试知识，而是跨层数据判断能力。

关键能力：

1. 读懂产品：知道 NOR、NAND、DRAM、MCU、传感器、模拟芯片分别怕什么；
2. 读懂制程：知道 CD、overlay、oxide、implant、metal、CMP 异常会怎么传导；
3. 读懂测试：知道 WAT、CP、FT、reliability 每层数据能证明什么、不能证明什么；
4. 读懂统计：知道均值、方差、tail、Cpk、wafer map、maverick 的意义；
5. 读懂客户：知道客户看到的是死机、读错、误触、功耗大，但背后可能是工艺边界；
6. 建立闭环：把异常识别转成 hold、screen、guardband、fab root cause、design feedback 和 customer containment。

这类能力很适合和 AI / 数据系统结合。因为质量工程的本质就是：

> 多源异构数据里的异常识别、因果假设、证据链构建和闭环决策。

## 15. 一句话收束

针对兆易创新这类产品组合，制程质量工程最核心的不是等芯片坏了再做 FA，而是在量产过程中通过：

> **Inline + WAT + CP + FT + Reliability + 客诉反馈**

识别：

> **均值偏移、分布变宽、尾部变厚、空间异常、应力 delta、多参数组合异常和 out-of-family 产品。**

最终目标是把可能导致：

- Flash retention；
- NAND BER / ECC margin；
- DRAM refresh；
- MCU boot / low-power / eFlash / SRAM；
- 传感器 noise / drift；
- 模拟电源 drift / stability；

的风险，在出货前用 guardband、筛选、隔离、制程反馈和设计反馈提前拦住。
