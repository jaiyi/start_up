## 核心项目经历

### 项目一：焊接曲线实时判异系统

> **角色**：技术负责人 | **周期**：2025.12–至今 | **状态**：生产运行中

**项目背景**：汽车焊装产线每日产生数十万条焊接电阻曲线（100-700采样点/条），需实时识别虚焊、飞溅、炸点等质量异常。

**技术方案**：
- 设计**6路并行独立检测器**架构（Envelope包络线偏离 / FFT频域相似度 / Slope导数异常 / DTW动态时间弯曲 / Extreme炸点检测 / Extreme飞溅检测），各检测器独立判级，最终取最高等级
- 实现**自适应标准曲线训练**：按(设备, 焊点, 脉冲段数, 曲线长度)四维分桶，每小时自动refit，append-only版本管理
- 构建**分段包络线**算法：预热段 max/min+expansion，焊接段 mean×multiplier，min_width_ratio保底
- 基于pgmq的**实时评估Worker**：Kafka CDC秒级入库 → PG Trigger入队 → Worker实时判异 → 严重告警10分钟熔断推送

**核心成果**：
- 覆盖 **298台焊接设备、4,913个焊点**，累计处理 **778万条焊接记录**
- 实时检测延迟 <1秒，单曲线推理耗时 <10ms
- 严重异常检出率高于设备自检（补充检出设备未识别的渐变型异常）
- 反馈闭环机制：推送→确认/忽略→误报率分析→检测器阈值自适应调优

**关键技术词**：波形异常检测 / 包络线算法 / FFT频域分析 / DTW / 实时流处理 / 边缘推理 / 自适应训练

### 项目二：SPC统计过程控制 + CPK趋势诊断Agent

> **角色**：技术负责人/架构设计 | **周期**：2025.06–至今 | **状态**：生产运行中 + Agent试点

**项目背景**：对焊装/涂胶/LASD等工艺的关键质量参数（UIP电压、扭矩、胶量）实施7×24实时统计监控，及时发现过程能力退化趋势。

**技术方案（SPC引擎）**：
- 实时评估层：Nelson Rules 8条判异规则实时检测，控制限内存缓存 + pg_notify失效刷新
- 训练层：Spec外数据自动过滤 → Box-Cox变换 → 自适应拟合 → Cp/Cpk/Pp/Ppk能力指数计算
- **CPK趋势检测**：三层决策树（触发模式: 急性/慢性 → 恶化侧: upper/lower/both → 归因: 漂移/散度/复合）
- EVI价值量化：每次异常检出 = 可量化经济收益(CNY)，累计呈现智能收益面板

**技术方案（诊断Agent）**：
- 基于**BPMN 5阶段**流程引擎的AI诊断Agent：感知→识别→诊断→措施→验证
- **OWL本体知识图谱**驱动：4M+1E故障分类、CpkTrendPattern诊断规则、设备拓扑关联
- 假设验证推理：Agent通过Tool调用（query_spc_data / query_glue_change_log / get_similar_cases）逐步排除候选假设
- Apache AGE图遍历：设备关联发现集群问题，历史案例匹配提升诊断confidence
- 工单生命周期管理：CPK恢复自动关闭 + 同工位去重合并

**核心成果**：
- 覆盖3个工艺域（点焊/涂胶/LASD），数千个监控窗口
- CPK趋势预警**提前2-4小时**发现过程能力退化（vs 人工巡检周期8小时）
- Agent诊断试点：涂胶工艺自动定位根因准确率>75%，人工介入时间减少60%
- 2025年累计计价收益 **3亿元**（团队整体EVI，含多个Agent方向）

**关键技术词**：SPC / Nelson Rules / CPK趋势检测 / AI Agent / OWL本体 / 知识图谱 / BPMN流程引擎 / 假设验证推理
