## 核心业务架构

```
兆易创新（"感存算控连"一体化芯片生态）
├── 存储芯片（营收占比~71%，核心利润引擎）
│   ├── SPI NOR Flash — 全球第二，市占18.5%，累计出货310亿+颗
│   ├── 利基型DRAM — DDR3/DDR4，绑定长鑫存储独家代工
│   └── SLC NAND Flash — 工控/车载，海外大厂退出后国产替代
├── MCU微控制器（营收占比~21%，第二增长曲线）
│   ├── GD32系列 — 国产32位通用MCU第一，800+款型号
│   ├── 车规MCU — 通过ISO 26262 ASIL D认证
│   └── RISC-V AI MCU — 2027年落地，面向机器人/边缘AI
├── 模拟芯片（营收占比~4%，爆发增长中）
│   ├── 电源管理芯片（PMIC）
│   ├── BMS电池管理
│   └── 电机驱动芯片（2026年推出三相栅极驱动器）
└── 传感器（营收占比~4%）
    ├── 指纹识别传感器
    ├── 触控传感器
    └── 温湿度传感器
```

### 关键战略关系：兆易创新 ↔ 长鑫存储

- **股权绑定**：兆易持有长鑫科技1.62%股份（前十大股东、唯一A股上市主体）
- **管理绑定**：朱一明同时担任两家公司董事长
- **业务绑定**：长鑫承诺30%成熟DRAM产能优先供给兆易，合作锁定至2028年
- **交易规模**：2025年11.82亿元 → 2026年计划57亿元（增长近5倍）

## 🔥 重点调研：AI/数据方向岗位分析

### 兆易创新的AI战略定位

兆易创新以 **"全面拥抱AI"** 为核心战略方向，构建"组织-产品-生态"三位一体的AI能力：

1. **AI组织赋能**：推动内部组织架构变革，组建资深专家团队领衔的**AI实验室**
2. **AI产品定义**：覆盖端侧算力到高速连接到云端的商业飞轮
3. **AI生态合作**：推出全栈式解决方案，尤其在**工业和消费领域**积极布局

### AI在兆易创新的具体落地场景

| 场景 | 技术路径 | 产品载体 |
|------|----------|----------|
| **工业直流拉弧检测(AFCI)** | 深度卷积神经网络，250K/500K采样率，100%准确率 | GD32H7 MCU + AI算法 |
| **AI语音识别** | 端侧轻量化模型，关键词训练+多语言识别+噪声抑制 | GD32H7 + Sensory平台 |
| **电机控制优化** | AI自适应优化，减少调试周期 | GD32 FOC/Servo方案 |
| **预测性维护** | 传感器异常检测，边缘推理 | MCU端侧TinyML |
| **人形机器人** | 多关节精准协同控制 + 多模态传感器融合 | GD32H75E EtherCAT |
| **工业质量检测** | 图像/信号处理AI模型部署 | GD32 Embedded AI Tool |
| **设备状态监测** | 振动/温度等多源数据异常检测 | MCU + AI算法 |

### AI开发工具生态

- **GD32 Embedded AI Tool**：将预训练模型（TensorFlow Lite/ONNX/GD32 Model Zoo）载入、分析、量化后自动转换为优化库
- 自动生成Benchmark和报告，模型评估一键完成
- 未来目标：一站式AI开发平台 + 客户定制服务

### 你看到的三个岗位分析

#### 1. AI算法高级工程师

| 维度 | 推测内容 |
|------|----------|
| **可能所属部门** | AI实验室 / MCU事业部AI方向 |
| **核心职责** | 端侧AI模型开发、训练、量化压缩、部署到MCU；TinyML算法优化 |
| **技术栈推测** | Python/C++, TensorFlow Lite, ONNX, 模型量化(INT8/INT4), 嵌入式AI推理优化 |
| **应用场景** | 拉弧检测CNN、语音识别、电机自适应控制、异常检测 |
| **薪资预估** | 40-60K×13薪（参考校招算法40-60K，社招高级会更高） |
| **门槛** | 需要AI模型训练+嵌入式部署经验，偏边缘AI/TinyML而非大模型 |

**关键区别**：这里的AI算法不是互联网大模型方向，而是**端侧轻量化AI**——模型要小到能在MCU上跑（Flash几百KB~几MB级），强调模型压缩、量化、推理效率。

#### 2. AI技术工程师

| 维度 | 推测内容 |
|------|----------|
| **可能所属部门** | AI实验室 / 生态与工具链团队 |
| **核心职责** | AI开发工具链建设（GD32 Embedded AI Tool）、客户AI方案支持、Demo开发 |
| **技术栈推测** | Python, TensorFlow/PyTorch, ONNX Runtime, 模型转换工具开发, MCU SDK |
| **应用场景** | 帮助客户将AI模型部署到GD32 MCU，开发参考设计和示例工程 |
| **薪资预估** | 30-50K×13薪 |
| **门槛** | AI+嵌入式交叉背景，或纯AI背景+愿意学嵌入式 |

**关键信息**：这个角色介于"AI算法"和"FAE技术支持"之间，既要懂模型也要懂如何在资源受限的MCU上跑起来。

#### 3. 数据应用主管工程师

| 维度 | 推测内容 |
|------|----------|
| **可能所属部门** | 战略与发展部 / 市场分析 / 供应链数据团队 |
| **核心职责** | 企业内部数据平台建设、业务数据分析、决策支持系统 |
| **技术栈推测** | SQL, Python/R, BI工具(Tableau/PowerBI), 数据仓库, 可能涉及ML预测 |
| **应用场景** | 销售预测、供应链优化、客户分析、产品定价策略 |
| **薪资预估** | 30-50K×13薪（主管级别，5-10年经验） |
| **门槛** | 数据分析/数据工程背景，了解半导体行业加分但非必须 |

**关键信息**：这是相对纯软/数据方向的岗位，不需要嵌入式/硬件背景，更接近互联网公司的数据分析师/数据工程师角色。

### 面试准备建议（AI方向）

**必须了解的技术知识点：**
1. **TinyML / 端侧AI**：模型如何在几百KB Flash的MCU上运行
2. **模型量化**：FP32→INT8/INT4的精度-效率权衡
3. **GD32 Embedded AI Tool**：兆易自研的AI部署工具链
4. **典型应用Case**：拉弧检测方案（1.7K代码、0.7ms推理、100%准确率）
5. **TensorFlow Lite Micro vs ONNX Runtime**：端侧推理框架对比
6. **MCU vs MPU**：为什么选MCU做AI而不是用树莓派/Jetson
7. **竞品对比**：ST的Edge AI（STM32Cube.AI）、瑞萨的Reality AI

**面试中可以展示的差异化优势：**
- 工业AI落地经验（预测性维护、质量检测等场景理解）
- 从云端大模型→端侧轻量化的完整链路认知
- AI产品化思维（不只是做模型，还懂如何做成产品方案交付给客户）

## 求职评估

### 优势
- ✅ **地理位置极优**：总部在中关村集成电路设计园（永丰/西北旺），通勤3-5公里
- ✅ **业绩爆发期**：2026年利润同比增长10倍+，薪资/奖金预期好
- ✅ **行业龙头**：国产存储+MCU双龙头，国产替代核心标的
- ✅ **管理规范**：A+H上市、外企管理基因、福利体系完善
- ✅ **AI战略明确**：已成立AI实验室，"全面拥抱AI"是公司级战略
- ✅ **工业AI场景丰富**：拉弧检测/电机控制/机器人/预测性维护均已落地

### 劣势
- ⚠️ AI团队仍在建设初期，规模和成熟度不如互联网AI团队
- ⚠️ 端侧AI技术栈（TinyML/MCU部署）与互联网AI（大模型/RAG）差异较大
- ⚠️ 芯片设计行业工作强度不低，业绩高速增长期可能更忙
- ⚠️ 硕博占比56%，AI算法岗可能偏好硬件+AI交叉背景

### 重点关注岗位（按推荐优先级）
1. 🥇 **AI技术工程师** — 最佳切入点，AI应用层+客户方案，可从软件侧切入
