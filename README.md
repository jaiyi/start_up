# 个人知识与实战仓库

这是一个长期积累型个人知识系统，同时承载技术学习、外部研究、个人洞察、职业建设和可运行实战项目。

## 目录

- [知识](./知识/)：稳定的技术与领域知识
- [研究](./研究/)：产品、公司、案例和外部事实研究
- [洞察](./洞察/)：个人判断、战略、行业和职业思考
- [项目](./项目/)：家庭营养师、SPC × DeepSeek Harness 等实战项目
- [个人](./个人/)：个人档案、职业资料、简历和证书
- [资料](./资料/)：暂时无归属或跨主题公共原始资料
- [管理](./管理/)：全仓库规范、模板、索引和迁移记录

## 内容归属原则

1. 稳定知识进入 `知识/`，外部事实进入 `研究/`，个人判断进入 `洞察/`。
2. 有代码、测试、部署或独立迭代节奏的内容进入 `项目/`。
3. 项目专属设计、计划、决策和资料跟随项目维护。
4. 原始资料优先跟随引用它的主题；只有暂时无归属或公共资料才进入 `资料/`。
5. 一个内容只有一个权威位置，其他位置通过 Markdown 链接引用。
6. `docs/` 已不再作为长期内容目录；新内容不要回填到旧路径。
