## 一句话排序（面向你当下数据方向）

> **CDGA → CDGP** 最对口，优先做。TOGAF 作为长期"架构/技术管理"背书可后补。PMP/CDMP 除非有明确外部门槛（落户/外企），否则不必。

**别指望证书完成转型**——它们是"体系认知 + 简历/投标加分"，真正的筹码是你手里的 SPC/云链/EVI 实战和跨部门落地能力。

## 决策树

```
你近期主攻哪个方向？
│
├─ 数据应用 / 数据治理（如兆易数据应用主管）
│    → 首选 CDGA（快速拿标签）→ 有余力上 CDGP（真正加分）
│    → TOGAF/PMP/CDMP 都不是当务之急
│
├─ 往企业架构师 / IT技术规划管理走
│    → TOGAF（综合级），补"企业架构方法论"体系化表达
│
├─ 需要一线城市积分落户加分
│    → PMP（便宜好考，落户加15-20分）
│
└─ 有外企 / 出海 / 跨国团队打算
     → CDMP（国际硬通货）
```

## 分场景建议

**场景A：稳扎数据方向（当前主线，推荐）**
1. **先 CDGA**：1000元、自学30天、建立 DAMA 数据治理体系认知 + 简历标签
2. **再 CDGP**：真正拉开差距的一张，面向数据治理专岗和甲方招投标；你本科+多年经验，门槛无碍
3. 时间线：CDGA/CDGP 每年 3/6/9/12 月考。若现在起步，可瞄准**12月 CDGA → 明年3月 CDGP**

**场景B：长期技术管理/架构背书**
- TOGAF 综合级作为补充，不急，等数据方向证书拿下后再说

**场景C：落户驱动**
- 若在北京落户需要积分，PMP 是低成本打勾项（¥6-8K），否则跳过

## 给你的坦率提醒

- **CDGA 含金量被门槛低稀释**，别把它当能力证明，当"入场券+体系框架"用
- **CDGP 才是数据治理方向最有分量的一张**，投入产出比最高
- **PMP 对你是"降维"**——它认证的经验你早就有了，除非落户/硬门槛，否则时间花在别处回报更高
- 证书堆叠 ≠ 转型成功。你的差异化在**工业数据实战（SPC/云链/EVI）能迁移到半导体**，这个故事比任何证都值钱——见 `../semiconductor-data-concepts.md` 和 `../interview-gigadevice-prep.md`
