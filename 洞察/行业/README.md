# 行业洞察

本目录沉淀对半导体、航天、制造和质量管理等行业的个人判断。它回答行业业务循环、关键约束、数字化机会和能力建设方向，不替代外部事实研究。

## 内容边界

- 外部公司、产品、案例和公开事实放在 [`研究/`](../../研究/)；
- 从多个事实归纳出的行业判断放在这里；
- 已经形成实施边界的系统设计放在 [`项目/`](../../项目/)；
- 经过验证的通用方法放在 [`知识/`](../../知识/)。

## 维护规则

- 每篇文章区分外部证据、行业归纳和个人判断。
- 行业事实发生变化时，更新来源和更新时间；不要用个人推断替代事实。
- 新主题先判断是否属于行业共性问题；单一公司或单一产品材料应归入 `研究/`。
- 与具体项目形成正式接口、数据或实施决策后，在项目目录建立权威设计文档并从这里链接过去。
