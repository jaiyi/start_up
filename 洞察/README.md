# 洞察

存放对多个事实进行消化后的个人判断、归纳、取舍和方向判断。洞察不是外部对象的事实档案，也不是具体项目的正式设计。

## 目录

- [AI原生转型](./AI原生转型/)：从 AI 能力、平台、组织到企业经营转型的连续判断
- [行业](./行业/)：制造、半导体、航天等行业中的业务、技术和质量判断
- [职业规划](./职业规划/)：岗位演化、行业选择和知识复利路线
- [潜在应用idea](./潜在应用idea/)：尚未形成项目边界的应用假设和产品化点子

## 与其他目录的边界

- 外部产品、公司和应用案例的事实研究放在 [研究](../研究/)。
- 已经具备独立项目边界的设计、计划、决策和实现放在 [项目](../项目/)。
- 经过实践验证、可以脱离具体项目复用的方法放在 [知识](../知识/)。
- 具体应用案例优先放在 [研究/案例](../研究/案例/)，再从案例中提炼洞察。

## 阅读顺序

```text
研究：外部事实、对象、案例和证据
   ↓
洞察：归纳、判断、取舍和方向
   ↓
项目：设计、实现和验证
   ↓
知识：经过验证后可复用的方法
```
