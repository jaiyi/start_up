# AI 原生转型

本目录沉淀基于产品研究、案例研究和项目实践形成的 AI 原生转型判断，覆盖任务闭环、平台、组织、企业经营、数据治理、价值归因和落地路径。

## 内容边界

这里记录“如何理解、如何取舍、如何行动”的个人判断，不重复保存外部产品事实，也不替代具体项目的正式设计。外部事实见 [`研究/`](../../研究/)，具体实现与验证见 [`项目/`](../../项目/)。经过项目验证并可复用的方法，再沉淀到 [`知识/`](../../知识/)。

## 维护规则

- 新文章先明确它是在做事实归纳、个人判断还是行动方案；事实研究不直接堆入本目录。
- 文章之间通过链接建立关系，不复制另一篇文章的完整正文。
- 当判断已经进入具体项目，项目决策以项目目录为准；当方法经项目验证后，再迁移或提炼到 `知识/`。
- 每次重要更新在文档开头记录更新时间、证据变化和判断变化。
- 方案比较应注明比较日期、维度、证据来源、事实与推断的边界。
