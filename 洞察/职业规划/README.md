# 职业规划

本目录沉淀岗位演化、行业选择、能力建设和知识复利相关的个人判断，重点关注智能制造、工业 AI 和业务技术复合型岗位。

## 内容边界

这里记录长期职业方向和能力结构判断，不存放简历、证书、面试材料等个人档案，也不存放单家公司事实研究。个人材料见 [`个人/`](../../个人/)，公司和行业事实见 [`研究/`](../../研究/)。

## 维护规则

- 将短期求职选择与长期能力资产分开记录。
- 行业和岗位判断应链接到对应的研究证据，避免只记录抽象观点。
- 新增岗位方向时，说明业务循环、知识复利来源、可验证成果和潜在迁移路径。
- 简历、证书、面试题和求职材料放入 `个人/`，不要复制到这里。
